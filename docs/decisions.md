# 의사결정 기록

목적: 팀의 선택과 근거, 적용 범위를 보존합니다. 공식 대회 사실은 출처를 확인하고 프로젝트 개요와 데이터 사전에 기록합니다.

## 초기 합의

- 개인 실험은 `experiments/`, 검증된 공용 코드는 `src/`에서 관리합니다.
- 실험은 질문/가설 중심으로 순차 관리하고, 유형은 metadata로 기록합니다.
- 데이터와 대용량 산출물은 Git에 올리지 않습니다.
- 실제 실험은 아직 시작하지 않습니다.
