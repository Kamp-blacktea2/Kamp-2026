# 데이터 EDA 결과 — YSH 실험 계보와 모델링 전제

작성 기준: 2026-09-27. 대상은 현재 프로젝트의 용접 데이터와 YSH-001~006B의 최종 보고서·저장 표다. **이번 작업은 원본 기술통계의 재계산과 기존 결과의 통합 검토이며, 새 모델 학습이나 기존 실험 재실행은 아니다.**

현재 데이터로 공정 상태·희소성·국소 신호를 탐색하는 비지도 모델링은 가능하다. 그러나 **개별 불량 분류, 불량 유형별 행 라벨, 제품 경계, 실제 안전 운전영역은 확정할 수 없다.** 주요 병목은 Feature 수 자체보다 관측 단위·품질 대응·반복에 따른 검증 독립성이다.

공식 원문 PDF는 현재 `data/`에서 찾지 못했다. 따라서 도메인 설명의 직접 근거는 사용자가 지정한 가이드 기반 두 문서와 그림이며, 이번에 원 PDF를 새로 대조했다고 주장하지 않는다. 원자료와 outputs는 Git 제외 대상이므로 주요 수치는 본문에 남겼다. 상세 표 링크는 로컬 산출물이 있을 때 사용할 수 있다.

표에서 NA/미기록은 0이 아니다. F=가압력(bar), I=전류(kA), V=전압(V), t=통전시간(ms). `행`은 관측 기록, `창`은 분석용 연속 행 묶음, `제품`은 실제 물품이며 서로 바꾸어 쓰지 않는다. Excel 행 번호는 헤더를 포함한 번호이고, `idx` 및 0-based 위치와 구분한다.

## 2. 실제 공정에 맞춘 해석 범위

![Spot 용접 구성과 가압·통전·유지·개방 순서](../data/용접방식.png)

문서와 그림이 설명하는 공정은 자동차 부품의 작업자 기반 저항 Spot 용접이다. 작업자가 부품을 위치시키고 전극으로 가압한 상태에서 전류를 흘린다. 전류가 꺼진 뒤에도 가압 유지 구간이 존재하고, 이후 전극이 열린다. PLC/MES 공정 기록과 ERP 소재 정보, 육안 품질검사가 배경이다. 과거 대화의 로봇·컨베이어 가정은 확정된 설비 설명으로 승격하지 않는다.

| 구분 | 확인할 수 있는 내용 | 확인할 수 없는 대응 |
| --- | --- | --- |
| 동작 순서 | 스위치 → 가압 개시 → 통전 개시 → 통전 완료 → 가압 완료 → 전극 개방 | Raw의 행별 단계 ID |
| 수집 메타데이터 | 약 8초 주기, 4지점, 각 지점 약 0.072초 수집이라는 문서 설명 | 8초당 제품 수, 한 행의 경과시간, 한 행=한 Spot |
| 통전시간 | `weld time(ms)`는 전극에 전류를 통한 시간 | 수집 구간과 통전 구간이 물리적으로 동일한지 |
| 압력 | F의 단위는 bar | 전극 힘 N, 접촉응력, 실제 가압 파형 |
| 전류·전압 | 용접 지점에서 기록한 값 | 순간값/평균/RMS/최댓값 중 무엇인지, 두 값의 동시 측정 방식 |
| 품목 | `Item No=65235-25800`, 생산품목 | 실제 개별 제품 instance ID |
| 4개 측정변수 | 한 행에 F/I/V/t가 함께 기록 | 네 변수=네 단계, 네 행=네 단계·네 지점·한 제품 |

**72ms 해석의 정리:** `0.072초=72ms`라는 단위 환산과 현재 t의 대표값이 72ms라는 사실은 맞다. 하지만 그것만으로 센서 수집 구간과 전류 공급 구간의 시작·끝이 같다는 결론은 나오지 않는다. 데이터 사전 §6·§14의 “직접 대응/측정·통전 구간” 표현은 이 문서에서 수치의 일치까지로 제한한다. `공정방식.md`의 행 대응 미확정 원칙을 따른다. `8/0.072`로 제품당 행 수를 산출하거나 `idx mod 4`에 Spot 이름을 붙이지 않는다.

가압력은 접촉저항에 영향을 줄 수 있으나 높을수록 좋다는 단조 관계가 아니다. 전류·통전시간은 저항열 및 Nugget 형성과 관련된다. 전극 접촉면적·마모·냉각이 중요하지만 현재 컬럼에는 없다. 특정 V/F/I/t 값만으로 파임·용접부족·크랙을 확정하지 않는다.

## 3. 입력 파일, 관측 단위와 결측

| 파일 | 시트 | 행 | 열 | 결측 셀 |
| --- | --- | --- | --- | --- |
| 원본 | Raw data | 11939 | 10 | 0 |
| 원본 | result | 23 | 7 | 20 |
| 원본 | data set | 10 | 3 | 0 |
| scaled | scaled_data | 11939 | 5 | 71 |

Raw의 실제 데이터는 Excel 2~11,940행이다. 따라서 11,940은 헤더를 포함한 마지막 행 번호이고 학습 기록 수는 11,939다. `data set`은 `Data / 항목 설명 / 수집 범위`로 구성된 변수 설명 시트이며 별도 학습 표본이 아니다.

`result`의 결측 20셀은 전부 `Unnamed: 6`의 유형 설명란이다. 실제 존재하는 23행의 날짜·defect·defect type에는 결측이 없다. 반면 특정 날짜×유형 레코드 자체가 없다는 문제는 별도로 남는다. 셀 결측과 미기록 조합을 구별해야 한다.

두께는 모두 0.7mm다. 두께로 나눈 파생변수는 현재 파일에서는 기존 변수의 상수배일 뿐 새 정보가 아니다. 설비나 품목이 다른 조건으로의 일반화도 현재 자료만으로 평가할 수 없다.

가압력의 저장값 고유 수는 177개지만 소수 둘째 자리로 정리하면 176개다. Excel 부동소수 표현 차이가 포함되어 있다. F/I/t 소수 둘째 자리·V 셋째 자리로 정리해도 네 변수 고유 조합 수는 1,574개로 동일했다. 계산 원본은 보존하고 표시 반올림과 실제 정제를 구분한다.

## 4. 네 공정변수의 전체 분포

아래는 전체 Raw를 같은 가중치로 재계산했다. std는 표본표준편차(ddof=1), MAD는 `median(abs(x-median(x)))`로 보정계수를 곱하지 않았으며 분위수는 선형 보간이다. YSH-006A의 일별 계산은 ddof=0인 통계가 있으므로 표준편차를 그대로 교차 비교하지 않는다.

controlled100에서 이 중10개는 anchor 자체가 제외되어 평가 불가이고, `FIV_delta_398`만 비정확 출현307개·상대날짜4개가 남았다. 통제 후 G를 재검증한 결과는 아니다. **gap16은 길이4 창의 시작점 간격16이며, 길이16 파형 전체가 반복된다는 뜻이 아니다.** 비중첩 선택의 최소 간격4도 알고리즘이 만드는 조건이므로 최빈 gap4를 4지점 증거로 사용하지 않는다. 선택적 J 비교는 실행되지 않았다.

## 11. 검증과 scaling에서 반드시 유지할 제약

### 11.1 날짜 분할만으로 새로운 상태 검증이 되지 않는다

기존 분할은 학습3/24~3/31 8,470행, 확인4/2·4/3·4/7 3,469행이다. 005의 정확 중복 감사:

| 창 폭 | 유효 확인 창 | 학습에 정확 일치한 확인 창 | 해당 창에 포함된 확인 행의 합집합 | 미포함 확인 행 |
| --- | --- | --- | --- | --- |
| 1 | 3469 | 3469 | 3469 | 0 |
| 4 | 3460 | 3430 | 3469 | 0 |
| 16 | 3424 | 3274 | 3469 | 0 |
| 100 | 3172 | 2622 | 3062 | 407 |

폭4·16은 모든 **행**이 어떤 일치 창에 포함되지만 모든 **창**이 일치하는 것은 아니다. 폭100을 제거하고 남은407행도 한 행의 네 값은 전부 학습에 있다. 이 분할은 재출현 자료에서의 점수 일관성·날짜 간 분포 차이를 볼 수 있으나 새로운 공정 상태에 대한 일반화 성능으로 보고하지 않는다.

002에서는 날짜를 통째로 보존하면서 긴 정확 대응도 모두 같은 그룹에 넣으면 9개 날짜가 하나의 연결 성분이 됐다. 그 조건을 유지한 독립 train/test 분리는 불가능하다. 이를 피하려고 행 random split으로 되돌아가면 검증 질문만 흐려진다. 확인셋이 비면 “검증 불가”를 보고하는 편이 정확하다.

### 11.2 전처리와 점수의 사용 규칙

| 항목 | 사용할 원칙 |
| --- | --- |
| split | 원본 위치·날짜·안전 구간·반복 소속을 먼저 고정 |
| scaler/imputer/PCA/군집 | 학습 자료에만 fit. 확인 자료에는 transform/predict만 적용 |
| 원자료 결측 | Raw에는 현재 없음. 의미 없는 대체값을 추가하지 않음 |
| Robust/MAD | t의 MAD=0 등 0 분모 처리 명시. Robust라고 품질 정답에 강한 것은 아님 |
| MinMax | 학습 min/max 저장. 새 값의 범위 초과를 감추는 자동 clipping은 별도 근거 필요 |
| threshold | 학습/교정 자료에서 정하고 고정. Result 개수와 맞추어 선택하지 않음 |
| 시계열 Feature | 안전 구간별 과거값만 사용. 실시간 목표라면 centered/future window 배제 |
| 중첩창 | 분할 경계 양쪽의 공유 행 및 최대 lookback 고려; purge 후 반복 중복도 별도 감사 |
| 상태별 기준 | 상태 모형과 상태별 scaler도 학습 내에서 정의. 작은 상태는 점수 불안정성을 표시 |
| 반복 민감도 | all·고유조합 가중치·긴 반복 제외 결과를 함께 비교; 제외본 자동 채택 금지 |
| 평가 단위 | 행/창/날짜를 구분. 독립성 미확보 행 bootstrap·유의확률은 피함 |
| 모델 선택 | 기존 later는 이미 여러 EDA에서 사용됨. 최종 미관측 test로 재명명하지 않음 |

스케일은 “어느 차이를 크게 볼 것인가”를 정한다. 특히 좁은 IQR의 F/V에서 작은 단위 변화도 커질 수 있다. Standard/Robust/MinMax 결과가 다르면 점수가 높은 설정을 고르는 대신 어떤 변수와 구간이 선택을 바꿨는지 확인해야 한다.

## 12. 지금 가능한 모델링 목표와 한계

| 질문 | 현재 가능 범위 | 결과를 부를 이름 | 아직 제시할 수 없는 것 |
| --- | --- | --- | --- |
| 어떤 공정 조건이 반복되는가 | GMM/군집, 값 프로파일, 점유율·전이 | 공정 조건 군집/잠재 상태 | 제품 종류·Spot 번호 정답 |
| 어떤 행이 드물거나 관계에서 벗어나는가 | IF, 이웃 거리, 저차원 PCA 잔차, 작은 AE 비교 | 희소성/관계 이탈/재구성 점수 | 불량 확률·불량 검출 정확도 |
| 언제 수준이 바뀌는가 | 경계 내 변화점·과거창 대비 편차 | 수준 전환 후보 | 가압 개시·전극 교체 이벤트 확정 |
| 어떤 짧은 신호가 재등장하는가 | Absolute/Shape/Delta 창 검색·맥락 | 국소 모양 후보 | 제품 경계·고정 설비 주기 |
| 날짜별 품질 기록과 무엇이 함께 변하는가 | 유형별 집계 연관·날짜제외 민감도 | 탐색적 집계 연관 | 행별 3클래스 학습·인과 조건 |
| 어느 조건이 안정적인가 | 관측 빈도·변동·전환이 작은 영역 기술 | 관측상 빈번/저변동 영역 | 양품 영역·안전 범위·최적 조건 |

모델링 기준선은 먼저 Raw4와 단순 분포·거리 점수를 두고, **서로 다른 질문을 하는 소수 모델**을 비교하는 것이 타당하다. 기존 IF/GMM/PCA/AE를 활용할 수 있지만 모든 점수를 합쳐 성능 향상이라고 부를 타깃이 없다. LOF는 중복0거리 영향이 크므로 고유값 가중치 민감도를 동반해야 한다. PCA는 성분 수를 줄일 때의 잔차만 해석할 수 있다.

좋은 비지도 결과의 증거는 설정·seed·중복 처리에 대한 순위/군집 안정성, 새 구간의 분포 적용 가능성, 원본 위치로 설명할 수 있는 사례, 실제 검사자의 후속 확인이다. 군집 실루엣·BIC나 재구성 손실만으로 품질 성능을 주장하지 않는다. 서로 다른 방법이 같은 경보를 내더라도 같은 높은 가압 반복 블록에 반응한 것일 수 있다.

## 13. Feature 설계와 외부 데이터 판단

### 13.1 다음 모델링에 사용할 Feature block

| block | 후보 | 선행 조건·한계 |
| --- | --- | --- |
| Raw | F/I/V/t | 항상 비교 기준으로 유지 |
| 물리 표현 | P/E/H/R, 선택적 E/F·H/F | 단위와 proxy 명시. 상관이 큰 중복 표현의 효과는 block ablation |
| 국소 산포 | 과거창 중앙값·IQR·MAD·범위·현재 편차 | 경계 내 과거만 사용. 창 길이는 제품 수가 아님 |
| 변화 | ΔF/ΔI/ΔV/Δt, 절대변화 상위 비중·수준 전환 | 기록당 변화. timestamp 없이 초당 변화율로 해석 금지 |

| 보류 | idx mod4/16=Spot, cycle ID, 제품 ID | 공식 대응 또는 독립 검증 없이 생성하지 않음 |

새 변수가 필요할 수는 있지만, 변수 수가 적다는 이유로 무조건 추가할 단계는 아니다. 현재 변수로 분포·상호작용·국소 안정성 분석은 충분히 시작할 수 있다. 다만 **그 분석만으로 실제 불량과 안전 영역을 확정하기에는 관측되지 않은 설비·품질 정보가 부족하다.** 따라서 “Feature engineering으로 품질 문제가 전부 해결된다”와 “외부 표를 붙이면 해결된다” 모두 현재 근거를 넘는다.

### 13.2 보유 외부 `용접 데이터.csv`의 역할

이번 통합 과정에서 CSV의 구조만 별도로 재확인했다. 외부 가이드북이나 그 데이터의 과거 lag189 실험을 이번에 재검증한 것은 아니다.

| 항목 | 재계산값 |
| --- | --- |
| 전체 크기 / 결측 셀 | 739888행 × 7열 / 0 |
| PIPE_NO / 연속 block | 303 / 303 |
| PIPE 내부 라벨 혼재 | 0 |
| FIN_JGMT=1 제품 / 행 | 262 / 626092 |
| FIN_JGMT=0 제품 / 행 | 41 / 113796 |
| 연속 pair 센서5값 일치 | 369944 / 369944쌍 |

외부 CSV는 실제 제품 ID와 제품 수준의 라벨을 가진 구조를 비교하는 참고점이다. 각 PIPE의 길이가 다르며 같은 품질 라벨을 여러 센서 행에 반복 부여한 형식이다. 센서 다섯 값의 연속 pair 동일성이 전체에 있어 원행 주기 해석에도 주의해야 한다. pair를 합쳐도 독립 제품 수가 늘지 않는다.

하지만 우리 Raw에는 PIPE_NO에 해당하는 식별자가 없다. 외부의 제품당 수백~수천 행 구조를 우리 파일에 그대로 이식하거나 PIPE 라벨을 전달할 근거가 없다. 외부 공정의 용접 방식·센서 단위/배율·수집 속도·재료·검사 정의·장비 차이를 먼저 맞춰야 하며, 현재 열 이름만으로 F/I/V/t와 바로 결합하지 않는다. 사전학습도 별도 가설과 독립 검증이 필요하다.

현재 우선순위는 다른 용접 행을 대량으로 가져오는 것보다 **동일 공정의 새 기간 데이터와 제품/Spot/검사 대응 정보**를 확보하는 것이다. 외부 데이터 사용 허용 여부는 이 보고서의 검증 범위가 아니다. 앞선 대화의 규정 해석을 이번 분석이 공식 재확인한 것으로 읽지 않는다.

## 17. 재현 기준과 상세 근거

이번 기술통계는 프로젝트 공용 `.venv`의 Python/pandas/numpy/openpyxl로 CPU에서 읽기 전용 재계산했다. 기존 모델은 재학습하지 않았고 원본·실험 코드·실험 산출물은 변경하지 않았다. 표의 표시값은 약 6자리 유효숫자로 반올림하므로 마지막 자릿수의 작은 차이는 가능하다.
