## 0. 문서 목적과 상태 표기

본 실험의 목적은 YSH-010을 재튜닝하거나 실패한 gate를 억지로 통과시키는 것이 아니다. 절대 스케일과 관측단위가 다른 Mendeley RSW와 KAMP RSW를 각 domain 내부의 상대적 분포 위치로 표현했을 때, Mendeley 실제 품질 category와 관련된 label-free anomaly 방향 및 기존 supervised 방향이 KAMP의 기존 비지도 이상구조와 일관된 상대 순위를 만드는지 감사한다.

다음 네 분석을 분리한다.

1. Mendeley Source 자체 품질구조 EDA
2. Category를 학습에 사용하지 않는 fully-unsupervised anomaly detection
3. Good label로 정상 학습집단을 선택하는 Good-only/one-class anomaly detection
4. YSH-010 frozen supervised score와 비교한 뒤, Source에서 지지된 상대 방향만 KAMP rank로 transfer

상태 표기는 다음과 같이 사용한다.

- **확정:** 현재 파일, schema, 코드 또는 기존 output에서 직접 확인한 사실
- **예정:** 본 계획에서 사전 고정했으나 아직 실행하지 않은 절차
- **가설:** 결과로 검증할 해석
- **미확인:** 현재 자료만으로 확인되지 않아 물리적 사실로 쓰지 않을 내용

KAMP에는 row-level defect label이 없다. 따라서 KAMP에서 defect probability, defect rate, precision/recall, 실제 불량 행을 주장하지 않는다.

## 2. 핵심 가설과 반증 가능한 판정

### H1 — Bad의 label-free anomaly 구조

- **가설:** 최소 하나의 공통 feature family에서 Bad가 Good보다 일관되게 높은 heldout anomaly score를 갖는다.
- **반증/제약:** 3개 primary seed에서 AUROC 방향이 반복적으로 0.5 이하이거나 effect 방향이 뒤집히면 해당 모델·표현의 Bad 방향은 transfer하지 않는다.

### H2 — Explode의 별도 구조

- **가설:** Explode와 Bad의 score 구조는 같지 않을 수 있다.
- **해석 원칙:** Explode AUROC가 약 0.5라고 해서 곧바로 구현 실패로 부르지 않는다. Explode가 DOE에서 반복되는 별도 공정조건 또는 density상 희귀하지 않은 cluster라면 density-based anomaly로 나타나지 않을 수 있다.

### H3 — Raw와 Q의 안정성

- **가설:** domain 내부 상대 위치를 나타내는 Q가 Raw보다 condition split 및 seed 변화에 안정적일 수 있다.
- **제약:** Source 내부 Raw 결과가 더 강해도 절대 단위·support가 다른 KAMP에 Raw 모델을 직접 transfer하지 않는다.

### H4 — Fully-unsupervised와 Good-only의 차이

- **가설:** train-all 분포를 학습한 완전 비지도 detector와 train-Good만 학습한 one-class detector는 서로 다른 weld를 상위에 둘 수 있다.
- **금지:** 두 score를 평균하거나 ensemble score로 만들지 않는다.

### H5 — 공통 feature와 Source-only feature의 역할

- **가설:** F2 Current+Time에서 유지되는 방향만 Pressure-like 의미 불확실성에 덜 의존한다.
- **진단:** F4_SOURCE_RICH에서만 Bad 또는 Explode가 분리되면, Source-only Force/Pressure/Angle 정보가 품질구조를 설명하며 KAMP 공통 feature만으로 같은 mechanism을 transfer하는 데 구조적 한계가 있음을 뜻한다.

### H6 — KAMP 상대 rank의 reference 안정성

- **가설:** Source에서 지지된 Q-space anomaly 방향은 KAMP K1과 K2에서도 유사한 row ordering을 만든다.
- **제약:** exact repeated Raw4의 빈도 때문에 row-weighted와 unique-Raw4 관점이 달라질 수 있으므로 둘을 분리 보고한다.

## 5. 세 학습 유형의 절대 분리

### 5.2 Fully-unsupervised branch

- Q representation의 reference는 각 fold의 train-all이다.
- heldout score를 모두 생성한 뒤에만 Category를 열어 Task A/B/C를 평가한다.
- naming prefix는 U_로 고정한다.

### 5.3 Good-only/one-class branch

- Good label은 정상 training cohort를 선택하는 데 사용한다.
- Raw scaler와 Good-relative Q reference는 각 fold의 train-Good에만 fit한다.
- heldout fold의 Good/Bad/Explode는 모두 test로 유지한다.
- fully-unsupervised가 아니며 one-class, normal-only 또는 semi-supervised branch로만 부른다.
- naming prefix는 OC_로 고정한다.

## 7. Representation, mapping, feature family

### 7.1 Raw representation

Raw는 Source 내부 anomaly ordering과 Q 비교를 위한 representation이다.

- Fully-unsupervised: fold train-all에만 StandardScaler fit 후 train/test transform
- Good-only: fold train-Good에만 StandardScaler fit 후 train/test transform
- GMM, LOF, MCD는 반드시 scaled Raw를 입력으로 사용한다.
- IF도 모델 간 입력 비교 일관성을 위해 같은 scaled Raw를 사용한다.
- scaler mean/scale, fit cohort, fit sample count를 metadata로 저장한다.
- Raw Source model을 KAMP absolute 값에 직접 적용하지 않는다.

### 7.2 Q representation

Q는 YSH-010의 tie-midpoint+smoothing 식을 고정한다.

\[
Q_R(x)=\frac{L(x)+0.5T(x)+0.5}{|R|+1}
\]

- L(x): reference에서 x보다 작은 값의 수
- T(x): reference에서 x와 같은 값의 수
- Fully-unsupervised: R = fold train-all
- Good-only: R = fold train-Good
- exact tie를 midpoint로 처리하고 정확한 0/1을 피한다.
- Q에는 추가 StandardScaler를 적용하지 않는다.
- Q reference cohort, count, feature별 reference hash와 quantile summary를 저장한다.

### 7.3 Current mapping

- M1 = Sample ID 내부 Current mean
- M2 = Sample ID 내부 Current max
- M3 = Sample ID 내부 Current min

M1/M2/M3를 사전 고정해 모두 실행하며 YSH-010 결과를 보고 제거하거나 설정을 바꾸지 않는다.

### 7.4 공통 feature family

| ID | Source feature | 역할 | KAMP transfer |
|---|---|---|---|
| F1 | mapping별 Current | ablation | Q-space에서 가능 |
| F2 | mapping별 Current + Welding Time | **primary common baseline** | Q-space에서 가능 |
| F3 | Pressure-like + mapping별 Current + Welding Time | 물리 대응 가정 sensitivity | Q-space에서 가능하나 SENSITIVITY_ONLY 가능성 명시 |

Mendeley Pressure(PSI)와 KAMP weld force(bar)가 동일한 물리 제어량이라는 점은 **미확인**이다. 따라서 F3만 강한 결과를 primary transferable mechanism으로 승격하지 않는다.

### 7.5 F4_SOURCE_RICH

F4는 다음 Source-only diagnostic vector로 고정한다.

- Current_min, Current_mean, Current_max, Current_std
- Force_min, Force_mean, Force_max, Force_std
- Pressure
- Welding Time
- Angle

F4는 M1/M2/M3 mapping과 교차하지 않는 하나의 독립 family다. Raw와 해당 branch의 Q 표현에서 Source validation만 수행한다. 목적은 Mendeley category가 KAMP에 없는 Force/Angle 및 Source-rich 변수로 더 잘 설명되는지 확인하는 것이다.

**F4는 어떤 결과가 나오더라도 KAMP에 transfer하지 않는다.** F4에서만 나타나는 signal은 Source-only explanation 및 KAMP transfer limitation으로 기록한다.

Thickness A/B, NuggetDiameter, PullTest, Category, Comments, Sample ID는 F4 anomaly model feature에 포함하지 않는다.

## 8. CV와 누수 방지

### 8.1 Primary split

- splitter: label-blind GroupKFold
- n_splits: 5
- shuffle: True
- seeds: 7, 42, 2026
- group: Pressure × Welding Time × Angle의 exact condition tuple
- Category는 split 구성, transformation, model fit, GMM K 선택에 사용하지 않는다.

각 seed에서 493개 표본은 정확히 한 번 heldout되어 sample별 OOF score 하나를 가져야 한다. seed별 493개 OOF prediction을 독립적으로 평가한다.

**금지:** 3 seed의 1,479 prediction을 독립 표본처럼 합쳐 하나의 AUROC/PR-AUC를 계산하지 않는다.

결과표는 다음 구조로 저장한다.

|---|---:|---:|---:|
| 7 | 예정 | 예정 | 예정 |
| 42 | 예정 | 예정 | 예정 |
| 2026 | 예정 | 예정 | 예정 |

같은 sample의 3개 OOF score 평균과 seed별 OOF rank 평균은 cross-seed consensus diagnostic으로 저장할 수 있으나 primary metric이나 독립 표본 수로 사용하지 않는다.

### 8.2 Split sensitivity

experiments/YSH/ysh-010/outputs/source_split_manifest.csv의 frozen StratifiedGroupKFold split을 read-only sensitivity로 사용한다. 이 split에서 새 모델·transformation은 해당 fold train만으로 다시 fit하되 split membership은 바꾸지 않는다.

### 8.3 사전 확인된 fold coverage

기존 frozen manifest의 15개 fold에서:

- Task A Good vs Bad: single-class heldout fold 3개
- Task B Good vs Explode: single-class heldout fold 0개
- Task C Good vs Any: single-class heldout fold 0개

제안된 label-blind GroupKFold 15개 fold에서 사전 감사 결과:

- Task A: single-class heldout fold 3개
- Task B: single-class heldout fold 3개
- Task C: single-class heldout fold 0개

single-class fold의 fold AUROC/PR-AUC는 undefined로 기록하되 OOF score는 보존한다. per-fold metric의 억지 평균을 만들지 않고 seed별 전체 493 heldout prediction의 pooled OOF metric을 계산한다.

### 8.4 Leakage checklist

- 모든 split은 Sample ID 단위다.
- 같은 Sample ID의 raw sensor row가 train/test에 나뉘지 않는다.
- StandardScaler는 branch별 fold train cohort에만 fit한다.
- Q reference는 branch별 fold train cohort에만 fit한다.
- fully-unsupervised branch에서 Category는 score 생성 완료 전 어떤 선택에도 사용하지 않는다.
- GMM K는 train BIC만으로 정한다.
- top-k, transfer status, model selection에 KAMP Result를 사용하지 않는다.
- YSH-010/007/008 output은 수정하지 않는다.

## 9. 모델과 고정 hyperparameter

대규모 search를 하지 않는다. 다음 설정을 사전 고정한다.

| Model | 고정 설정 | anomaly score |
|---|---|---|
| Isolation Forest | n_estimators=500, max_samples=auto, contamination=auto, random_state=42 | -score_samples |
| GMM | K=1..6 중 train-fold BIC 최소, covariance_type=full, reg_covar=1e-6, n_init=10, random_state=42 | negative log likelihood |
| LOF novelty | n_neighbors=20, novelty=True, metric=euclidean | -score_samples |
| Robust distance | MinCovDet(support_fraction=None, random_state=42) | squared Mahalanobis distance |

모든 score는 **값이 클수록 anomalous**하도록 모델 정의에서 미리 고정한다. label을 본 뒤 부호를 바꾸지 않는다.

GMM은 각 fold에서 K=1..6의 성공한 fit 중 BIC 최소 K를 선택한다. 일부 K가 수치 실패하면 그 K와 오류를 기록하고 남은 K로 결정한다. 모든 K가 실패하면 해당 model specification만 MODEL_SPECIFIC_EXCLUSION로 둔다.

MCD/GMM/LOF의 numerical failure는 전체 실험 중단 사유가 아니다. model, branch, representation, feature family, mapping, seed, fold, 예외 유형을 failure log에 저장한다. AE는 이번 실험의 primary 모델에 포함하지 않는다.

## 11. Group-bootstrap CI

Group-bootstrap 95% CI는 transfer의 단일 hard gate가 아니라 **strong statistical support** 표시용이다.

- sampling unit: Pressure × Welding Time × Angle condition group
- 각 seed·task에서 condition group을 replacement로 resample
- 예정 반복: 2,000 draws, random_state=42
- 한 class만 포함된 replicate는 metric undefined로 남기고 valid/invalid replicate 수를 함께 저장
- 95% percentile CI는 valid replicate에서 계산
- lower bound > 0.5이면 strong_statistical_support=True
- CI가 0.5를 포함해도 다른 transfer 요건을 충족하면 자동 탈락시키지 않는다.

positive class가 특정 DOE group에 집중되어 CI가 불안정할 수 있음을 결과에 명시한다.

## 13. Category별 transfer 판정

판정 단위는 model × branch × representation × feature family × mapping × **category direction**이다. Bad와 Explode를 따로 판정하며 Any abnormal 성공으로 둘 중 하나의 실패를 덮지 않는다.

예:

- U_GMM_ALLQ_F2_M1 / Bad: SUPPORTED_FOR_TRANSFER
- U_GMM_ALLQ_F2_M1 / Explode: NOT_TRANSFERRED

이 경우 불량 transfer model이라고 부르지 않고 **Bad-related source anomaly direction**이라고 기록한다.

### 13.1 SUPPORTED_FOR_TRANSFER

해당 Bad 또는 Explode 방향에서 다음을 모두 만족해야 한다.

1. leakage-free pooled OOF score가 seed별 493개 완전하게 존재한다.
2. primary 3 seed 모두 AUROC > 0.5다.
3. Good 대비 anomaly score effect 방향이 primary 3 seed 모두 양의 방향이다.
4. F2 Current+Time에서도 같은 category 방향이 유지된다.
5. label-blind primary split과 frozen YSH-010 split sensitivity에서 방향이 동일하다.
6. KAMP에서 같은 차원의 Q representation을 만들 수 있다.

group-bootstrap CI lower > 0.5이면 strong statistical support flag를 추가하지만 필수 hard gate로 쓰지 않는다.

### 13.2 SENSITIVITY_ONLY

다음 중 하나면 sensitivity로 둔다.

- AUROC > 0.5이지만 CI가 0.5를 포함
- seed별 magnitude가 크게 다름
- primary와 frozen split의 차이가 큼
- F3 Pressure 포함에서만 signal 존재
- F4_SOURCE_RICH에서만 signal 존재
- Good-only → KAMP처럼 추가 normal-reference assumption이 필요
- K3 또는 pressure-like 의미 대응에 의존

### 13.3 NOT_TRANSFERRED

다음 중 하나면 transfer하지 않는다.

- 세 primary seed 중 반복적으로 AUROC ≤ 0.5
- effect 방향이 seed/split에서 뒤집힘
- OOF score 생성이 불완전
- KAMP 공통 representation이 없음
- 해당 specification에서 반복적인 numerical failure

NOT_TRANSFERRED는 정상적인 연구결과다. 특히 Explode가 density-based anomaly로 나타나지 않는 결과는 anomaly와 defect가 동의어가 아님을 보여주는 구조적 실패조건일 수 있다.

## 15. Rank와 Top-k tie 처리

midpoint rank는 다음 식을 고정한다.

\[
R(x)=\frac{L(x)+0.5T(x)+0.5}{N+1}
\]

사전 고정 threshold:

- Top 1%: rank ≥ 0.99
- Top 5%: rank ≥ 0.95
- Top 10%: rank ≥ 0.90

동점은 Excel row 순서로 강제 절단하지 않고 모두 포함한다. exact repeat의 큰 tie 때문에 actual coverage가 nominal k와 크게 다를 수 있으며 이를 오류로 숨기지 않는다.

두 candidate view를 분리한다.

1. **row-weighted view:** 11,939 row score 분포에서 rank와 threshold를 계산
2. **unique-Raw4 view:** unique Raw4 score 분포에서 rank와 threshold를 계산하고, 선택된 motif를 원 row에 다시 mapping

모든 top-k 결과에는 다음을 저장한다.

| 필드 | 의미 |
|---|---|
| nominal_top_k | 0.01 / 0.05 / 0.10 |
| rank_threshold | 0.99 / 0.95 / 0.90 |
| candidate_view | row_weighted / unique_raw4 |
| actual_row_count | tie 포함 실제 row 수 |
| actual_row_fraction | actual_row_count / 11,939 |
| unique_Raw4_count | 선택된 unique Raw4 수 |
| unique_Raw4_fraction | unique_Raw4_count / 1,574 |

동일 Raw4가 동일 specification에서 다른 score를 갖는다면 candidate를 만들기 전에 deterministic scoring sanity failure로 기록한다.

## 25. 성공/판단 기준

좋은 AUROC 숫자 자체가 실험 성공은 아니다. 다음을 분리해 답하면 성공으로 본다.

- 어떤 Mendeley category가 label-free anomaly로 나타나는가?
- 어떤 category는 공정조건 공간에서 density anomaly로 나타나지 않는가?
- Bad와 Explode를 합치는 것이 정당한가?
- supervised quality direction과 unsupervised anomaly direction은 같은가?
- Source 공통 F2 signal과 Source-only F4 signal은 무엇이 다른가?
- 어떤 category 방향만 KAMP transfer 요건을 만족하는가?
- K1/K2 및 exact-repeat weighting에 따라 rank가 얼마나 변하는가?
- 기존 KAMP GMM/AE/physical과 agreement/disagreement가 무엇인가?

negative result와 NOT_TRANSFERRED도 계획된 유효 결과로 채택한다.
