## Executive Summary

1. Source EDA와 전체 계획의 fully-unsupervised/Good-only OOF는 완료됐다.
2. 총 473,280 OOF score, 2,880 metric 행을 만들었고 960개 specification×seed 묶음 모두 493표본으로 완전하다.
3. model-specific numerical failure는 0건이다.
4. Bad는 Isolation Forest에서 강한 label-free anomaly 방향을 보였다.
5. Core Q/F2–F3/M1–M2 IF의 Bad 3-seed AUROC 중앙값은 0.9095였다.
6. Explode는 같은 구조가 아니며 같은 Core IF 중앙 AUROC는 0.5121로 거의 무작위 수준이다.
7. GMM은 Core에서 Bad와 Explode 모두 seed와 mapping에 따라 방향이 뒤집혀 transferable하지 않았다.
8. Raw IF는 Q IF보다 Source AUROC가 약간 높았지만 absolute Raw는 KAMP에 직접 transfer할 수 없다.
9. F4_SOURCE_RICH도 Bad는 강했으나 Explode는 충분히 분리하지 못했다.
10. Fully-unsupervised와 Good-only IF score 순위는 높게 연관됐지만 top set은 완전히 같지 않았다.
11. YSH-010 supervised score와 Core anomaly score는 음의 Spearman을 보여 같은 ordering이 아니었다.
12. KAMP 단계는 전체 320 category-direction 조합을 계속 실행하지 않고 YSH-011A Core로 축소했다.
13. anomaly와 defect는 동일하지 않으며 Bad/Explode를 하나의 abnormal mechanism으로 묶을 근거가 없다.

## 실제 수행 내용

- recorded file order를 101개 상대 위치로 보간해 EDA에만 사용했다.
- Raw는 fold train-only StandardScaler, Q는 branch별 train-all/train-Good reference로 변환했다.
- fully-unsupervised와 Good-only를 별도 파일과 naming으로 실행했다.
- primary label-blind GroupKFold와 frozen YSH-010 condition-group split을 각각 seed 7/42/2026으로 평가했다.
- IF, GMM BIC K1–6, LOF novelty, MCD를 Raw/Q, F1–F4, M1–M3에 실행했다.
- 세 seed를 1,479개 독립표본으로 합치지 않고 seed별 493 OOF metric을 계산했다.
- group-bootstrap CI는 strong-support 표시로만 사용했다.

## Core가 보여준 label-free 성능

아래 값은 primary label-blind GroupKFold의 seed7/42/2026 전체 Core 조합을 합친 metric 분포의 중앙/최솟값/최댓값이다. 조합은 F2/F3 × M1/M2다.

| Representation | Model | Task | AUROC median | min | max |
|---|---|---|---:|---:|---:|
| Q | IF | Bad | 0.9095 | 0.8206 | 0.9638 |
| Q | IF | Explode | 0.5121 | 0.4711 | 0.5610 |
| Q | IF | Any abnormal | 0.6695 | 0.6368 | 0.6894 |
| Q | GMM | Bad | 0.3162 | 0.1154 | 0.5958 |
| Q | GMM | Explode | 0.4726 | 0.4177 | 0.5393 |
| Raw | IF | Bad | 0.9145 | 0.8833 | 0.9638 |
| Raw | IF | Explode | 0.5467 | 0.4983 | 0.5958 |
| Raw | IF | Any abnormal | 0.6975 | 0.6540 | 0.7228 |

Bad와 Explode를 하나의 abnormal class로 합치면 IF 성능이 중간 수준으로 보이지만, 이는 강한 Bad signal과 약한 Explode signal의 평균이다.

| MCD Q | 0.9470 | 0.5355 |

Force/Pressure/Angle을 포함한 F4도 Explode를 강하게 분리하지 못했다. 따라서 Explode가 단순히 KAMP에 없는 Source-only 변수 때문에만 놓친다고 말할 근거는 약하다.

## Fully-unsupervised와 Good-only

Core seed42의 동일 specification에서 U와 OC score Spearman은 IF 0.9399–0.9731, GMM 0.5344–0.6729였다. 그러나 top10 Jaccard는 IF 0.4000–0.7500, GMM 0.0889–0.4848이었다.

즉 IF의 전반적 순위는 유사하지만 상위 후보 집합은 동일하지 않다. Good-only score를 fully-unsupervised score와 같은 것으로 취급하지 않는다.

## YSH-010 supervised와의 관계

Core seed42에서 frozen YSH-010 supervised score와 anomaly score의 Spearman은 다음 범위였다.

- IF: -0.3727 ~ -0.2874
- GMM: -0.3397 ~ -0.1642
- top5 Jaccard: IF 0.0435–0.2000, GMM 0

지도 품질 방향과 density/anomaly ordering은 같은 sample을 높게 평가하지 않았다. 이를 합산하거나 ensemble하지 않는다.

## 계획에서 변경된 점

- 전체 Source Phase 1–5는 계획대로 완료했다.
- 최초 병렬 실행은 Windows joblib core 탐지 이후 관리가 어려워져 중복 process를 정리하고 n_jobs=1로 직렬 실행했다. 모델 구조와 n_estimators는 유지했다.
- Source 실행이 과도하게 커 KAMP Phase 6–8은 이 실험에서 중단했다.
- 완료된 Source OOF를 버리지 않고 Core 조합만 YSH-011A로 이관했다.
- transfer status 후처리에서 completeness lookup의 seed 차원이 누락된 버그를 발견했다. OOF score는 변경하지 않고 판정 코드만 수정했다.

## 직접 확인된 사실

- Bad는 IF에서 강한 label-free anomaly ordering을 보인다.
- Explode는 같은 IF에서 거의 0.5 수준이며 Bad와 같은 anomaly 구조가 아니다.
- GMM density NLL은 Core category 방향에서 불안정하거나 역방향이다.
- F4 Source-rich도 Explode 분리를 크게 개선하지 않는다.
- supervised와 anomaly ordering은 다르다.

## 결과가 지지하는 해석

- Bad는 현재 Source process/sensor 공간의 희귀 이탈과 연결될 가능성이 높다.
- Explode는 density anomaly가 아니거나, 현재 요약 feature가 설명하지 못하는 품질문제일 수 있다.
- anomaly detector가 모든 실제 defect category를 공통 방식으로 잡는다는 가설은 지지되지 않는다.
