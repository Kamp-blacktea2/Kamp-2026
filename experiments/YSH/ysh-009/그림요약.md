# YSH-009 가설 감사 그림 요약

이 문서는 YSH-009에서 생성한 다섯 그림을 한곳에서 확인하기 위한 안내서다. 그림의 `component`, `score`, `candidate`는 실제 공정상태나 불량 라벨을 뜻하지 않는다.

## Figure 1. 원본 신호와 idx 고정 위상

[PNG 원본 열기](outputs/figures/figure1_raw_idx_phase_audit.png)

![대표 원본 구간의 F/I/V/t와 idx mod4/mod8/mod16](outputs/figures/figure1_raw_idx_phase_audit.png)

03-24의 대표 96행에서 F/I/V/t와 `idx mod4/mod8/mod16`을 함께 표시했다. 산술적으로 만든 위상 경계가 실제 신호 경계와 일치하는지 눈으로 감사하기 위한 그림이다. 고정 위상마다 네 신호가 함께 끊기는 명확한 경계는 보이지 않으며, 이 그림만으로 실제 cycle의 존재나 부재를 확정할 수는 없다.

## Figure 2. B 날짜의 parent exact-repeat 구조

[PNG 원본 열기](outputs/figures/figure2_b_parent_repeat_timeline.png)

![B 날짜 parent exact-repeat 전체 시계열](outputs/figures/figure2_b_parent_repeat_timeline.png)

B 날짜 5,600행의 F/I/V/t를 날짜 순서로 연결했다. 회색은 parent exact-repeat union 5,584행, 주황은 그 안의 repeat298 core 1,192행이다. 아래 띠는 고정 전체재적합 GMM의 C0/C3와 탐색 기준 `F>3 bar` 위치다. repeat298이 더 긴 반복구조의 일부이고 high-F 및 특정 component와 겹친다는 사실은 보여주지만, 이를 실제 공정 cycle이나 불량 구간이라고 부를 수는 없다.

## Figure 3. repeat298 상대위치별 AE–GMM 비교

[PNG 원본 열기](outputs/figures/figure3_repeat298_aligned_profile.png)

![repeat298 상대위치별 Raw4 AE GMM physical 정렬](outputs/figures/figure3_repeat298_aligned_profile.png)

동일한 네 occurrence를 상대위치 1~298로 정렬해 Raw4, AE total·feature error, NLL/d² percentile, conditional-z dominant variable, physical candidate support를 표시했다. 노란 영역 1–12는 AE episode이고 보라 영역 139–143은 support≥3/4의 GMM d² local episode다. AE는 motif 시작부만, NLL은 넓은 범위, d²·conditional-z·physical은 일부 국소 위치를 표시해 모델별 anomaly 정의가 다름을 보여준다. 강조 위치는 실제 불량이나 원인 라벨이 아니다.

## Figure 4. 반복 문맥별 GMM score 분포

[PNG 원본 열기](outputs/figures/figure4_gmm_distributions_by_repeat_context.png)

![A B-repeat298 B-parent-other outside-parent의 NLL과 d² 분포](outputs/figures/figure4_gmm_distributions_by_repeat_context.png)

A, B-repeat298, B-parent-other, outside-parent에서 LODO global NLL과 component 내부 d² 분포를 비교했다. repeat298은 global NLL이 높지만 d²는 parent-other와 크게 분리되지 않아 전역 희소성과 국소 이탈이 다른 구조임을 보여준다. 각 그룹의 행 수를 함께 표시했으며 outside-parent는 16행뿐이므로 안정적인 대조군으로 해석할 수 없다.

## Figure 5. 물리 signature와 일별 Result

[PNG 원본 열기](outputs/figures/figure5_physical_signatures_vs_daily_result.png)

![파임 용접부족 크랙 physical signature와 일별 Result](outputs/figures/figure5_physical_signatures_vs_daily_result.png)

파임·용접부족·크랙에 대해 YSH-007에서 고정한 physical signature의 날짜별 행 비중을 같은 날짜의 Result 기록과 나란히 표시했다. 날짜 집계 Spearman은 각각 0.272(n=8), -0.274(n=8), 0.048(n=7)이며 미기록은 0으로 채우지 않았다. 이는 날짜 수준의 탐색 비교일 뿐, 막대의 Result가 선으로 표시된 개별 행의 불량 라벨이라는 뜻은 아니다.
