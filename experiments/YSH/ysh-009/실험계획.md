# 실험계획 — YSH-009 용접 데이터 해석 가설 감사

## Metadata

- 실험 ID: YSH-009
- 담당자: YSH
- 실험 유형: EDA / VALIDATION / ERROR_ANALYSIS / DOCUMENTATION
- 관련 영역: YSH-001~008 계획·결과·기존 outputs, `docs/데이터EDA결과.md`, 공정 설명 자료, 원본 Raw/result
- 상태: 완료
- 작성일: 2026-10-01
- 장치: CPU. 새 모델 학습 없음.

## 질문

지금까지의 실험 증거로 한 행, 반복 motif, A/B, GMM/AE 후보, 세 불량 유형과 Result의 관계를 어디까지 도메인 의미로 해석할 수 있는가?

## 가설

사용자 지정 14개 가설을 개별 감사한다. 특히 물리 단위가 확인되지 않은 `row → spot → product/cycle` 승격, exact repeat를 실제 설비 cycle로 부르는 해석, component/anomaly/candidate를 불량으로 부르는 해석을 기존 증거가 지지하는지 확인한다.

## Baseline

- YSH-001~003: 순서·exact repeat·lag 및 고정 위상 감사.
- YSH-004~005: PCA/GMM/IF/LOF, 네 행 가설, train-only scaler AE와 중복 감사.
- YSH-006A/B: 물리 proxy–Result 날짜 집계, 비정확 국소 motif.
- YSH-007: Raw4 GMM의 global NLL, component 내부 d², conditional-z와 사후 physical signature.
- YSH-008: repeat298/parent 구조, 고정 YSH-005 AE와 GMM agreement 및 episode.
- `Guidebook_Welding`이라는 이름의 원문 파일은 저장소 검색에서 미확인이다. 직접 확인했다고 주장하지 않고, 원 가이드 기반으로 작성됐다고 명시된 `docs/공정방식.md`와 `data/용접방식.png`를 2차 근거로만 사용한다.

## 변경할 요소

모델·문턱·후보 정의는 변경하지 않는다. 기존 output을 행·episode·motif·date 해석 단위에 맞춰 재배열하고, 사용자 지정 Figure 1~5를 새로 그리며, 필요한 기술 집계만 정확히 재계산한다.

## 고정할 요소

- Raw4는 F/I/V/t와 기존 단위를 그대로 사용한다.
- GMM·AE score, component, threshold와 A/B 날짜 정의는 YSH-007/008 산출물을 그대로 사용한다.
- Result는 마지막의 날짜 집계 비교에만 사용한다.
- 반복 occurrence를 독립 오류 사건으로 세지 않는다.
- component, anomaly score, candidate를 defect label로 해석하지 않는다.
- 새 모델 적합, threshold 재조정, ensemble score 생성은 하지 않는다.

## 사용 데이터

- 원본: `data/Welding_Data_Set_01.xlsx`의 `Raw data`, `result`, `data set` 시트(읽기 전용).
- 문서: YSH-001~008의 `실험계획.md`/`실험결과.md`, `experiments/YSH/실험기록.md`, `docs/데이터EDA결과.md`, `docs/공정방식.md`, `data/용접방식.png`.
- 기존 산출물: 각 실험의 `outputs/`; 특히 YSH-007 행별 GMM/physical 파일과 YSH-008 repeat298/AE agreement 파일.
- 외부 용접 CSV와 `scaled_data.xlsx`는 계보·단위가 현재 Raw/result와 직접 연결되지 않으므로 그림·가설 수치 산출에 사용하지 않는다.

## 검증 방법

1. 14개 가설마다 최초 제기 실험, 검증, 핵심 수치, 제한, 정확한 관련 경로를 대조한다.
2. 기존 CSV와 원본 Excel의 행 수·Excel 행 번호·날짜·Raw4를 join 검산한다.
3. Figure 1은 대표 원본 구간의 F/I/V/t와 idx mod4/mod8/mod16을 표시하되 cycle이라 명명하지 않는다.
4. Figure 2는 B의 parent exact-repeat 구조와 repeat298, YSH-007 고정 component C0/C3, F>3 bar 표시를 겹친다. component는 상태 후보 표지로만 쓴다.
5. Figure 3은 repeat298 상대위치별 기존 AE/GMM/physical 값을 정렬하고 AE 1–12, d² local episode 139–143을 강조한다.
6. Figure 4는 A/B-repeat298/B-parent-other/outside-parent의 기존 LODO NLL·d² 분포와 n을 표시한다.
7. Figure 5는 기존 YSH-007 세 physical signature의 일별 비중과 Result 건수를 유형별로 나란히 그린다. 행별 불량 label처럼 보이지 않게 날짜 집계임을 명시한다.
8. 그림과 핵심 집계를 독립 검산해 `outputs/verification.json`에 기록한다.

## 평가 지표

- 판정 범주: `supported`, `partially_supported`, `not_supported`, `unresolved`, `untestable_with_current_data`.
- 기존 보고 수치와 새 기술 집계의 일치, 행 매핑 완전성, group별 n 합계, repeat298 4×298 대응, figure 파일 존재·크기·해상도.
- 모델 성능, defect precision/recall/AUC는 행 정답이 없어 계산하지 않는다.

## 성공/판단 기준

- 각 가설의 증거 단위와 물리 의미 사이의 간극을 명시하고, 확인된 사실과 해석을 분리한다.
- 14개 가설 표에 사용자 지정 필드를 빠짐없이 포함한다.
- 다섯 그림 아래에 각각 “그림이 말할 수 있는 것”과 “그림으로 말할 수 없는 것”을 둔다.
- 문서 마지막에 전체 요약/말할 수 있는 것/말할 수 없는 것/필요 데이터 네 섹션을 둔다.

## 데이터 누수 점검

학습은 없다. 기존 모델 결과를 그대로 읽으며 Result는 모델·threshold·그림 대상 선택에 사용하지 않는다. 다만 과거 실험의 후보 선택 자체가 탐색적이었음과 날짜 간 exact repeat 때문에 명목 날짜가 독립 재현이 아님을 감사 문서에 보존한다.
