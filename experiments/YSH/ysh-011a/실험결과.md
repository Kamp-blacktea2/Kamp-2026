## 결론

Source 493개 전체에 Category를 쓰지 않고 fit한 F2 Isolation Forest 두 개를 KAMP 11,939행에 적용했다. 네 조합의 47,756행 score가 생성됐고, 이전의 넓은 복구 실행과 score가 해당 공통 범위에서 정확히 일치했다(최대 절대차 0).

K1/K2를 바꿔도 전체 순위는 Spearman 0.8121–0.8383으로 비교적 유지됐지만 극상위 집합은 완전히 같지 않았다. 특히 M2의 Top-5% Jaccard는 0.3316이었다. M1/M2 간 순위는 Spearman 약 0.936으로 더 안정적이었다.

External IF는 기존 GMM d²와 가장 일관된 연속 overlap을 보였지만 그 크기도 중앙 Top-5% Jaccard 0.0940에 그쳤다. AE total과의 연속 상관 중앙값은 -0.0199, YSH-010 matched supervised score와는 0.0006이었다. 즉 External IF는 기존 AE·GMM·physical·supervised 중 어느 하나와 같은 ordering을 재현하지 않는다.

repeat298의 AE 1–12 위치는 External IF Top-10%에 하나도 들지 않았고, GMM local 139–143도 네 조합에서 일관된 극상위 구간이 아니었다. 반면 상대위치 51, 56, 61, 66, 102, 124, 196, 234, 255, 260, 284의 11개는 네 조합 모두 Top-5%였다. 이것은 exact repeated motif 내부의 상대적 IF 고순위 위치이지 실제 defect 위치가 아니다.

## 3. 기존 GMM/AE/physical 중 무엇과 가장 많이 겹치는가?

![Figure 3 — existing anomaly Top-5% Jaccard](outputs/figures/figure3_existing_top5_jaccard.png)

- 그림으로 말할 수 없는 것: overlap이 높은 방법이 더 정확하거나 두 방법이 실제 같은 defect를 검출한다는 것.

| 기존 방법 | Median Spearman | Median Jaccard@5% | 범위 |
|---|---:|---:|---:|
| GMM d² | 0.3415 | 0.0940 | 0.0740–0.1318 |
| conditional-z score | 0.2793 | 0.0856 | 0.0739–0.1160 |
| AE total error | -0.0199 | 0.0630 | 0.0493–0.1317 |
| GMM NLL | 0.2909 | 0.0487 | 0.0393–0.0789 |
| physical native candidate | 해당 없음 | 0.0246 | 0.0131–0.0535 |
| AE native candidate | 해당 없음 | 0.0000 | 0.0000 |

conditional-z native candidate의 Jaccard@5% 중앙값은 0.1085였지만, 이는 1,279행의 고정 native set을 각 External IF Top-5%와 비교한 값이라 동일 Top-5% 대 Top-5% 비교와 구분해야 한다.

판정: **연속 score 중에는 GMM d²가 가장 일관되게 높지만 overlap은 낮다.** 단일 최고값은 M2/K1의 GMM d² 0.1318과 AE total 0.1317로 비슷하다. 어느 기존 방법도 네 조합에서 일관되게 높은 overlap을 보이지 않았다.

## 6. 현재 결과로 실제 KAMP defect에 대해 어디까지 말할 수 있는가?

말할 수 있는 것:

- Source에서 Bad와 연관된 label-free F2 IF ordering을 KAMP Q-space에 적용한 상대 순위가 존재한다.
- 이 순위는 M1/M2에는 비교적 안정적이고 K1/K2에는 중간 이상 안정적이나, 극상위 set은 reference에 민감하다.
- 기존 GMM/AE/physical/supervised와의 overlap은 전반적으로 낮아 서로 다른 rarity 또는 deviation 구조를 본다.
- repeat298 exact occurrence에는 동일 Raw4가 동일 IF score를 받는다.

말할 수 없는 것:

- External IF Top-k가 KAMP의 실제 Bad, Explode, 파임, 용접부족, 크랙이라는 것
- Top-k의 precision, recall, defect rate
- repeat298 또는 특정 상대위치가 실제 cycle·weld·defect episode라는 것
- overlap이 낮은 이유가 어느 모델의 오류라는 것

이는 F3가 repeat298 전체의 high-F/Pressure-like 상태를 강하게 잡는다는 뜻에 가깝다. repeat298 내부의 독립적인 실제 결함을 검출했다고 해석하지 않는다.

K1/K2에서는 네 occurrence의 동일 Raw4 score range가 정확히 0이었다. K3에서는 최대 range 0.1841이었는데, K3가 Raw4 자체가 아니라 date/fold-conditioned conditional-z를 입력으로 쓰기 때문이다.
