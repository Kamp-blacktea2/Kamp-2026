## 고정 Source 모델

YSH-011에서 사용한 fully-unsupervised Isolation Forest 설정을 고정한다.

```text
n_estimators = 500
max_samples = "auto"
contamination = "auto"
random_state = 42
anomaly_score = -score_samples
```

- 모델 cohort: sensor-valid Source weld 493개
- Category 사용: final Q transformation·IF fitting에 사용하지 않음
- Feature family: F2 = Current + Welding Time만 사용
- M1: weld-level mean Current
- M2: weld-level max Current
- 최종 Source 모델: `IF_Q_F2_M1`, `IF_Q_F2_M2` 두 개
- Source Q reference: 각 모델의 493개 전체

YSH-011의 OOF label 평가는 이 방향을 채택한 근거일 뿐 final model fitting 입력이 아니다.

## KAMP representation

| ID | Q reference | 행 가중 방식 |
|---|---|---|
| K1 | KAMP 11,939행 전체 | 반복 빈도 반영 |
| K2 | 1,574개 unique Raw4 | 각 unique Raw4 동일 가중 |

K3는 사용하지 않는다. 정확한 조합은 `K1×M1`, `K1×M2`, `K2×M1`, `K2×M2` 네 개다.

각 행에 `row_index`, `excel_row`, `date`, `mapping`, `target_reference`, `external_if_score`, `external_if_rank_percentile`을 저장한다. 순위는 다음 midpoint 식을 사용한다.

\[
R(x)=\frac{L(x)+0.5T(x)+0.5}{N+1}
\]

## 고정 분석

1. Top 1/5/10%를 각각 rank ≥ .99/.95/.90으로 정의하고 동점을 모두 포함한다.
2. K1↔K2는 M1/M2별 score·rank Spearman과 Top-k Jaccard로 비교한다.
3. M1↔M2는 K1/K2별 동일 지표로 비교한다.
4. YSH-007 GMM NLL·d²·conditional-z·physical, YSH-008 AE, YSH-010의 reference/mapping 일치 supervised score와 비교한다.
5. continuous score는 Spearman과 Top-k rank Jaccard를 계산한다. 기존 binary candidate는 native candidate set과 External IF Top-k의 Jaccard만 계산한다.
6. repeat298에는 네 score를 붙여 298 상대위치별 median rank, Top 5/10% 위치, AE 1–12, GMM local 139–143, physical candidate 위치를 비교한다.
7. Result sheet는 읽지 않는다.
