## 493표본 재개 최종 결론

원본 495표본 감사 기록은 유지하고, 유효 Current/Force 관측이 0개인 Good 표본 ID 250과 252만 모델 코호트에서 제외해 493표본(Good 441, Bad+Explode 52)으로 처음부터 재실행했다. 결측값 대치는 하지 않았다.

Source Gate A~C는 Q 표현의 M1(mean current)과 M2(max current)가 통과했다. RZ 세 mapping은 condition-group CV의 일부 train fold에서 Good IQR=0이어서 사전 규칙대로 invalid 처리했고, Q/M3(min current)는 group ROC-AUC 0.5944로 Gate B를 통과하지 못했다.

따라서 KAMP에는 Gate-B 통과 source 조합인 Q/M1·Q/M2만 적용했다. K1/K2/K3를 합쳐 6개 target 조합을 계산했으며, GMM과 독립적인 K1/K2 네 조합끼리는 중앙 Jaccard 0.7937, 중앙 Spearman 0.9953으로 유사했다. 그러나 사전 정의한 primary 12조합 중 4조합만 평가할 수 있어 RZ/Q 및 M1/M2/M3 coverage가 충족되지 않았다. Gate D는 **fail**이다.

이에 따라 `transfer_consensus_candidate`는 생성 가능한 consensus로 인정하지 않고 전 행 False와 불가 사유를 저장했다. Gate E는 `not_evaluated`, 날짜별 Result 연결과 Figure 8은 미실행이다. 이것은 실행 누락이 아니라 계획된 Gate D 실패 분기다.

## 실행 결론

YSH-010은 Stage 0 source/domain audit까지 수행했으며 source 모델 학습 전에 중단했다.

External CSV의 Sample ID 250과 252는 각각 raw row가 1개뿐이고, 그 행의 `Force (N)`와 `Current (A)`가 모두 `-99`, `Comments=Communication error`다. 따라서 두 weld sample에는 집계 가능한 유효 current/force 관측이 0개다.

계획은 “communication-error row를 NaN으로 바꾼 뒤 나머지 valid row로 집계하며, valid count가 0이면 모델 단계 전에 중단”하도록 고정했다. 두 Sample ID를 임의 제외하거나 보간하지 않고 이 규칙을 적용했다.

결과적으로 다음 단계는 실행하지 않았다.

- Good/Abnormal source OOF 분류와 Gate A~C
- NuggetDiameter/PullTest 회귀와 regression corroboration gate
- KAMP domain-normalized scoring, Gate D와 consensus
- 기존 AE/GMM/physical candidate 비교와 Gate E
- repeat298 transfer profile
- CORAL sensitivity
- Result association

## 실제 수행 내용

1. `Data_RSW.csv`와 KAMP 원본의 SHA-256, 행 수, 열 schema를 확인했다.
2. External 4,186 raw sensor row를 Sample ID 기준 495 weld-level row로 재구성했다.
3. Sample ID별 metadata/target 일관성과 communication-error row를 감사했다.
4. KAMP 11,939 record의 absolute source-support와 boundary extrapolation을 negative control로 계산했다.
5. Figure 1을 생성했다.
6. 모델 단계 진입 전 valid sensor count가 0인 Sample ID를 확인하고 Stage 0을 fail로 확정했다.
7. Gate A~E와 regression gate를 모두 `not_evaluated`로 기록했다.
8. 별도 `verify.py`로 입력 hash, 집계 수, 중단 이유, 미학습·미scoring 상태를 검산했다.
