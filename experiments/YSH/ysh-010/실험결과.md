## 실행 결론

YSH-010은 Stage 0 source/domain audit까지 수행했으며 source 모델 학습 전에 중단했다.

External CSV의 Sample ID 250과 252는 각각 raw row가 1개뿐이고, 그 행의 `Force (N)`와 `Current (A)`가 모두 `-99`, `Comments=Communication error`다. 따라서 두 weld sample에는 집계 가능한 유효 current/force 관측이 0개다.

계획은 “communication-error row를 NaN으로 바꾼 뒤 나머지 valid row로 집계하며, valid count가 0이면 모델 단계 전에 중단”하도록 고정했다. 두 Sample ID를 임의 제외하거나 보간하지 않고 이 규칙을 적용했다.

결과적으로 다음 단계는 실행하지 않았다.

- Good/Abnormal source OOF 분류와 Gate A~C
- NuggetDiameter/PullTest 회귀와 regression corroboration gate
- KAMP domain-normalized scoring, Gate D와 consensus
- 기존 AE/GMM/physical candidate 비교와 Gate E
- repeat298 transfer profile
- CORAL sensitivity
- Result association

## 실제 수행 내용

1. `Data_RSW.csv`와 KAMP 원본의 SHA-256, 행 수, 열 schema를 확인했다.
2. External 4,186 raw sensor row를 Sample ID 기준 495 weld-level row로 재구성했다.
3. Sample ID별 metadata/target 일관성과 communication-error row를 감사했다.
4. KAMP 11,939 record의 absolute source-support와 boundary extrapolation을 negative control로 계산했다.
5. Figure 1을 생성했다.
6. 모델 단계 진입 전 valid sensor count가 0인 Sample ID를 확인하고 Stage 0을 fail로 확정했다.
7. Gate A~E와 regression gate를 모두 `not_evaluated`로 기록했다.
8. 별도 `verify.py`로 입력 hash, 집계 수, 중단 이유, 미학습·미scoring 상태를 검산했다.

실행 명령:

```powershell
.\.venv\Scripts\python.exe experiments\YSH\ysh-010\source_audit.py
.\.venv\Scripts\python.exe experiments\YSH\ysh-010\transfer_experiment.py
.\.venv\Scripts\python.exe experiments\YSH\ysh-010\verify.py
```

`transfer_experiment.py`는 첫 normalized Logistic fold에서 NaN 입력을 감지해 성공적으로 모델을 적합하지 못했다. 이 오류를 추적하면서 두 Sample ID의 valid count가 0임을 확인했고, 이후 Stage 0 코드가 해당 조건을 먼저 차단하도록 수정했다. 최종 재현 절차에서는 `source_audit.py`가 fail 상태를 기록한 뒤 모델 단계로 진행하지 않는다.

## 계획에서 변경된 점

- 분석 설계와 threshold/gate 기준은 변경하지 않았다.
- 최초 audit 구현이 `-99→NaN` 변환 후 valid count 0을 즉시 차단하지 못한 구현 오류를 수정했다.
- Stage 0 실패에서도 감사 가능한 행별 negative-control과 Gate 미평가 사유를 남기도록 다음 산출물을 추가했다.
  - `outputs/absolute_transfer_negative_control.csv`
  - `outputs/transfer_gate_decisions.csv`
- 계획에 없던 493-sample exclusion, imputation, 모델 재튜닝은 수행하지 않았다.

## 오류/실패

### 실행 중 관찰된 오류

최초 `transfer_experiment.py` 실행은 LogisticRegression 입력의 NaN 때문에 중단됐다. 원인은 집계 코드가 `-99`를 NaN으로 바꾼 뒤 ID 250/252에 유효 current가 하나도 없다는 사실을 model fit 직전에야 노출한 것이었다.

### 조치

- `source_audit.py`가 zero-valid sensor Sample ID를 Stage 0에서 검출하도록 수정했다.
- 최종 audit status를 `stage0_fail_source_sensor_valid_count_zero`로 고정했다.
- model/threshold/score 파일이 없음을 `verify.py`에서 확인했다.
- 두 표본을 0, median, neighbor 값으로 대치하지 않았다.
- 두 표본을 사후 임의 제외하고 493-sample 모델을 실행하지 않았다.

## 결론

YSH-010의 source/domain audit는 수행됐지만 transfer 실험은 완료되지 않았다. 중단 이유는 absolute domain mismatch가 아니다. External source의 Sample ID 250/252에 유효 current/force 측정이 전혀 없고, 계획이 이 경우 모델 전에 중단하도록 정했기 때문이다.

따라서 현재 결과로 external quality pattern의 KAMP 전이 가능성을 긍정하거나 부정할 수 없다.
