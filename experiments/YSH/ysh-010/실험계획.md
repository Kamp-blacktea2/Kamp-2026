## 1. 질문과 목표

핵심 질문은 다음과 같다.

> 외부 RSW에서 실제 Good/Bad/Explode 및 nugget diameter/pull-test strength와 연결된 공정조건 방향을 학습했을 때, 장비·범위·관측단위가 다른 KAMP에서 그 방향과 상대적으로 유사한 record를 안정적으로 찾을 수 있는가?

목표는 세 단계로 분리한다.

1. 외부 `Data_RSW.csv`를 495개 독립 weld sample로 정확히 복원하고 source 내부 quality signal을 검증한다.
2. absolute raw transfer가 부적절한 이유를 단위·support·OOD 수치로 확인하되 이를 relative transfer 중단 gate로 사용하지 않는다.
3. source와 KAMP를 각자 domain 내부에서 Robust-Z/Quantile로 정규화한 뒤, source Good 기준 abnormal 방향이 KAMP에서 안정적으로 반복되는지 확인한다.
4. normalization/reference/current mapping 안정성, 기존 YSH 후보와의 agreement, 날짜 Result와의 탐색적 관계를 모델·문턱 고정 후 확인한다.

성공은 KAMP에서 많은 행을 flag하는 것이 아니다. source signal, condition holdout, mapping/reference 안정성, 기존 후보와의 반복 가능한 교집합을 분리해 판정하는 것이 성공 조건이다.

## 2. 금지 해석과 결과 명칭

KAMP에는 row-level defect label이 없으므로 다음 표현을 사용하지 않는다.

- predicted defect
- 실제 불량 행 또는 불량 제품 수
- 파임 검출, 용접부족 검출, 크랙 검출
- KAMP nugget diameter/strength의 절대 예측값
- external Bad=KAMP 특정 불량, external Explode=KAMP 크랙이라는 대응

허용 명칭은 다음으로 고정한다.

- `external_abnormal_similarity`: source Abnormal 방향과의 연속 decision score 유사도
- `external_abnormal_like`: source OOF에서 고정한 문턱을 넘은 KAMP record flag. 실제 불량 label이 아님
- `external_small_nugget_like`: 외부에서 작은 nugget과 연결된 **상대 방향 점수**. mm 예측이 아님
- `external_low_strength_like`: 외부에서 낮은 pull strength와 연결된 **상대 방향 점수**. N 예측이 아님
- `transfer_consensus_candidate`: 사전 정의한 primary mapping/reference 조합에서 반복된 후보
- `transfer_not_stable`: mapping/reference에 따라 결과가 크게 달라지는 경우의 판정

Logistic sigmoid는 계산할 수 있지만 KAMP calibrated defect probability로 저장하거나 표시하지 않는다. KAMP primary 값은 decision function/logit 계열의 similarity score다.

## 5. 관측단위의 절대 분리

### 5.1 External RSW

**논문기재 및 CSV와 일치:** Sample ID 한 개가 실제로 제작한 RSW weld sample 한 개다. 그 안의 여러 CSV 행은 용접 중 반복 기록된 current/force sensor observation이다.

- raw rows: 4,186
- unique Sample ID: 495
- Sample ID당 raw row 수: min 1, median 9, mean 8.4565657, max 16
- current/force acquisition: 논문상 10 SPS

감사 단위는 `4,186 raw sensor rows → Sample ID aggregation → 495 weld samples`다. 승인된 두 zero-valid 표본을 제외한 모델링 단위는 493 weld samples다. raw row를 독립 observation으로 split하거나 동일 Sample ID를 train/test에 나누는 행위는 금지한다.

### 5.2 KAMP

YSH-001~009가 확인한 최소 단위는 F/I/V/t가 동시에 저장된 **11,939개의 record**다. 다음은 확인되지 않았다.

- 한 행=한 제품/Spot/weld
- 연속 4행=한 제품/cycle
- idx mod4/8/16=실제 cycle
- repeat298 또는 parent sequence=실제 한 cycle

따라서 external 495 weld와 KAMP 11,939 record를 동일 physical observation unit으로 간주하지 않는다. KAMP 출력은 `record-level external similarity`이고 제품 수·weld 수·불량 수가 아니다.

### 8.1 Category 불일치

CSV를 Sample ID 기준으로 집계하면 Good 443, Explode 31, Bad 21이다. Sensors 논문 Table 4는 Good 443, Bad 31, Expulsion 21을 기록한다. `Bad`와 `Explode/Expulsion`의 31/21이 뒤바뀐 불일치를 임의 수정하지 않는다.

Primary classification target은 다음 binary로 고정한다.

- Good=0: 443 samples
- Bad+Explode=1: 52 samples

3-class는 source label provenance가 확인되기 전까지 exploratory sensitivity일 뿐이며 KAMP score 생성에 사용하지 않는다. CSV의 `Explode`를 논문 표에 맞추려고 바꾸지 않는다.

## 10. 누수 방지와 feature/target 분리

- 모든 split은 승인된 493 Sample ID 단위다. raw sensor row 단위 split 금지.
- `Sample ID`, `Category`, `Comments`, `PullTest`, `NuggetDiameter`는 binary classification feature로 사용하지 않는다.
- regression에서 다른 quality target이나 Category를 feature로 넣지 않는다.
- source scaler, imputer, Good reference median/IQR/ECDF, threshold와 feature transformation은 각 train fold에서만 fit한다.
- KAMP에는 source scaler를 적용하지 않는다. KAMP Robust-Z/ECDF reference는 Result를 전혀 사용하지 않는 target-domain unsupervised transform으로 별도 계산한다.
- KAMP Result는 source/target model, normalization, mapping, threshold, gate 선택에 사용하지 않는다.
- 논문 image model 성능을 현재 tabular source model의 baseline으로 사용하지 않는다. 현재 실험은 image를 입력으로 쓰지 않는다.

## 11. Source feature space

### 11.1 `FULL_SOURCE`

Source 내부에서 사용 가능한 process feature의 정보량을 확인한다.

- pressure_bar
- welding_time_ms
- angle_deg
- current_min/current_mean/current_max
- force_min/force_mean/force_max
- thickness_a_mm/thickness_b_mm

Material은 AISI 1010 한 값이므로 제외한다. FULL_SOURCE는 KAMP transfer 모델이 아니라 source upper-reference다.

### 11.2 `COMMON_RAW_C1/C2/C3`

KAMP와 이름/기전상 최소 대응 가능한 source-only feature set이다.

- pressure_bar
- welding_time_ms
- current summary 하나
- thickness_a_mm
- thickness_b_mm

Current mapping은 다음을 동등하게 평가한다.

- C1=`current_mean`
- C2=`current_max`
- C3=`current_min`

## 13. Stage A — Source-only binary classification

### 13.1 모델

Primary는 `TRANSFER_CORE=[pressure-like, current, welding time]`를 source Good 기준으로 변환한 두 normalized-space Logistic이다. source와 KAMP에 같은 scaler를 fit/적용하지 않는다.

1. **RZ — Good-relative Robust-Z**
   - 각 source train fold의 Good sample에서 feature별 median/IQR을 fit한다.
   - `z_src=(x-median_Good)/IQR_Good`로 train/test를 변환한다.
   - train Good의 IQR=0이면 임의 epsilon으로 숨기지 않고 해당 fold·feature·mapping을 invalid로 기록한다. 그 조합은 Gate A~C 통과 대상으로 사용하지 않는다.
2. **Q — Good-relative Quantile**
   - 각 source train fold의 Good sample empirical CDF만 fit한다.
   - 동점은 mid-rank로 처리하고 `q=(n_< + 0.5*n_= + 0.5)/(n_Good+1)`로 고정해 정확한 0/1을 피한다.
   - test의 범위 밖 값도 같은 train-Good ECDF에서 양 끝으로 포화시킨다.

두 representation 각각에 L2 Logistic Regression을 사용한다.

- `C=1.0`, `class_weight='balanced'`, `max_iter=5000`, seed가 필요한 단계는 42
- 각 M1/M2/M3 current mapping을 별도 모델로 적합한다.
- representation별 coefficient, 원래 feature 방향, fold별 sign을 저장한다.
- `FULL_SOURCE`와 raw `COMMON_RAW`의 `StandardScaler` Logistic은 source 정보량/normalization 비교용 baseline이며 KAMP 주 transfer 모델이 아니다.

Benchmark:

- RZ/Q 각각 RandomForestClassifier, `n_estimators=500`, `class_weight='balanced_subsample'`, `min_samples_leaf=2`, `max_features='sqrt'`, `random_state=42`, `n_jobs`는 공용 CPU 제한 준수
- KAMP 주 해석과 threshold는 normalized-space Logistic의 decision direction을 사용하고 Random Forest는 source-side 비선형 benchmark로만 둔다.

현재 공용 환경에는 scikit-learn 1.6.1만 확인됐고 CatBoost/LightGBM/XGBoost는 없다. 이번 실험에서 새 패키지를 설치하거나 requirements를 변경하지 않는다.

### 13.2 split 1 — stratified sample CV

- RepeatedStratifiedKFold 5-fold × 3 repeats
- seeds 42, 7, 2026에 해당하는 고정 반복
- 목적: source sample 내부에 quality signal이 있는지 확인

### 13.3 split 2 — process-condition group CV

- group key=`(Pressure, Welding Time, Angle)`
- 실제 495 weld에는 19개 group이 있고 10개는 단일 category, 9개는 복수 category이며 group 크기 min 4, median 29, max 51이다.
- StratifiedGroupKFold 5-fold, shuffle=True, seeds 42/7/2026
- 같은 setting group을 train/test에 동시에 넣지 않는다.
- fold가 한 class만 포함하면 fold ROC-AUC/PR-AUC를 NA로 남기고 class를 임의 보정하지 않는다. 모든 sample의 global OOF metric과 계산 가능한 fold metric을 함께 보고한다.

Group CV를 KAMP transfer gate의 주 검증으로 사용한다. random split 성능만 높으면 recipe memorization 가능성을 우선 기록한다.

### 13.4 DOE leakage 감사

`Pressure × Welding Time × Angle` 19개 실제 group별로 sample/Good/Bad/Explode/Abnormal 수, abnormal rate, mean/median Nugget, mean/median PullTest를 저장한다.

추가 source baseline:

- welding-time-only Logistic
- setting-only Logistic: pressure, time, angle

COMMON_RAW/FULL_SOURCE가 이 baseline보다 무엇을 추가하는지 비교한다. label이 특정 recipe에 의해 사실상 구성된 경우 이를 quality mechanism의 독립 검증으로 해석하지 않는다.

### 13.5 평가 지표

- ROC-AUC, PR-AUC
- Balanced Accuracy, F1, Recall, Precision, Specificity
- Brier score
- confusion matrix
- abnormal prevalence=52/493도 함께 표시

반복 OOF는 Sample ID별 예측 평균으로 global metric을 계산하고 개별 repeat/fold도 보존한다. stratified CV는 sample bootstrap 1,000회, group CV는 process-condition group bootstrap 1,000회 percentile 95% CI를 계산한다. seed=42이며 양 class가 없는 bootstrap draw는 제외 수를 보고한다.

## 15. 사전 고정 Transfer Gate

아래 수치는 방향 없는 random/상수 baseline과 최소 구분을 요구하기 위한 **운영 기준**이며 보편적인 산업 성능 기준이 아니다. 결과를 본 뒤 바꾸지 않는다. Absolute range overlap은 어느 gate에도 포함하지 않는다.

### Gate A — source common-feature signal

RZ/Q × M1/M2/M3 normalized Logistic 중 적어도 한 조합의 stratified global OOF가 모두 만족해야 한다.

- ROC-AUC > 0.60
- PR-AUC > source abnormal prevalence(52/493)
- Balanced Accuracy > 0.55

실패하면 `source_signal_not_supported`로 판정한다. Stage C absolute negative control은 수행하지만 KAMP normalized abnormal similarity/flag는 생성하지 않는다.

### Gate B — unseen process-condition signal

Gate A를 통과한 조합 중 적어도 한 조합의 condition-group global OOF가 모두 만족해야 한다.

- ROC-AUC > 0.60
- PR-AUC > source abnormal prevalence
- Balanced Accuracy > 0.55
- group ROC-AUC가 같은 조합의 stratified ROC-AUC보다 0.15 초과 하락하지 않음

Gate A는 통과하고 Gate B가 실패하면 `recipe_dependent_source_signal`로 판정한다. normalized score는 source 진단 목적으로만 보존하고 KAMP `external_abnormal_like`, consensus, 기존 후보 비교, Result 비교는 만들지 않는다.

### Gate C — normalized representation confirmation

Gate B를 통과한 조합을 representation별로 감사한다.

- RZ와 Q 각각의 유효/무효 fold, coefficient sign, OOF metric을 모두 보고한다.
- 적어도 한 normalization family에서 M1/M2/M3 중 2개 이상이 Gate B를 통과해야 `normalized_source_structure_supported`로 판정한다.
- 한 current mapping만 통과하면 `mapping_sensitive_source_structure`, 어떤 family도 2개 mapping을 통과하지 못하면 Gate C fail이다.

Gate C 실패 시 KAMP normalized score는 구현 확인용 진단 산출물로만 허용하고 threshold flag, consensus, Result association은 생성하지 않는다.

### Regression corroboration gate — Nugget/PullTest별 독립 판정

Nugget/PullTest 각각 normalized `TRANSFER_CORE` Ridge condition-group OOF에서 다음을 모두 만족할 때만 해당 relative-quality score를 허용한다.

- R² > 0
- Spearman > 0.20
- Dummy 대비 MAE 5% 이상 개선

한 target의 실패가 binary abnormal transfer를 자동 중단하지는 않지만 실패 target의 `small_nugget_like`/`low_strength_like`는 생성하지 않는다.

### Gate D — KAMP transfer stability

Gate A~C를 통과한 뒤 §20의 normalization/reference/current 조합에서 score rank, top-k, threshold flag가 사전 기준을 만족하는지 판정한다. 실패하면 `transfer_not_stable`로 기록하고 consensus/Result association은 확증적 결과로 만들지 않는다.

### Gate E — 기존 YSH 후보와의 반복 구조

GMM 입력을 사용하지 않은 primary consensus와 기존 AE/GMM/physical candidate의 row·unique Raw4·episode overlap을 frozen 상태에서 기술한다.

- 독립 primary consensus가 AE/GMM/physical 세 계열 중 둘 이상과 unique Raw4 또는 episode 수준에서 1개 이상 겹치면 `cross_method_structure_observed`
- 아니면 `cross_method_structure_not_observed`
- 이 판정은 threshold/model을 되돌려 조정하는 gate가 아니며 actual defect validation도 아니다.
- GMM-relative K3가 포함된 consensus를 GMM overlap 근거로 사용하지 않는다.

DOE 감사에서 다음 중 하나면 별도로 `recipe_dominated`를 기록한다.

- Gate A 통과 후 Gate B 실패
- setting-only model과 같은 representation의 COMMON 모델 stratified ROC-AUC 차이가 0.02 이하이면서 group 성능이 Gate B 미달

모든 결정은 `outputs/transfer_gate_decisions.csv`에 metric, 기준, pass/fail 또는 observed/not-observed, 후속 허용 단계를 저장한다.

- `in_source_current_range`
- `in_source_time_range`
- `in_source_thickness_a_range`
- `in_source_thickness_b_range`

- `joint_source_support`

## 17. Stage D — Domain-wise normalized relative transfer

핵심 가설은 두 장비의 절대값이 같다는 것이 아니라, 각 RSW system 안에서 representative state로부터 벗어나는 **상대 방향과 정도**에 일부 공통성이 있을 수 있다는 것이다.

금지 구현:

```text
scaler.fit(source)
kamp = scaler.transform(kamp)
```

주 구현:

```text
source_normalized = T_source(source; source Good reference)
kamp_normalized   = T_kamp(kamp; KAMP unlabeled reference)
```

### 17.1 Source normalization

RZ — Good-relative Robust-Z:

- `z_src=(x-median(x|Good))/IQR(x|Good)`
- CV에서는 train fold의 Good만, final frozen model에서는 전체 허용 source Good만 reference로 사용
- IQR=0 처리와 invalid 조합 규칙은 §13.1을 따른다.

Q — Good-relative Quantile:

- `q_src=ECDF_Good(x)`이며 §13.1의 train-Good mid-rank 공식을 사용한다.
- 0은 Good 기준 매우 낮음, 0.5는 중앙, 1은 매우 높음에 가까운 상대 위치를 뜻한다.
- source Logistic은 representation별 `[pressure, current, time] → Abnormal`로 별도 적합한다.

### 17.2 KAMP reference와 normalization

K1 — Global:

- RZ: KAMP 전체 11,939 record의 F/I/t median/IQR
- Q: KAMP 전체 11,939 record의 feature별 mid-rank empirical CDF
- KAMP Result와 기존 candidate를 reference 산출에 사용하지 않는다.

K2 — Unique-Raw4 weighted:

- unique(F,I,V,t) pattern 하나에 동일 weight를 주어 F/I/t median/IQR과 empirical CDF를 계산한다.
- 계산한 reference를 11,939개 원행에 되돌려 적용한다.
- V는 uniqueness 정의와 사후 해석에만 쓰고 transfer feature에는 넣지 않는다.

K3 — Existing GMM-relative diagnostic sensitivity:

- YSH-007 `physical_row_followup.csv`에서 실제 확인된 `conditional_z_F`, `conditional_z_I`, `conditional_z_t`를 read-only 재사용한다. 실행 전 column명을 다시 assert한다.
- RZ sensitivity는 signed conditional-z를 사용한다.
- Q sensitivity는 각 signed conditional-z의 KAMP 전체 mid-rank ECDF를 사용한다.
- 새 GMM은 학습하지 않는다.
- 날짜별 reference model 차이 때문에 동일 Raw4도 K3 score가 달라질 수 있다. 따라서 K3는 K1/K2와 분리된 sensitivity이며 GMM과의 agreement 검증에 독립 근거로 사용하지 않는다.

K1/K2는 target 전체 분포를 사용하는 비지도·transductive reference다. Result/label은 쓰지 않지만 새 날짜가 추가되면 값이 달라질 수 있으므로 reference 통계와 input hash를 frozen artifact로 저장한다.

### 17.3 Current mapping

- M1: source `current_mean`
- M2: source `current_max`
- M3: source `current_min`
- 세 mapping을 동등하게 비교한다.
- `current_median`은 필요 시 별도 sensitivity이며 primary consensus에서 제외한다.
- external은 weld 내부 시계열 요약이고 KAMP I는 scalar이므로 어느 mapping도 물리적 대응으로 확정하지 않는다.

### 17.4 Pressure/force mapping

Primary:

- external pneumatic Pressure의 source 내부 상대 위치 ↔ KAMP `weld force(bar)`의 KAMP 내부 상대 위치
- absolute PSI↔bar 값 일치가 아니라 lower/typical/upper direction만 비교한다.

같은 pressure-like 축으로 배치해도 동일 장비의 동일 물리량이라는 뜻은 아니다. External Force(N)를 KAMP bar로 환산하지 않는다.

Secondary sensitivity:

- external force_min/mean/max의 source 내부 상대 위치 ↔ KAMP F의 내부 상대 위치
- 결과 열·표·판정을 primary pressure mapping과 분리한다.

### 17.5 Thickness와 Voltage

- KAMP thickness 0.7/0.7은 target 내 변동이 없으므로 transfer ranking core에서 제외한다.
- thickness 포함 source model은 source-only/sensitivity로만 유지한다.
- KAMP Voltage는 external model 입력 금지다.
- transfer score가 높은 KAMP record의 V 원값, 기존 `conditional_z_V`, AE feature error V와의 overlap은 모델 freeze 후 post-hoc으로만 확인한다.

### 17.6 Optional CORAL sensitivity

RZ와 Q의 비-CORAL 결과와 Gate A~D 판정을 먼저 고정한 뒤에만 수행한다.

- 각 representation×K1/K2×M1/M2/M3에 대해 KAMP normalized covariance를 source normalized covariance로 옮기는 target-to-source CORAL을 적용한다.
- 평균을 제거하고 covariance에 `1e-6 I`를 더한 뒤 target whitening/source recoloring을 수행하며, source mean을 복원한 KAMP 좌표에 frozen source Logistic을 적용한다.
- KAMP Result와 기존 candidate는 CORAL 적합에 쓰지 않는다.
- score Spearman, top-k overlap, flag Jaccard가 non-CORAL 대비 얼마나 바뀌는지만 본다.
- CORAL은 primary threshold·Gate D·`transfer_consensus_candidate`에 포함하지 않는다. MMD와 adversarial adaptation은 이번 실험에서 수행하지 않는다.

## 18. Source threshold와 KAMP flag

각 RZ/Q × M1/M2/M3 normalized Logistic의 **condition-group OOF decision score**에서 Balanced Accuracy가 최대인 cutoff를 각각 고정한다. K1/K2/K3는 같은 source representation의 모델과 cutoff를 공유하며 KAMP reference별로 cutoff를 다시 맞추지 않는다.

- threshold 후보는 OOF score의 고유값 사이 midpoint
- 동률이면 specificity가 큰 cutoff
- 다시 동률이면 cutoff 절대값이 0에 가까운 값
- threshold 선택 후 같은 source normalization으로 full source model을 fit하고, 각자 정규화된 KAMP coordinate에 decision function과 cutoff를 적용
- source stratified threshold, KAMP Result, KAMP 후보 수는 threshold 결정에 사용하지 않음

0.5 probability threshold metric도 source 참고값으로 보존하지만 KAMP primary flag는 위 group-OOF decision cutoff를 사용한다.

## 19. KAMP row scoring과 counting unit

`outputs/kamp_external_transfer_scores.csv`는 11,939행을 보존하고 다음을 포함한다.

- `excel_row`, `date`, `idx`, F/I/V/t
- source model/feature set/current mapping M1/M2/M3
- normalization `RZ/Q`, target reference K1/K2/K3, CORAL 여부
- 정규화된 pressure-like/current/time 좌표와 reference ID
- `external_abnormal_similarity`
- `external_abnormal_like`
- source raw support flags, extrapolation magnitude와 `n_features_in_support`
- transfer gate 상태
- primary consensus support와 GMM-included sensitivity support

각 조건에서 반드시 함께 보고한다.

1. flagged row count
2. flagged unique Raw4 count
3. contiguous flagged episode count

Episode는 기존 safe segment 안의 원본 Excel 연속행으로만 묶는다. 날짜, idx 불연속, singleton 격리 경계와 제외 틈을 넘어 연결하지 않는다. 표현은 `External-RSW abnormal-like records: N/11,939`로 제한한다.

## 20. Mapping/reference stability와 consensus

비-CORAL 18조합을 모두 비교한다.

- normalization: RZ, Q
- KAMP reference: K1 Global, K2 Unique-Raw4, K3 GMM-relative
- current mapping: M1 mean, M2 max, M3 min

조합별 계산:

- flagged rows, unique Raw4, episodes
- pairwise Jaccard
- score rank Spearman
- top 5%/10% row overlap; 동점 포함 개수도 병기
- repeat298 relative-position support

GMM과 독립적인 **primary stability family**는 RZ/Q × K1/K2 × M1/M2/M3의 12조합이다. K3를 primary consensus에 넣으면 이후 GMM overlap 검증이 순환적이므로 제외한다.

`transfer_consensus_candidate`는 다음을 모두 만족할 때만 True다.

- primary 12조합 중 8개 이상에서 flag
- RZ와 Q 각각 최소 한 조합에서 flag
- K1과 K2 각각 최소 한 조합에서 flag

별도 `transfer_consensus_with_gmm_sensitivity`는 전체 18조합 중 12개 이상에서 flag되고 RZ/Q와 K1/K2/K3가 각각 최소 한 번 포함될 때 True다. 이 열은 K3 영향 확인에만 쓰며 Gate E의 GMM agreement 근거로 사용하지 않는다.

Gate D primary 안정성 판정:

- 12조합 pairwise flag Jaccard 중앙값 ≥0.50이고 pairwise rank Spearman 중앙값 ≥0.70이면 `transfer_stable`
- 둘 중 하나라도 미달이면 `transfer_not_stable`

전체 18조합과 CORAL sensitivity에도 같은 통계량을 계산하되 primary Gate D를 대체하지 않는다. 이 기준은 KAMP Result를 보기 전에 고정한다. 안정적이어도 actual defect 검증은 아니다.

## 21. 기존 YSH 후보와 frozen comparison

Transfer model·reference·threshold를 전부 freeze한 뒤 다음 기존 output을 read-only join한다. GMM overlap의 주 비교에는 K3와 `transfer_consensus_with_gmm_sensitivity`를 제외하고 K1/K2 기반 `transfer_consensus_candidate`만 사용한다.

- YSH-005/YSH-008 AE total/error/candidate
- YSH-007 LODO NLL q90, d² q90, conditional-z≥2.5, physical candidates
- YSH-008 repeat298 profile, AE episode 1–12, GMM d² primary episode 139–143

각 기준과 다음을 계산한다.

- intersection, union, Jaccard
- transfer flag 기준 conditional overlap rate
- 2×2 table와 odds ratio; 셀 하나라도 5 미만이면 sparse 표시하고 확증적 해석 금지
- score rank Spearman
- unique Raw4 및 episode 수준 overlap

AE/GMM/transfer score를 하나의 ensemble score로 합치지 않는다. 높은 agreement도 defect validation으로 해석하지 않는다.

## 22. repeat298 sanity와 aligned profile

repeat298 네 occurrence는 Raw4가 완전히 동일하다.

- RZ/Q × K1/K2 deterministic transform에서는 동일 relative_position의 transfer score와 flag가 occurrence 간 정확히 같아야 한다.
- 다르면 구현 오류로 중단한다.
- K3는 날짜별 GMM reference 차이 때문에 달라질 수 있고 그 차이를 Raw4 변화로 해석하지 않는다.

relative_position 1~298에 다음을 정렬한다.

- F/I/V/t
- RZ/Q transfer score, primary consensus와 normalization/reference/current mapping support
- AE total/per-feature error와 AE episode 1–12
- NLL percentile, d² percentile과 primary episode 139–143
- max conditional-z/dominant variable
- physical candidate

AE 1–12와 GMM 139–143의 Robust-Z score, Quantile score, primary consensus 분포·순위·flag support를 사전 고정 비교한다. 어느 쪽도 실제 defect 위치로 부르지 않는다.

## 23. Stage E — Result는 마지막에만 연결

모델, feature, mapping, reference, gate, threshold, consensus를 모두 freeze한 이후에만 KAMP Result를 date로 join한다. Gate A~C 또는 Gate D가 실패하면 Result association을 수행하지 않고 사유를 남긴다. Gate E는 Result 허용 여부를 결정하거나 model/threshold를 변경하는 기준이 아니다.

날짜별 집계:

- flagged rows/share
- flagged unique Raw4
- flagged episode count
- mean/median/q90/q95 transfer score
- Result 파임/용접부족/크랙 count

NA를 0으로 채우지 않는다. 각 Spearman에 sample n을 병기하며 유형1/2는 최대 8일, 유형3은 최대 7일뿐임을 명시한다. row label, defect rate, causal relation으로 해석하지 않는다.

## 24. Relative nugget/strength direction

Regression corroboration gate를 통과한 target만 source target을 train median/IQR로 표준화한 Ridge 방향을 normalized transfer core에 적합한다. RZ와 Q 결과는 분리해 보고하고 binary abnormal score와 합치지 않는다.

- `external_small_nugget_like = -(predicted source-relative nugget direction)`
- `external_low_strength_like = -(predicted source-relative pull direction)`

두 값은 연속 우선순위 점수다. KAMP nugget mm·strength N로 역변환하지 않는다. binary flag가 필요하면 source OOF predicted direction의 상위 10% cutoff를 사전에 사용하고 `_flag` suffix를 붙이며, KAMP Result에 맞추지 않는다.

## 29. 실행 순서와 중단 분기
