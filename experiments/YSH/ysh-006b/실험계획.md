## 질문

**공정 기록의 짧은 변화 모양이 비중첩 위치에서 다시 나타나는가? 그 모양은 전후 맥락에서도 유지되며, 재등장 간격에 반복적인 구조가 있는가?**

## 검증 방법

### 1. 인덱스·anchor·검색 영역 정의

- 원본 연속 구간 내부0-based 위치 `a`를 사용한다. 저장 시 Excel 행번호와 idx를 함께 기록한다.
- burn-in100은 첫100기록을 **anchor 시작점 선정에서만** 제외한다. 첫 anchor 후보는 `a=100`, 즉 구간의101~104번째 기록이다. 첫 구간에서는 Excel102~105행이다. '100행 부근'의 구현상 정의이며 초기 시험 라벨이 아니다.
- 주 anchor 후보는 `a=100+4k`, `a+w <= floor(0.6×구간길이)`로 둔다. 앞60%에서 template를 정하고 뒤40%를 위치상 후속 확인으로 사용한다. 충분한 앞부분이 없는 구간은 anchor 없음으로 기록한다.
- 계산량 상한: 구간별 최대32개. 후보가 많으면 첫 후보를 포함해 후보 인덱스에 균등 간격32개를 결정론적으로 선택한다. 수치·Result·유사도에 따른 선별은 하지 않는다.
- anchor 시작 위상 민감도는 위 후보격자에+1/+2/+3행을 각각 적용한다. anchor 없는 조건을 숨기지 않는다.
- 상대 후보는 원본 유효 구간의 모든 `b=0,1,2,…,n−w`다. 앞100행을 검색 대상에서 지우지 않고 `target_in_initial100`으로 표시한다. 제외를 양쪽에 적용한 보조 결과도 별도 표시한다.
- 같은 구간의 `|a−b|<w`는 자기/중첩으로 제외한다. 보조 조건은 `|a−b|<2w` 제외다.
- 검색 결과는 같은 구간 앞부분(발견), 같은 구간 뒤40%(위치상 확인), 다른 원본 구간/날짜로 분리한다.
- 시간 분리 표는3월24~31일 anchor→4월2·3·7일 상대만 사용한다. 4월 날짜에서 만든 anchor는 그 표에 넣지 않는다. 이미 탐색한 자료이며 날짜 간 중복이 있으므로 외부 일반화 검증은 아니다.

### 2. 스케일·양자화·정체 창

- 공통 기준은3월24~31일의 Raw8,470행. 변수별 median/IQR을 저장하고 Result는 읽지 않는다.
- 거리 스케일 `s_j=IQR_j`. 0이면 기준 기간 std(ddof0), 그것도0이면 해당 변수를 비활성으로 처리한다. 작은 임의 epsilon으로 큰 신호를 만들지 않는다.
- 표시용 관측 해상도 q_j는 기준 기간의 정렬된 고유값 사이 양의 차이 중1e-9보다 큰 최소값이다. 원본 단위로 보고하며 센서의 공식 분해능이라고 부르지 않는다.
- window range≤q_j이면 해당 변수의 모양을 '평평/저변화'로 표시한다. shape/delta의 단변수 후보는 두 창 모두 range>q_j여야 한다. 공동 view는 두 창에서 동시에 활성인 변수가2개 이상이어야 한다.
- 비활성·저변화 창의 absolute recurrence는 보존하되 '같은 상태의 지속'으로 따로 집계한다. 공정 변화 motif의 성공 수에 넣지 않는다.
- 높은 상관 하나를 성공 기준으로 쓰지 않는다. 네 점은 짧고 양자화된 상승/유지 패턴이 우연히 많이 나올 수 있다.

### 3. 세 표현과 거리의 정확한 정의

선택 view의 변수 수를 d, 행 창을 X라고 한다. 거리의 분모는 차원 수로 고정하고 view마다 따로 비교한다.

| 표현 | 변환 | 거리 |
|---|---|---|
| Absolute | `Z_tj=(X_tj−ref_median_j)/s_j` | `sqrt(mean((Z_A−Z_B)^2))`, w×d차원 |
| Shape | `Z_tj=(X_tj−mean_window_j)/s_j` | 같은 정규화 RMSE, w×d차원 |
| Delta | `Z_tj=(X_(t+1)j−X_tj)/s_j` | 같은 정규화 RMSE, (w−1)×d차원 |

Shape는 창별 표준편차로 나누지 않아 진폭 차이를 그대로 남긴다. 평균 이동만 허용한다. 원시 단위 RMSE·최대오차·창 평균 차이·범위 비율도 저장한다.

주 거리 문턱은≤0.25, 민감도는≤0.125/0.50이다. 단위는 기준IQR당 RMSE이며 물리적 허용오차가 아니다. 각 표현·view·길이별 결과를 따로 낸다. threshold를 defect나 lag16 재현에 맞추지 않는다. Pearson/cosine은 보조 기술통계로 계산하고 평평한 벡터는NA다. 음의 상관은 동일 모양으로 뒤집어 수용하지 않는다.

### 4. exact·near-exact·모양 유사의 분리

- `exact4_raw`: 창의 네 변수 원시값이 전부 원소별 정확히 같은가? 스케일/평균제거 후0거리로 판정하지 않는다.
- `exact_view_raw`: 선택된 변수만 정확히 같은가? 전압만 같은데 다른 값이 다를 때 이를 구별한다.
- `near_exact4`: exact4가 아니며 모든 원시 차이가 변수별q_j 이하인가? 이것은 관측 격자 기반 보조 범주다.
- Shape/Delta match는 별도 플래그다. 위 범주들과 중첩될 수 있으므로 전체 합계를 독립 사건 수로 더하지 않는다.
- 비정확 모양 후보의 주 표에서는 `exact_view_raw` 상대를 제외한다. 원시값은 다르지만 중심화 모양이 정확히 같은 경우는 `shape_exact_raw_nonexact`로 명시한다.
- 긴 exact block 소속과 다른 날짜의 대응 위치를 표시한다. 같은 궤적의 복사본 여러 개를 독립 재현으로 세지 않는다.
- controlled100은 원본 창 전체가 보존된 anchor/상대만 남기는 통제다. 삭제 후 재포장하거나 보존 구간마다 burn-in을 새로 적용하지 않는다. 원본 위치의 burn-in·앞60% 규칙을 유지한다.
- 강한 통제로 확인 가능한 날짜·창이 줄면 coverage를 함께 보고한다. 부족하면 '통제 후 미확인'이지 부재 증명이 아니다.

### 5. 중복 출현을 줄이고 간격을 계산

- 같은 anchor가 인접한 여러 창과 매칭될 때, 거리 오름차순·동점은Excel 시작행 오름차순으로 정렬하고 이미 고른 창과 겹치는 상대를 제외한다. 원래 모든 match 수와 이 비중첩 출현 수를 둘 다 저장한다.
- anchor와 상대의 순서를 바꾼 쌍은 동일한 unordered pair ID로 집계한다. anchor별 검색 성적과 전체 고유 쌍 수를 구분한다.
- 모양 family의 주 정의는 **대표 anchor와 직접 문턱을 만족한 별 모양 집합**이다. A~B와 B~C가 비슷하다는 이유로 A~C까지 같다고 연결하지 않는다.
- 대표 목록은 발견 영역에서만 정한다. 비정확·비중첩 출현 수 내림차순, 중앙거리 오름차순, 원본행 순으로 선정하며 대표 anchor끼리 겹치는 후보를 제외한다. 상세 본문은 최대20개, 나머지 후보의 성적은 전수 표로 남긴다.
- 각 anchor의 출현을 같은 원본 segment 안에서 시작위치 순으로 정렬해 이웃 출현 간 gap을 구한다. 날짜/segment를 넘는 간격은 산출하지 않는다. 초·제품수로 환산하지 않는다.
- 후보 gap은 가능한 전체 범위다. 주 표의1~256행 구간과 >256 꼬리를 모두 보존한다. 최빈 gap, top3, 중앙값/IQR, gap 수, 4의 배수 비중을 낸다. gap16은 이 표가 확정된 다음 별도로 대조한다.
- 전체 lag별 가능한 유효 위치쌍 수도 계산해 큰 lag의 기회 감소를 표시한다. 이 기회보정만으로 검출/비중첩 편향이 해결됐다고 보지 않고 아래 대조를 적용한다.
- 배제폭 w가 최소 gap을 w로 만들 수 있으므로 gap4/8 peak를 곧바로 공정 주기라고 부르지 않는다.

### 6. 네 행의 앞뒤 맥락 확인

- w4에서 선택된 anchor/상대 쌍에 대해 같은 시작점의8/16행 확장과, 가능하면 앞2+중심4+뒤2의8행 맥락을 비교한다.
- 원본/통제 경계를 넘는 확장은 미산출 사유와 함께 남긴다. 확장이 불가능한 쌍을 실패0점으로 처리하지 않는다.
- w8/16 자체 검색은 w4와 같은 anchor 위치를 우선 유지하고 유효 길이만 확인한다. 별도의 좋은 시작점을 재선택해 원래 쌍의 성공처럼 보고하지 않는다.
- 양쪽 모두 변화가 있고 확장에서도 같은 문턱을 만족한 쌍의 비율을 보고한다. 중심4행만 비슷하고 맥락이 다르면 '짧은 공통 모양'으로 낮춰 표시한다.

### 7. 질문별 대조 설계

모든 대조는 seed42,100회. Result를 보지 않고 대표 목록 확정 전 대조 설정을 저장한다. p값 경쟁을 하지 않고 실측치·대조 중앙값·5/95분위·실측 순위를 보고한다.

**대조T: 짧은 모양이 순서 정보를 가지는가?**

- 같은 구간·같은 앞/뒤 영역에서 고정된32행 블록 내부의 행 순서를 무작위화한다. 네 변수는 한 행 벡터로 함께 이동해 동시 변수 관계와 블록별 분포는 유지한다.
- 후보·anchor의 위치격자와 선정 상한은 원본과 동일하다. 각 대조에서도 후보 검색과 대표 선정 규칙을 재적용해 원본에서 가장 좋은 anchor만 고른 효과를 반영한다.
- 셔플 블록 경계를 넘는 창은 대조와 원본 비교 양쪽에서 제외한다. 연속 순서의 대부분을 파괴하는 강한 대조이므로 '느린 변화까지 완전히 보존한 null'이라고 설명하지 않는다.
- 주 통계는 각 view/표현에서 최대 비정확·비중첩 출현률과 맥락 유지율이다. 다수 view에서 최대값만 골라 확증적 유의성을 주장하지 않는다.

**대조G: 간격 집중이 출현 빈도와 제외 규칙을 넘는가?**

- anchor별·segment별 유효 검색 위치와 관측된 비중첩 출현 수 N을 고정한다. 그 위치들에 무작위 우선순위를 부여하고 같은 비중첩 선택 규칙으로N개를 뽑아 gap을 계산한다.
- N개를 만들 수 없으면 해당 반복은 미산출로 기록하고 분모를 보존한다. 임계값을 바꾸거나 출현 수를 줄여 성공한 대조로 바꾸지 않는다.
- 비교 통계는 전체 후보 gap에서의 최대 점유율과4의 배수 비중이다. 관측 최빈 gap 하나를 고정한 채 그 지점만 검사해서 peak 선택 효과를 숨기지 않는다.
- 이는 조건부 위치 대조이며 센서의 전체 자기상관을 보존하는 생성모형이 아니다. 대조T와 함께 해석한다.

**선택적 대조J: 여러 변수의 동반 변화인가?**

- 변수별로 서로 다른 원형 이동을 적용해 각각의 단변수 순서 구조를 유지하며 변수 간 정렬을 흐트러뜨린다. 감긴 접합부를 넘는 창은 제외한다.
- 다변수 motif의 동반 변화만 검사한다. 단일 신호를 통째로 원형 이동하면 motif와 반복 간격이 보존되므로 단변수 motif 부재 null로 사용하지 않는다.
- 이 대조는 주 결과가 다변수 후보를 지원할 때만 보조로 수행하며 실행/미실행을 명시한다.

블록 전체 순서만 섞는 대조는 블록 내부의 짧은 motif를 보존한다. 그것만으로 짧은 motif가 우연보다 강한지 판정하지 않는다. 필요하면 긴 간격 정렬의 보조 대조로만 추가한다.

### 8. 가압 조건과의 관계는 사후 해석

- motif 목록·문턱·대표를 확정한 뒤 F>3bar run과 연결한다. >2.8/>3.2는 고정 민감도다.
- motif 출현 중 해당 조건에 완전 포함/부분 걸침/미포함 수와 전체 유효 검색 창 중 해당 조건 비중을 함께 보고한다. 단순 비율만으로 enrichment라 부르지 않는다.
- 낮은 가압 구간을 '양품/정상 영역'으로 부르지 않는다. >3bar도 불량 기준이 아니다.

## 성공/판단 기준

다음 수치는 사전 탐색 기준이다. 기계 원인을 입증하는 유의수준이 아니다.

- **국소 모양 후보:** 한 anchor 외에 동일 구간에서 비정확·비중첩 상대가3개 이상이고 저변화 창이 아니며, 최소2개의 서로 겹치지 않는 anchor에서 관찰된다. 주 문턱과 적어도 하나의 인접 민감도 문턱에서 유지한다.
- **맥락이 있는 후보:** 유효8행 확장 쌍이5개 이상이고 그중50% 이상이 같은 표현의 주 문턱을 만족한다. 미달이면 네 행 공통 모양으로만 보존한다.
- **여러 구간 모양 후보:** 최소2개 원본 구간·2개 날짜에서 보이고 긴 exact 상대 제외 후에도 남는다. 같은 복제 계보만의 출현이면 별도 재현으로 인정하지 않는다. 자료 부족 시 미확정이다.
- **주기적 재등장 후보:** 위 모양 후보 중 같은 원본 구간에서 유효 gap≥5이며 최대 gap 점유율이 대조G의95분위보다 크다. 넓은 제외폭2w에서도 단순 최소허용 gap만 따라가는 현상이 아니어야 한다. 다른 설정에서 gap이 바뀌면 후보 범위를 모두 보고한다.
- 대조T에서도 원본 대비 차이가 없으면 '일반적인 짧은 모양'으로 분류한다. 대조 결과 여러 개 중 유리한 것만 채택하지 않는다.
- 하나의 날짜에서만 남으면 국소 후보로는 보고하되 공통 기계 cycle로 부르지 않는다. 불규칙한 출현은 모양 후보와 별개로 '주기성 지지 부족'이라 기록한다.
- 물리적 동작·제품·spot 대응은 위 조건과 무관하게 미확정이다.
