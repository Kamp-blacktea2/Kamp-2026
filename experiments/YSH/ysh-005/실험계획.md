## 질문

**연속 네 공정 기록을 네 수집 지점에 대응시키는 가설이 관측 자료에서 지지되는가? 지지되는 범위에서 어떤 작업 묶음·조건 유형을 구성할 수 있으며, 그 묶음의 특징이 Result의 일별·유형별 불량 개수와 어떤 관계를 보이는가?**

이 질문에는 세 단계의 증거가 필요하다.

1. 행 순서에 네 위치의 반복 구조가 있는가?
2. 그 구조로 묶음의 경계를 특정할 수 있는가?
3. 그 묶음을 실제 제품 한 개라고 부를 수 있는가?

1을 확인해도 2와 3이 자동으로 확인되지 않는다. 따라서 각 단계의 결론을 별도로 낸다. 제품 단위가 끝내 식별되지 않아도 후보 묶음과 공정 조건 유형의 분석은 수행할 수 있다.

## 공정·관측 단위의 전제

### 공식 설명과 이번 가설

데이터 사전에 인용된 공정은 자동차 부품의 **작업자 기반 저항 점용접**이다. 공식 수집 설명은 ‘약 8초 주기로 4지점에서 센서 데이터를 수집하고, 각 지점별 약 0.072초 동안 수집’이다.

사용자가 제시한 작업 흐름은 다음의 검증 대상 가설이다.

```text
작업자가 제품/부품 위치를 잡음
    → Spot #1: 가압 → 약 72ms 통전 → 유지
    → Spot #2
    → Spot #3
    → Spot #4
    → 다음 작업/수집 cycle
```

- 72ms는 지점별 측정/통전 구간이다. 행 생성 간격으로 취급하지 않는다.
- `8 / 0.072 ≈ 111`로 제품당 기록 수를 계산하지 않는다.
- 약 8초가 제품 한 개의 생산시간인지, 4지점이 한 제품의 공간적 용접점인지, 1행이 1지점인지까지는 주어진 문서에서 확정되지 않는다.
- 한 행에 네 측정값이 있다고 해서 그 행이 가압·통전·유지 중 어느 단계인지 분류할 수 있는 것은 아니다. cycle 내부 waveform과 단계별 timestamp가 없으므로 **한 spot 내부의 가압/통전/유지 단계 복원은 이번 목표가 아니다.**
- 이번에 추정하는 것은 ‘기록의 위치 후보’와 ‘여러 기록으로 구성된 작업 묶음 후보’다. 위치 후보 0~3을 실제 Spot #1~#4로 이름 붙이는 데에는 별도 앵커가 필요하다.
- Item No는 생산품목/품번이다. 관측된 품번 하나를 여러 제품 모델로 분류하지 않는다. ‘몇 개 아이템’이라는 질문은 아래 세 가지로 분리한다.

| 구분 | 이번에 산출할 수 있는 것 |
|---|---|
| 개별 제품의 총수 | 제품-기록 매핑이 검증되지 않으면 확정 불가 |
| 네 행 작업 묶음의 후보 개수 | 시작점·경계 규칙별 개수와 미할당 행 수 |
| 묶음의 조건 유형 수 | 통계적 군집 후보와 설정 안정성. 실제 제품 모델 수가 아님 |

### Result의 역할

Result는 개별 행의 정답이 아니라 날짜/Lot 수준의 불량 개수·유형 집계다. 날짜는 연결 키로 사용할 수 있지만 제품 ID를 대신하지 않는다. 유형별 불량이 동일 제품에서 중복 집계되는지, 검사 모집단과 raw 기록 모집단이 정확히 같은지도 별도 확인이 필요하다.

**공정 데이터로 묶음·점수·문턱을 먼저 정한 뒤 Result를 대조한다.** Result 개수가 잘 맞는 시작점·군집 수·이상치 문턱을 고르는 절차는 사용하지 않는다.

## 검증 방법

### A. 생산순서의 네 위치 구조 확인

#### A1. 순서·위상 정의

- 주 위상은 `q=(idx-1) mod p`다. idx가 정수 생산순번인지 확인한 뒤 사용한다.
- 민감도는 각 원본 연속 구간 내 0-based 위치 mod p다. 서로 어떤 일정 offset으로 대응하는지 기록한다.
- 구간을 합칠 때 삭제된 행을 압축해 phase를 다시 매기지 않는다. 원본 위치·idx 기준을 유지한다.
- p=4에서 시작점만 한 칸 옮겨 phase 이름을 순환시키면 전체 위치별 분산 설명력은 그대로일 수 있다. **이 점수를 이용해 실제 제품 시작점을 선택하지 않는다.**

#### A2. p=4가 추가로 설명하는 것

- 변수별 lagged Pearson 상관과 exact match rate를 원신호·1차 차분에 계산한다. 주 lag1..64, n-lag>=100을 요구한다. 상수 비교는 NA.
- p별 phase 중앙값/IQR, 관측 수, phase 간/내 변동을 원시 단위로 제시한다. 통전시간은 연속값 통계와 함께 값별 빈도표를 제시한다.
- 먼저 네 변수 exact run 길이와 변수별 값 유지 길이를 확인한다. 두 행 반복이 네 행 효과로 보이는지 p2와 반드시 비교한다.
- 구간별 n>=200에서 앞60%를 학습, 뒤40%를 확인에 사용한다. 앞뒤 경계는 원본 순서로 정하고 어떤 Result 정보도 쓰지 않는다. 짧은 구간은 기술통계만 산출한다.
- 각 변수에 대해 다음의 단순 예측 기준을 비교한다: M0=학습 중앙값, M1=직전값을 이용한 선형 모델, M2=M1+위상 one-hot. M1/M2는 학습자료에서 전처리한 Ridge(alpha=1, intercept 포함)를 사용한다.
- p별 M2를 학습 앞부분에서만 fit한다. 확인 구간에서 MAE/RMSE와 `(M1오차-M2오차)/M1오차`를 보고한다. M1오차0이면 비율 NA.
- p4의 절대 효과와 p2 대비 추가 효과를 따로 본다. p8/16은 자유도가 더 크므로 학습 적합도 대신 확인 오차로 비교한다. p3/5는 4의 배수가 아닌 대조 후보다.
- 변수별 결론을 낸다. 네 변수 모두에 효과가 있어야 한다는 조건은 두지 않는다.

#### A3. 국소적인 연속성·반복의 영향

- 64행 블록마다 phase 라벨의 offset을 독립적으로 0..3만큼 바꾸는 대조를 100회(seed42) 만든다. 값의 순서 자체는 바꾸지 않고 전역적 phase 일관성만 흐트러뜨린다.
- 필요 시 블록32/128을 제한적 민감도로 확인한다. 최소4블록이 없는 구간은 미산출한다. 원본 경계는 넘지 않는다.
- 실제 p4의 추가 설명력이 대조 분포의 어느 위치인지 보고한다. 이미 탐색한 자료·반복 종속성을 고려해 확증적 p값으로 해석하지 않는다.
- all/controlled100을 비교하되 통제 자료는 원본 phase를 유지한다. 날짜별 수치가 같은 긴 exact block의 재등장에 의존하면 독립 재현으로 세지 않는다.

### B. 네 행 묶음과 경계 후보

#### B1. 네 시작점을 모두 만들기

- 각 연속 구간에서 첫 행의 `(idx-1) mod4`가 r이 되는 위치부터 연속4행을 묶는다. r=0/1/2/3을 모두 생성한다.
- 묶음 내부 idx 증가가 정확히1인지, 날짜가 같은지, Excel 행이 연속인지 확인한다.
- `candidate_id`는 condition/origin/r/segment/Excel_start를 포함한다. product_id라는 이름을 쓰지 않는다.
- 묶음별 시작·끝, 원본4행, 네 위치의 값, 완전/불완전 여부를 남긴다. 앞뒤 잔여 행은 버리지 않고 미할당 표에 기록한다.
- controlled100에서는 all에서 만든 원본 묶음의 네 행이 전부 보존된 경우만 비교한다. 삭제 뒤 새로 네 행을 이어 맞추지 않는다. 제외로 사라진 묶음과 잔여를 집계한다.

#### B2. 경계의 구별 가능성

- 각 r에 대해 묶음 내부 인접3회 변화와 묶음 사이1회 변화를 변수별로 비교한다. 단위가 다른 값은 훈련 scale로 조정하되 원시 차이도 함께 낸다.
- 네 위치의 중앙 프로파일, 묶음 간 프로파일 상관, 시작·끝 전이 분포, 경계 인근 가압력/전류 수준 변화의 재현을 확인한다.
- 한 변수의 특정 위상 점프가 경계처럼 보일 수 있다. 경계 점프 하나만으로 제품 시작점이라고 하지 않는다.
- 날짜/구간별로 같은 r이 반복되는지 확인한다. idx reset 규칙이 없거나 위상 대응이 바뀌면 전역 단일 경계를 강제하지 않는다.
- 특정 r이 불량 개수에 잘 맞는다는 이유로 경계로 선택하지 않는다. 경계 근거가 동등하면 네 r을 모두 후보로 유지한다.

#### B3. 개수 보고

| 출력 | 해석 |
|---|---|
| 원본 날짜별 행 수 | 공정 기록 수 |
| 각 r의 완전4행 묶음 수 | 그 가정하의 작업 묶음 수 |
| 구간별 미할당/불완전 행 수 | 관측 누락·시작위치·경계 영향 |
| r별 후보 수의 최솟값~최댓값 | 네 정렬 가정 사이의 범위이며 실제 제품 수의 신뢰구간이 아님 |

네 r의 묶음 수를 합산하지 않는다. 같은 기록을 다른 정렬로 본 결과다. `11,939/4`의 몫을 곧바로 제품 수로 보고하지 않는다. 실제 제품 수는 매핑 근거가 추가되지 않으면 미확정으로 남긴다.

### C. 전압16 및 높은 가압력 구간을 네 위치 가설과 연결

#### C1. 전압16

- 네 위치 각각에서 원본 순서대로 값을 뽑으면 인접 원본4행이 위치별1스텝이 된다. **4행 대응 가정하에서만** 원본 lag16은 해당 위치의 4묶음 간격에 대응한다.
- 위치별 lag1..8 묶음의 raw/차분 상관, 비교 쌍 수, exact 비율을 보고한다. 최소3회 반복이 들어가는 구간만 주기 해석에 사용한다.
- 길이4/8/16 원본행 프로파일과 기존 YSH-003 길이16의 국소 유사성을 비교한다. 16행 창 길이와 실제 반복 간격을 구분한다.
- 전압만 위상 구조가 있어도 후보로 인정하되 다른 세 변수의 위치별 조건을 함께 기술한다.
- 특정 위치 하나가 주로 설명하는지, 모든 위치가 같은 위상으로 움직이는지, 묶음이 아니라 느린 수준 변화인지 분리한다.

#### C2. 높은 가압력의 300행 주장

- 데이터 사전의 ‘300행’은 재현할 관찰 대상이다. 임계값을 조정해서 300을 만들지 않는다.
- 주 탐색 범위는 force>3.0bar, 민감도는 >2.8 및 >3.2bar로 미리 고정한다. 이것은 품질 이상 기준도 공식 범위 위반 기준도 아니다. 별도로 7.8~8.0bar의 고밀도 구간 분포를 기술한다.
- 연속구간 내부의 threshold run을 탐색한다. 같은 날짜의 떨어진 높은 값들을 합쳐 하나의 연속 block으로 부르지 않는다. 각 run 길이와 날짜 전체 초과 행 수를 따로 낸다.
- 각 run의 시작·끝 phase, 길이 mod4, 완전히 포함되는 네 행 묶음 수, 걸치는 부분 묶음 수를 계산한다.
- 300행 run을 확인하더라도 시작/끝이 후보 경계와 맞아야 75개의 **후보 묶음**이라고 부를 수 있다. 75제품이나 600초로 환산하지 않는다.
- 구간 길이가 4의 배수인 빈도는 일정 길이의 다른 sliding run 또는 위상 이동 대조와 비교한다. 단순 정수 나눗셈은 공정 증거가 아니다.

### D. 작업 묶음의 조건 유형과 특이성 모델

구조 근거가 약해도 민감도 탐색으로 실행하되 '가정된4행 창'으로 표기한다. 모델이 군집을 만들었다는 사실을 H1/H2의 증명으로 역사용하지 않는다.

#### D1. 표현

- S: 변수별 평균·범위(max-min), 총8개. 순서 없는 묶음 조건을 나타낸다.
- P: 네 위치×네 변수의16차원 배열. 위치 정렬 가정에 의존한다.
- 원시값과 위치별 원시 차이를 설명 표에 보존한다. 입력 열 수가 늘었다고 새 측정 정보가 추가된 것으로 해석하지 않는다.
- 물리 proxy는 필수 주 분석에 넣지 않는다. 우선 현재 네 변수와 네 위치 가설을 평가한다. 원 가이드의 전류/전압이 같은 측정구간 대표값인지 추가 확인되면 VI, V/I, VIt 등을 별도 Feature 실험으로 제안한다.

#### D2. 모델과 설정

- GMM: S를 주 입력, P를 보조 입력. K=1..4, full covariance, reg_covar=1e-3, n_init=5, max_iter=500, seed42. 학습 BIC의 최솟값, 차이2 이내에서는 작은 K를 선택한다. 상한 선택은 실제 유형 수 확정이 아니다.
- 스케일: StandardScaler 주, RobustScaler 민감도. 행 단위 scaler를 무조건16개 위치에 따로 fit하지 않는다. 표현별 학습 feature에서 fit하고 열 정의를 기록한다.
- seed7/2026은 선택K에서만 확인한다. K에 상관없이 큰 군집부터 이름을 고정하지 않고 프로파일/공통 묶음의 ARI로 비교한다.
- IF: S 입력, n_estimators300, max_samples=min(256,n_train), seed42. 학습 점수 상위5% 문턱을 고정해 확인 구간에 적용한다. 상위1%는 보조 민감도이며 Result에 맞춰 선택하지 않는다. 동점 포함 실제 선택 수를 기록한다.
- GMM은 조건 유형 수, IF는 드문 묶음의 검토 순위를 제공한다. 어느 것도 제품 종류/불량 정답이 아니다.
- LOF는 기존 exact duplicate 민감성 때문에 필수 모델에 넣지 않는다. 추가 모델을 나열해 다수결하지 않는다.
- 학습 묶음<100 또는 고유 묶음<20이면 모델 적합을 보류하고 기술통계만 산출한다. 모델이 안 되는 조건은 기록하고 나머지 조건을 진행한다.

### E. 공식 AE 구조 참조와 행/묶음 비교

- 주 raw 모델 학습은 3월24~31일, 확인은 4월2·3·7일로 분리한다. 기대 행 수는 8,470/3,469이며 실제 날짜·행 대응을 검산한다.
- AE 입력은 현재 raw의 네 변수. MinMaxScaler는 학습8,470행에서만 fit한다. 공식 과거 극단값으로 현재 raw를 스케일한 결과와 혼동하지 않는다.
- AE 구조/학습 설정은 Baseline 항목을 따른다. seed42 주, 7/2026 민감도, CPU로 학습한다. reconstruction score는 행당 네 변수 제곱오차 평균으로 고정한다.
- 문턱은 학습 score 평균+8×모집단 표준편차(ddof=0). 과거 문서의 0.08386612를 현재 모델에 그대로 사용하지 않는다. 실제 가이드 코드가 확보돼 정의가 다르면 차이를 기록한다.
- 이 구현은 수정 데이터 사전의 구조에 근거한 참조 모델이다. 원 코드의 activation 배치·전처리 시점 등을 직접 대조하지 않았다면 완전 재현이라고 쓰지 않는다.
- 새 모델 추가의 효과를 평가하려고 AE 문턱을 최적화하지 않는다. 점수 분포·flag 수·seed 안정성만 보고한다.
- 같은 날짜 분리로 행 단위 IF도 fit한다. AE/IF의 행 점수를 후보 묶음에 최대값·평균값으로 집계하여 묶음 IF와 비교한다. 최대/평균 중 하나를 Result로 골라내지 않는다.
- 학습/확인 양쪽에 존재하는 네 값 조합과 길이4/16/100 exact sequence를 감사한다. 겹치는 확인 행·묶음 비율을 함께 보고하고, 해당 부분을 제외한 잔여 결과도 산출한다.
- 제거 후 확인 표본이 충분하지 않으면 독립 일반화 평가는 불가능하다고 기록한다. 날짜가 다르다는 이유로 누수 없는 검증이라고 하지 않는다.
- 이미 이 자료로 EDA를 수행했다. 시간 분리는 미래 정보 유입을 줄이는 재현 절차이며 완전히 보지 않은 테스트셋은 아니다.
- torch 미설치 등으로 AE가 불가능하면 환경 문제를 기록하고 A~D/F는 진행한다. 설치가 가능하면 별도 환경을 사용한다. 원본이나 공유 런타임을 무단 변경하지 않는다.

### F. Result와의 연결 — 집계 단위에서만 검토

#### F1. 날짜·유형별 품질 표

- Result의 각 원문 행을 원본 그대로 보존하고 `(date, defect_type)`로 정리한다. 중복 키는 자동 합산 전에 집계 의미를 확인한다.
- 명시적0과 미기록을 구분한다. 미기록은 NA. 유형별 합을 실제 불량 제품의 중복 없는 총수라고 부르지 않는다.
- 각 날짜에서 원본 기록 수, 완전 후보 묶음 수(r별), 미할당 행 수, 학습/확인 구분을 함께 붙인다.
- 원본 기록 기반 노출량과 네 행 후보 기반 노출량을 병기한다. `count / records`, `count / candidate_groups`는 단위 가정에 따른 지표이며 검증된 불량률이 아니다.

#### F2. 대조할 지표를 사전 제한

다음 지표를 Result를 보지 않고 정의한 채 비교한다.

1. 가압력>3bar 기록 비중 및 해당 후보 묶음 비중.
2. 날짜별 전류 중앙값/IQR, 통전시간 값별 비중, 전압 차분 절댓값 중앙값.
3. 위치별 차이를 제거하기 전/후의 묶음 내 변동. 학습 위치별 중앙 프로파일을 빼서 계산한다.
4. GMM 조건 유형 점유율·혼합/전환 빈도.
5. 행 AE/IF와 묶음 IF의 score 중앙값·95분위수·학습 고정 문턱 초과 개수 및 비율.

- 유형1/2/3을 별도로 대조한다. 기재합도 보조로 제시하되 누락 유형이 있으면 '부분 합'을 표시한다.
- 날짜별 원시 표·순위 비교·Spearman 상관을 산출한다. 값이 일정하거나 유효 날짜<5이면 상관 NA.
- 학습 날짜와 확인 날짜를 표에서 분리한다. 전체 유효 날짜를 합친 상관은 사후 기술통계이며 독립 검증 점수가 아니다. 확인 기간은 3일뿐이므로 위 최소 날짜 기준에 따라 확인 기간 단독 상관은 계산하지 않고 날짜별 값만 보고한다.
- leave-one-date-out 상관 범위를 기록해 한 날짜가 관계를 지배하는지 확인한다. 이는 모델 외부 검증 점수나 신뢰구간이 아니다.
- 불량 개수와 이상치 개수가 비슷하더라도 위치가 일치하는지 알 수 없다. 일별 count MAE를 산출하면 **단위 대응을 가정한 참고 수치**로만 표시하고 모델 선택에는 쓰지 않는다.
- 날짜가9개, 품질기록은8개 날짜 수준이므로 다변량 불량 회귀·MIL/label-proportion 학습·복잡한 다중검정은 이번 범위에서 제외한다.
- 이상치 검출 수를 Result 개수로 강제하는 top-k, defect-count 기반 contamination 설정, weak label을 만들어 행별 F1을 계산하는 행위는 하지 않는다.
- Result 대응 날짜가 같아도 검사 모집단과 raw 모집단이 같은지 모르면 분자/분모의 물리적 일치를 주장하지 않는다.

## 경계·검증 설계의 공통 규칙

1. 계산상의 네 행 묶음 생성과 물리적 boundary 복원을 구분한다. 임의 offset은 위치 라벨을 회전시킬 뿐인 경우가 있으므로 경계 식별 불가능성도 정식 결론이다.
2. 기준선 선택·위상 후보 선정·클러스터 K·이상치 문턱에 Result를 사용하지 않는다. 공정 표현을 확정한 뒤 집계 품질 대조 단계를 실행한다.
3. chronological fit에서는 scaler/모델을 train에서만 학습한다. 미래 test값으로 clipping/정규화/결측 대치 기준을 정하지 않는다.
4. 행 단위 차분·묶음·학습/확인 분리가 기존 연속 구간·모순 행·반복 제외 공백을 넘지 않도록 검산한다.
5. all과 controlled100을 비교할 때 삭제로 줄어든 날짜·길이 효과를 명시한다. 통제본의 적은 표본을 곧바로 진짜 데이터 양으로 부르지 않는다.
6. p4의 우수성이 네 센서 또는 네 물리 spot의 직접 증명은 아니다. 수집·정렬 구조와 실제 공정을 구분한다.
7. 정확 반복된 날짜의 결과를 독립 재현 횟수로 합산하지 않는다. 공식8초 설명을 활용해 허위 timestamp를 생성하지 않는다.

## 성공/판단 기준

수치 문턱은 탐색용으로 사전 고정하며, 결과에 맞춰 완화하지 않는다.

- **네 위치 통계 후보:** 한 개 이상의 변수에서 확인 구간 p4 모델이 M1 대비 MAE를5% 이상 낮추고 p2 대비도 개선하며, 최소2개의 충분한 연속 구간에서 방향이 같다. 정확 반복으로 같은 구간이 다시 나온 경우는 별도 재현으로 세지 않는다. 위상 대조·차분 결과와 함께 설명한다. 미달이어도 실제4지점 부재를 입증하는 것은 아니다.
- **경계 후보:** 여러 r 중 하나의 경계/전이 특성이 구간과 표현 변경에도 일관되며, 원본과 반복 통제에서 유지된다. 원시 변화량 하나로만 우세하면 약한 후보로 표시한다. 회전 동등하면 '경계 식별 불가'.
- **제품 단위:** 별도 제품 ID·작업 로그·명시된 row-to-product 정의가 없으면 항상 미확정. 통계 문턱만으로 제품 ID를 확정하지 않는다.
- **조건 유형 후보:** 원시값으로 설명 가능한 차이와 seed/스케일 민감도 결과를 모두 낸다. ARI<0.6가 반복되면 설정 의존으로 표시한다. 모든 모델이 K=1이어도 유효한 결과다.
- **집계 품질 관계:** 유효 날짜 수·누락·개수/비율 차이·날짜제외 민감도를 제시한다. 인과관계·개별 결함 식별·공식 F1을 주장하지 않는다. 소수 날짜에서 보이는 관계는 후속 가설로만 채택한다.

최종 판정은 H1~H5별로 '관측 지지 / 제한적 후보 / 설정 의존 / 지원 부족 / 미확정'을 사용한다. 하나의 성공 점수로 모든 단계를 합치지 않는다.

## 실행 전 확정 사항 — 2026-09-23

- 사용자의 최신 확인에 따라 주 질문은 네 지점의 행 대응이며, lag 4/8/12/16은 같은 지점의 1/2/3/4묶음 간격이라는 가정으로 함께 평가한다. H3의 lag16은 이전 관찰의 보조 재검증이다. 16을 기준으로 경계·제품·주기를 정의하지 않는다.
- 원신호·차분 외에 학습 구간의 네 위치별 중앙값을 뺀 잔차에서도 lag를 비교한다. 지점 간 평균 차이와 작업 간 변동을 구분한다.
- GMM/IF의 all 및 controlled100 모두 동일한 날짜 분할을 사용한다. 통제본에 확인 날짜가 부족하면 적은 확인 표본 자체를 결과로 보고한다. 무작위 분할로 대체하지 않는다.
- 모든 시작점 r0..3, S8/P16, Standard/Robust를 유지한다. seed 민감도는 각 설정의 선택 K를 고정한다. 행 IF도 Standard/Robust와 seed42/7/2026을 비교한다.
- p별 Ridge에서 직전값과 one-hot 모두 학습자료로 StandardScaler를 fit한다. 실제 p4와 surrogate의 학습/확인 경계는 동일하다. 값의 재배열은 없다.
- 연속 구간 상대위상은 idx위상의 일정 회전이므로 예측값이 같아야 한다. 경계 식별 증거로 세지 않는다.
- 길이4/8/16 창 프로파일 상관은 인접 비중첩 창의 기술통계다. YSH-003의 복합 유사성 기준과 같다고 보고하지 않는다.
- 독립 원 가이드 PDF는 프로젝트에서 발견되지 않았다. 데이터 사전 인용과 공식 원문 직접 확인을 구분한다.
- 실행 코드는 common.py를 공통 입력 모듈로 추가한다. 숫자 표는 CSV, 해시/검산은 JSON, 본문은 Markdown으로 저장한다.
