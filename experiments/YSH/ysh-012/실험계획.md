## 질문

## 가설

### Primary — H12-2

KAMP에서 단일 External IF score보다 K1/K2 및 M1/M2에서 반복적으로 Top-5%에 드는 record를 `reference-robust external anomaly candidate`로 정의할 수 있다.

단, 실제 defect label이 없으므로 “이 후보가 단일 score보다 실제 defect에 더 정확하다”는 주장은 현재 데이터로 검증할 수 없다.

### 해석 제약으로 유지할 후속 가설

- H12-1: External IF는 기존 AE/GMM/physical/supervised와 구별되는 rarity 축일 수 있다.
- H12-3: Pressure-like feature는 defect보다 공정 regime/state를 탐지할 수 있다. 이번 실험은 F2만 사용하므로 직접 검증하지 않는다.
- H12-4: 모든 defect가 density anomaly로 나타난다고 가정하지 않는다.
- H12-5: 모델 간 낮은 overlap을 곧바로 한 모델의 오류로 해석하지 않는다.

## Baseline

- YSH-011A의 검증 완료 행별 파일 `../ysh-011a/outputs/kamp_external_if_scores.csv`
- 정확한 네 view: `M1_mean/K1`, `M1_mean/K2`, `M2_max/K1`, `M2_max/K2`
- 각 view는 11,939개 `excel_row`와 midpoint rank를 가진다.
- YSH-011A의 score/model/Q reference를 변경하거나 재학습하지 않는다.

## 후보 정의 — 실행 전에 고정

행별 네 rank에서 다음만 계산한다.

- `top5_support`: rank ≥ 0.95인 view 수, 0~4
- `median_rank`: 네 rank의 중앙값
- `rank_min`, `rank_max`, `rank_range = max-min`
- `rank_iqr`: Q3-Q1

후보 tier:

| Tier | 고정 정의 | 용도 |
|---|---|---|
| Primary strict | `top5_support == 4` | 주 reference-robust 후보 |
| Sensitivity 3-of-4 | `top5_support >= 3` | 한 view 이탈 허용 |
| Sensitivity median | `median_rank >= 0.95` | support count와 별도 확인 |
| Stable-high diagnostic | `median_rank >= 0.95` and `rank_range <= 0.05` | 높은 순위와 작은 분산 동시 확인 |

`rank_range <= 0.05`는 결과를 본 뒤 고르지 않고 Top-5% band 폭과 동일한 사전 기준으로 둔다. Score 또는 rank의 평균으로 새 anomaly score를 만들지 않는다. Tier는 defect label이 아니다.

## 분석 단위

1. Row view: KAMP 11,939행
2. Unique Raw4 view: F/I/V/t exact tuple 1,574개

동일 Raw4 반복행은 독립 오류 사건으로 세지 않는다. 모든 후보 수는 row 수와 unique Raw4 수를 함께 제시한다. 동일 Raw4가 서로 다른 consensus 결과를 받으면 검증 실패로 처리한다.

## 고정 비교

### A. 후보 규모와 안정성

- support 0~4 분포
- tier별 row 수/비율, unique Raw4 수/비율
- tier별 median rank, rank range/IQR 분포
- 네 개 단일-view Top-5% 대비 strict/3-of-4 후보 관계

### B. 기존 KAMP anomaly와의 관계

새 모델 없이 실제 기존 output만 읽는다.

- GMM NLL Top-5% rank
- GMM d² Top-5% rank
- max conditional-z Top-5% rank 및 기존 z≥2.5 candidate
- AE total error Top-5% rank 및 기존 AE candidate
- 기존 physical candidate

각 tier에 대해 overlap rows, candidate coverage, existing-set coverage, Jaccard를 계산한다. 방법들을 합친 ensemble score나 union defect score는 만들지 않는다.

### C. 공정값·날짜·motif 구조

- F/I/V/t의 tier별 median, Q25, Q75
- 전체 KAMP IQR로 나눈 candidate-vs-all median shift
- 날짜별 row 수와 날짜 내 후보 비율
- repeat298 포함 수와 298 상대위치
- 후보 exact Raw4의 반복 횟수와 등장 날짜 수

통계적 독립표본을 가정한 p-value는 계산하지 않는다.

## 평가 지표

- candidate count/fraction, unique Raw4 count/fraction
- top5 support 분포
- rank median/range/IQR
- overlap count, coverage, Jaccard
- F/I/V/t descriptive quantile와 robust median shift
- date 및 repeat298 concentration

## 성공/판단 기준

- `operationally_identified`: strict 4/4 후보가 1개 이상 존재하고 동일 Raw4 consistency 검사를 통과
- `motif_concentrated`: strict unique Raw4의 80% 이상이 repeat298에 포함되면 별도 motif 집중으로 판정
- `distinct_from_existing`: 모든 기존 방법과 strict Jaccard가 0.20 미만이면 기존 축과 구별되는 후보 구조로 기술
- `actual_reliability`: row/weld-level defect label이 없으므로 결과와 관계없이 `untestable_with_current_data`

0.20과 80% 기준은 실행 전에 고정하며 모델 선택이나 threshold 튜닝에 사용하지 않는다.

## 데이터 누수 점검

- Result sheet와 일별 defect 집계를 읽지 않는다.
- YSH-011A의 네 frozen rank 외에 새 score를 학습하지 않는다.
- existing anomaly는 결과 해석에만 사용하고 tier 정의에 사용하지 않는다.
- 날짜·repeat motif는 threshold 선택에 사용하지 않는다.
