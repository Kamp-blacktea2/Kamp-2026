## Executive Summary

1. YSH-011A의 frozen F2 External IF rank 네 개만 사용했다. 새 모델은 학습하지 않았다.
2. 주 기준인 4/4 Top-5% 후보는 277행, 39개 unique Raw4였다.
3. 277행을 독립 오류로 세면 안 된다. 후보 exact Raw4당 평균 7.10행이고 최대 반복은 30행이다.
4. strict 후보의 네 rank 중앙값 중앙치는 0.9817, rank range 중앙치는 0.0202였다.
5. repeat298은 strict 후보 중 44행, 11개 unique Raw4였다. strict unique 후보의 28.21%이므로 사전 80% motif 집중 기준에 해당하지 않았다.
6. 모든 기존 anomaly set과 strict Jaccard가 0.20 미만이었다. 최고도 conditional-z≥2.5의 0.0761이다.
7. AE native candidate 56행과 strict 후보의 교집합은 0행이다. AE total-error Top-5%와는 56행이 겹쳤다.
8. unique Raw4 기준 strict 후보는 전체보다 Current 중앙값이 2.14 IQR 낮고 time이 1.00 IQR 낮았다.
9. strict 후보는 모든 날짜에 존재하며 날짜 내 비율은 1.60%~3.75%였다. Result는 사용하지 않았다.
10. `reference-robust external anomaly candidate`는 운영적으로 식별됐지만 실제 defect에 더 신뢰할 만하다는 주장은 현재 데이터로 검증할 수 없다.

## 실제 수행 내용

- 입력: `../ysh-011a/outputs/kamp_external_if_scores.csv`
- 네 view: M1/K1, M1/K2, M2/K1, M2/K2
- 기준: 각 view의 midpoint rank ≥ 0.95
- 분석 단위: 11,939 row와 1,574 unique Raw4
- read-only 비교: YSH-007 GMM/physical, YSH-008 AE/repeat298
- 미사용: Result sheet, defect 일별 집계, 새 모델, 새 threshold 탐색, ensemble score

Score 평균을 만들지 않았다. `median_rank`, `top5_support`, `rank_range`, `rank_iqr`는 네 reasonable view에서의 안정성 설명값이다.

## 동일 Raw4 반복 감사

Strict 277행은 39개 exact Raw4로 축약됐다.

| 항목 | 값 |
|---|---:|
| Strict rows | 277 |
| Strict unique Raw4 | 39 |
| Rows / unique Raw4 | 7.10 |
| 한 strict Raw4의 최대 반복행 | 30 |
| repeat298 strict rows | 44 |
| repeat298 strict unique Raw4 | 11 |
| strict unique 중 repeat298 비율 | 28.21% |

따라서 277개의 독립 defect event가 아니라 39개 exact 공정값 motif가 여러 행과 날짜에 반복된 구조로 보는 것이 맞다. repeat298만으로 strict 후보 전체가 설명되지는 않는다.

## 공정값 특징

![Figure 2 — feature profile](outputs/figures/figure2_feature_profile.png)

- 그림이 말할 수 있는 것: unique Raw4 관점에서 각 candidate tier의 중앙값이 전체 KAMP 중앙값으로부터 몇 IQR 이동했는지 보여준다.
- 그림으로 말할 수 없는 것: 해당 이동이 defect 원인이라는 것. 특히 F와 V는 External IF의 F2 입력이 아니다.

Strict unique Raw4의 기술통계:

| 변수 | Strict median | 전체 median | 전체 IQR 기준 shift |
|---|---:|---:|---:|
| F | 2.380 | 2.330 | +0.417 |
| I | 14.590 | 14.740 | -2.143 |
| V | 2.705 | 2.703 | +0.222 |
| t | 71.000 | 72.000 | -1.000 |

F2 모델이 직접 사용한 것은 I와 t뿐이다. 따라서 주 구조는 **상대적으로 낮은 Current와 짧은 welding time** 방향이다. F와 V의 차이는 이 후보와 함께 나타난 동반 구조이며 모델 기여나 품질 원인으로 해석하지 않는다.

## 결론

`reference-robust external anomaly candidate`는 식별 가능하다. Primary strict set은 277행이지만 독립 단위로는 39개 exact Raw4 motif이며, 낮은 Current·짧은 time 방향이 핵심이다. repeat298 하나에 집중되지 않고 기존 AE/GMM/physical과도 낮게 겹친다.

따라서 이 후보표는 향후 검사 대상을 정하는 **진단 우선순위**로는 채택한다. 실제 defect 검출기 또는 consensus defect label로는 채택하지 않는다.

## 다음 행동

가장 필요한 것은 새 모델이 아니라 `excel_row → weld/product/spot → inspection result` 연결이다. 해당 key가 확보되면 strict 4/4, ≥3/4, 단일-view Top-5%를 frozen 상태로 비교해 실제 defect precision/recall과 defect-type별 coverage를 검증한다.
