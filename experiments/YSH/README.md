# YSH 개인 실험 공간

목적: YSH의 질문과 가설, 실행 과정, 결과를 보존합니다. 현재 실제 실험은 없습니다.

- 새 실험은 이 폴더에서 `EXP001_짧은이름`, `EXP002_짧은이름` 순으로 만듭니다. 아직 EXP 폴더는 생성하지 않습니다.
- 실험 시작 전에 `실험계획.md`, 종료 후 `실험결과.md`를 작성합니다.
- [실험기록](실험기록.md)의 상단 정보와 표를 갱신하고 실험당 3~4줄 요약을 남깁니다. 실패한 실험도 보존합니다.
- 실험 유형은 metadata로 기록하며 EDA / ML / DL 등의 상위 폴더를 만들지 않습니다.
- 공용화는 실험에서 검증한 뒤 `src/`로 승격합니다.

[공용 템플릿](../../templates/)과 [실험 규칙](../../docs/experiment_rules.md)을 참고합니다.
