# YSH 개인 실험 공간

목적: YSH의 질문과 가설, 실행 과정, 결과를 보존합니다. 첫 번째 실험 [ysh-001의 계획](ysh-001/실험계획.md)을 등록했습니다. 실험은 아직 실행하지 않았습니다.

- 첫 실험은 사용자 요청에 따라 `ysh-001`로 생성했습니다. 번호 001은 사용한 것으로 관리하며 재사용하지 않습니다. 후속 실험은 사용자 지시와 실험 규칙을 따릅니다.
- 실험 시작 전에 `실험계획.md`, 종료 후 `실험결과.md`를 작성합니다.
- [실험기록](실험기록.md)의 상단 정보와 표를 갱신하고 실험당 3~4줄 요약을 남깁니다. 실패한 실험도 보존합니다.
- 실험 유형은 metadata로 기록하며 EDA / ML / DL 등의 상위 폴더를 만들지 않습니다.
- 공용화는 실험에서 검증한 뒤 `src/`로 승격합니다.

[공용 템플릿](../../templates/)과 [실험 규칙](../../docs/experiment_rules.md)을 참고합니다.

다음 행동: 첫 실험계획에 따라 관측 단위·생산순서·반복 구간을 점검하고, 실행 후 결과와 실험기록을 갱신합니다.

## 공용 실행 환경

모든 실험은 프로젝트 루트의 `.venv`를 사용합니다. 실험별 `.deps` 설치를 추가하지 않습니다. [설정과 실행 방법](../../docs/environment.md)을 참고하세요.
