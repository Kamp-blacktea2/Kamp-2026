## 가설

원본의 순서가 보존된 구간에서는 연속 기록의 공정조건 변화와 상태 구간을 탐색할 수 있다. 다만 날짜·순번의 모순이나 복제된 패턴을 처리하는 방식에 따라 변화의 빈도와 모양이 달라질 수 있다. 따라서 하나의 시간순서를 확정하지 않고 비교해야 한다.

앞선 대화의 분석에서 알려진 결측·반복·날짜 불일치 및 원본/scaled의 추정 대응은 **사전 탐색에서 얻은 단서**다. 이번 실험에서 새로 발견한 독립적인 결과로 취급하지 않는다. 현재 저장소 데이터의 해시와 직접 재계산한 결과로 확인한다. 이 실험은 사전 단서가 있는 탐색·감사 실험이며, 확증적 가설검정이나 모델 성능 입증이 아니다.

## Baseline

- **ysh-001 분석 기준선:** 원시 공정변수 궤적과 과거 창 중앙값·IQR·표준편차를 사용한다. 이것은 통계적 비교 기준이며 학습된 불량예측 모델이 아니다. 이번 실험에서는 모델을 학습하지 않는다.
- **후속 이상탐지의 첫 ML 베이스라인 예정: Isolation Forest.** 개별 정답 없이 원본 4개 공정변수의 다변량 이상점수를 만드는 CPU 모델로 시작한다. 원본 변수만의 기준을 먼저 만들고, 물리 변수·순서 특징은 별도 제거실험으로 비교한다.
- 모델 학습은 이번 결과를 통해 기록 단위·반복 구간·학습/평가 분할을 정한 다음 별도 계획으로 진행한다. 정상만 모인 자료라고 가정하지 않으며, 결과는 불량확률이 아닌 이상점수다. `result`의 합계로 contamination을 확정하거나 개별 정답을 만들지 않는다.
- 후속 비교 후보는 작은 AutoEncoder다. 첫 ML 모델의 한계가 확인될 때 비교하며, 순서 근거가 없는 상태에서 LSTM을 기본 모델로 정하지 않는다. 모델·파라미터는 공식 대회 지정이 아닌 내부 제안이다.
- 모델 선택 참고: scikit-learn 공식 이상탐지 문서 https://scikit-learn.org/stable/modules/outlier_detection.html#isolation-forest
- 분석 기준선 A: 원본 파일 행 순서 그대로. 입력 Excel 행 번호를 별도 보존한다.
- 비교안 B: 날짜 → 생산순번 → 입력 행 번호의 안정 정렬. 이를 실제 작업순서라고 확정하지 않는다.
- 각 비교안에서 날짜 경계와 식별자 모순을 표시하고, 창 계산이 해당 경계를 넘지 않게 한다.
- 원본 전체와 반복 구간을 별도로 표시·제외한 민감도 분석을 비교한다. 원본 파일은 삭제·수정하지 않는다.

## 변경할 요소

1. 분석 순서: 원본 파일 순서 / 날짜·순번 정렬 후보.
2. 반복 구간 포함 여부: 전체 / 확인된 반복 구간 제외 결과를 나란히 비교.
3. 이동창: 과거 20 / 50 / 100건, 한 기록씩 이동. 현재값은 기준 통계에서 제외한다.
4. 비중첩 구간 분할: 동일한 연속 구간 시작점에서 20 / 50 / 100건씩 잘라 비교한다. 100건 내 20건 구간 5개의 반복 여부를 함께 본다.
5. 확대 분할: 100건에서 판단이 불명확한 구간은 200 / 500건으로 확대한다. 각 길이에서 어떤 구간을 확대한 이유와 실행 여부를 남긴다.

두 분석의 단위는 분·초 또는 확정된 용접 횟수가 아니라 기록 건수다. 이동창과 비중첩 분할은 서로 다른 분석으로 결과를 구분한다.

위 비교는 하나의 질문에 대한 민감도 점검이다. 새로운 모델·외부 데이터·복잡한 파생변수를 함께 추가하지 않는다.

## 고정할 요소

- 동일한 원본 파일과 해시, 전체 관측 범위.
- 원본 4개 공정변수를 주 분석 대상으로 사용한다. 컬럼명·단위는 현재 파일에서 다시 확인한다.
- 날짜 및 값의 자동 보정 없음, 결측 자동 대치 없음.
- 매칭에 따른 원본/scaled 결합을 확정 정답이나 품질라벨로 사용하지 않는다.
- 일별 정규화 진행률은 사후 탐색에만 사용한다. 실제 오전·오후 또는 온라인 예측 입력으로 해석하지 않는다.
- 도메인 설명은 관측값과 분리하며, 일반적인 장비 사양으로 개별 기록의 시각을 채우지 않는다.

## 검증 방법

공용 `docs/validation_strategy.md`는 아직 TODO 상태다. 아래는 이 첫 탐색 실험에만 적용하는 내부 점검 방법이며 공식 평가 방식이 아니다.

1. **관측 단위 확인:** `data set` 설명, 실제 키 구조, 공식 가이드에서 얻은 근거를 대조한다. 파일만으로 알 수 없는 제품당 용접점 수·가동시간은 미확정으로 남긴다.
2. **구조 감사:** 모든 시트의 결측·고유값·전체행 중복, 공정변수 조합 반복, 날짜+순번 중복, 순번의 누락·역전·재시작을 계산한다. 원본 위치를 보존해 문제를 추적한다.
3. **일별 집계:** 관측 행 수, 고유 순번 수, 변수 분포를 계산한다. `result`는 날짜·유형별 원래 기록을 보존하고, 수량 해석을 가정하는 집계와 확정된 사실을 구분한다. 결측 집계는 0으로 채우지 않는다.
4. **순서 비교:** 기준선 A와 비교안 B의 원시 궤적, 과거 창 통계, 급변 후보를 비교한다. 정렬로 모순이 가려지지 않도록 원래의 위치·날짜·순번도 함께 보여준다.
5. **반복 구간:** 순서가 같은 공정변수 블록을 해시 등으로 탐색하고 실제 값으로 재확인한다. 사전 단서인 298행 반복도 다시 검증한다. 반복된 개별 값과 긴 연속 블록의 반복을 구분한다.
6. **생산순서 특징:** 현재값 이전의 20/50/100건에 대해 중앙값·IQR·표준편차와 현재값의 편차를 계산한다. 각 창은 이전 관측만 사용하고 창이 부족한 구간은 결측으로 표시한다. IQR=0인 구간은 나눗셈을 하지 않고 별도 상태로 표시한다.
7. **변화 후보:** 각 변수의 직전 기록 대비 절대 변화량을 계산하고 각 날짜·구간의 상위 1%를 사후 검토 후보로 표시한다. 동률은 모두 포함하고 해당 변수·구간의 변화량이 모두 0이면 후보 0건으로 처리한다. 이 기준은 불량 임계값이 아니며 결과에 맞춰 변경하지 않는다.
8. **시간축 가능성:** 실제 타임스탬프·수집 주기·작업 로그가 확인되면 그 근거와 범위에서만 경과시간 해석을 허용한다. 날짜와 건수만으로 임의 시각을 생성하지 않는다.

## 구간 분할 및 그래프 계획

### A. 이동창 — 최근 공정 수준에서 얼마나 벗어나는가

- 변수별 원시값 위에 직전 20/50/100건의 중앙값과 25~75% 범위를 표시한다. 변동성 및 현재값 편차는 별도 그래프로 만든다.
- 날짜 경계, 순서가 불명확한 지점, 반복 구간 제외로 생긴 틈을 넘지 않는다. 창이 부족하면 계산하지 않는다.

### B. 비중첩 분할 — 짧은 패턴이 큰 구간 안에서 반복되는가

- 확인 가능한 각 연속 구간의 첫 기록을 공통 시작점으로 삼는다. 20건은 1~20, 21~40, 41~60처럼 자른다. 50·100건도 같은 시작점에서 각각 분할한다.
- 각 변수의 20/50/100건 블록을 빠짐없이 찾아볼 수 있도록 페이지별 작은 그래프와 블록 위치 목록을 만든다. 길이가 다른 블록을 무리하게 한 장에 겹치지 않는다.
- 각 완전한 100건 블록은 전체 궤적에 20건 경계를 표시하고, 내부 20건짜리 5개 구간을 별도 패널 및 구간 내 순서 1~20 기준 중첩 그래프로 비교한다.
- 가압력·전류·전압·통전시간은 별도 패널로 표시한다. 동일 변수의 직접 비교 패널에서는 세로축 범위를 고정한다. 전체 범위 그림과 필요한 확대 그림을 구분해 축 범위를 표시한다.
- 원시값 비교를 먼저 하고, 모양 비교용으로 각 블록의 평균만 뺀 그래프를 추가한다. 블록마다 표준편차로 나눠 크기 차이를 없애는 정규화는 기본값으로 쓰지 않는다.
- 각 블록에 날짜, 입력 Excel 행 번호, 분석 내 순서, 분할 길이, 반복 구간 여부를 기록한다. 마지막 불완전한 블록은 실제 길이를 표시하며 완전한 블록과 같은 길이의 유사도 계산에서 제외한다. 패딩·보간하지 않는다.

### C. 200·500건 확대와 경계 민감도

- 100건에서 반복이 보이지 않거나, 다섯 개 20건 블록의 수준·모양 비교가 엇갈려 판단하기 어려운 구간을 확대 대상으로 기록한다. 시각 판단에 따른 탐색임을 명시하고 판정 근거를 남긴다.
- 대상 100건 블록을 포함하는 동일 연속 구간의 200건 블록을 먼저 보고, 여전히 불명확하면 500건 블록을 확인한다. 시작점은 해당 연속 구간 시작점에 정렬한다. 구간이 짧으면 가능한 길이와 부족 사유를 표시한다.
- 날짜·순번 모순·삭제된 반복 구간 경계를 넘어 기록을 이어 붙여 200·500건을 만들지 않는다.
- 20건 주기를 미리 가정하지 않는다. 경계 때문에 패턴이 가려지는지 보기 위해 대상 연속 구간에서 시작점을 10건 이동한 분할도 민감도 그림으로 제공한다. 원래 시작점 결과를 함께 보존한다.
- 추가 탐색으로 충분히 긴 연속 구간에서 기록 간격별 자기상관을 볼 수 있다. 추세·상수 구간·복제 블록에 의한 유사성을 실제 설비 주기로 확정하지 않는다. 주기 단위는 기록 수다.
- 이미 알려진 날짜 간 298행 반복은 별도 비교 대상으로 표시한다. 같은 데이터 블록의 반복과 실제 운전 주기의 반복을 구분한다.

### 그래프 산출물

- `rolling/`: 변수별 20/50/100건 과거 창 기준과 현재 편차.
- `blocks/20`, `blocks/50`, `blocks/100`: 각 길이별 원시값 블록 패널과 위치 목록.
- `nested_20_in_100/`: 100건 전체 + 내부 20건 5개 패널 + 원시값/평균 제거 중첩 비교.
- `expanded/200`, `expanded/500`: 확대 대상의 그래프와 선택 이유. 미실행이면 미실행 사유 기록.
- `summary/`: 순서 후보 및 반복 구간 처리에 따른 비교와 반복 판단 근거.
- 위 폴더는 로컬 산출물 `outputs/YSH/ysh-001/` 아래에 실행 시 생성한다. 현재 계획 수정 단계에서는 생성하지 않는다.

## 평가 지표

- 날짜별 관측 행 수, 고유 생산순번 수, 날짜+순번 중복 수, 순번 역전 및 누락 수.
- 공정변수 고유 조합 수와 반복 비율: 중복 건수는 동일 조합의 첫 번째 관측을 제외한 추가 행 수로 정의한다.
- 반복 연속 구간의 길이·출현 수·위치, 동일 블록이 서로 다른 날짜에 등장하는지.
- 순서 A/B 사이 변경되는 인접 행 쌍의 수와 비율.
- 20/50/100건 창별 유효 관측 수, 변화 후보 수·위치 및 순서별 차이. 변화 후보의 비교는 입력 행 번호를 기준으로 한다.
- 반복 구간 포함/제외 시 분포·변화 후보의 차이. 제외로 생긴 틈을 이어서 하나의 연속 구간으로 취급하지 않는다.
- 날짜별 결과 집계가 있는 날짜 수와 누락 유형. 정의가 확인되지 않은 전체 불량률은 산출하지 않는다.
- 분할 길이별 완전/불완전 블록 수, 확대 대상 수와 사유, 100건 내부 20건 블록 간 원시값 RMSE·평균 제거 RMSE·상관계수. 같은 변수·같은 길이끼리 비교하고 변수 단위가 다른 RMSE를 합산하지 않는다. 상수 블록의 상관계수는 계산 불가로 표시한다.
- 반복 판단은 값 수준과 모양을 별도로 서술한다. 높은 상관계수 하나를 반복 주기나 실제 공정 정상의 증거로 사용하지 않는다. 최적 구간만 골라 전체를 대표하는 것처럼 제시하지 않는다.
- **F1, 개별 불량 재현율, 불량확률, 시간당 생산량은 이번 실험의 평가 지표가 아니다.**

## 성공/판단 기준

- 성공은 좋은 모델 점수가 아니라, 다음 세 판단 중 어느 것이 근거에 맞는지 기록하는 것이다.
  - **생산순서 분석 진행:** 순서의 근거가 확인되고 모순 구간을 식별할 수 있다. 확인된 구간부터 순서 기반 분석으로 진행한다.
  - **순서 후보별 제한적 탐색:** 원본 순서와 정렬 후보 중 하나를 확정할 수 없다. 두 결과를 유지하고 순서 의존적인 해석을 보류한다.
  - **순서 분석 보류:** 순번의 의미나 기록 단위에 근거가 없거나 재구성이 불가능하다. 정적 분포·비지도 탐색을 우선한다.
- 실제 시간축은 별도 근거가 있을 때만 채택한다. 일반적인 용접 사이클 추정만으로 시간축을 확정하지 않는다.
- 서로 다른 날짜에 동일한 연속 공정변수 블록이 확인되면 날짜 분할만으로 독립 검증이 보장되지 않는다고 기록한다. 다음 모델 실험에서 반복 구간을 고려한 분할을 설계한다.
- 가이드나 관측 단위를 끝내 확인하지 못해도 데이터 감사 자체는 완료할 수 있다. 단, 불명확한 부분을 확정 사실로 바꾸지 않는다.
- 관측이 많은 공정 범위를 품질이 검증된 안정영역이라고 부르지 않는다.
