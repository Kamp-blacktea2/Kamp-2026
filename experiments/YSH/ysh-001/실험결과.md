# 실험결과 — YSH 첫 번째 실험 (ysh-001)

**판정: 순서 후보별 제한적 탐색을 채택한다. 공통된 20건 주기는 확인되지 않았고, 날짜 사이의 긴 동일 기록 블록이 더 중요한 문제로 확인되었다.**

모델 성능 실험이 아니라 데이터 감사·순서·반복 민감도 실험이다. CPU에서 실행했으며 개별 불량 예측 모델은 학습하지 않았다.

## 실제 수행 내용

1. 원본 3개 시트와 scaled를 읽어 행·열·결측·고유값·중복·분포를 재계산했다.
2. 원본 순서 A와 날짜→생산순번→원본 행 번호 정렬 B를 비교했다. 날짜 변경, 순번 불연속, 날짜+순번 충돌, 원본의 경계와 제외 후 틈에서 창을 끊었다.
3. 모든 행 간 오프셋을 검사해 4개 공정변수의 **20건 이상 완전 동일한 연속 구간**을 찾았다. 각 일치 구간은 값 배열로 재검증했다.
4. 원본 전체(all)와 100건 이상 동일 블록의 후행 출현을 제외한 민감도 조건(dedup)을 비교했다. 앞선 출현을 유지하며 겹치는 제외 구간은 합집합으로 처리했다. 100건은 이번 구현에서 명시한 탐색 기준이며 검증된 정제 기준이 아니다.
5. 각 조건에서 현재값을 제외한 과거 20·50·100건의 중앙값·IQR·표준편차·현재 편차를 계산했다. 부족한 창은 결측, IQR=0은 별도 표시했다.
6. 20·50·100건 비중첩 구간 전체를 그래프 탐색기에 연결했다. 완전한 100건 내부의 20건 5구간을 개별·원시값 중첩·평균 제거 중첩으로 비교했다. 모든 10쌍의 변수별 RMSE·평균 제거 RMSE·상관계수를 계산했다.
7. 시작점 10건 이동 민감도, 200·500건 확대, 기록 간격 1·10·20·50·100·200·500의 자기상관을 계산했다. 자기상관은 해당 구간 길이가 200 이상이고 비교 쌍이 100 이상일 때만 계산했다.
8. result는 날짜·유형 집계 수준에서만 연결했다. 개별 행의 라벨을 생성하지 않았다.

## 계획에서 변경된 점

- 현재 원본 파일명이 공백 대신 밑줄을 쓰는 `Welding_Data_Set_01.xlsx`다. 해시는 계획의 입력과 동일하다.
- 사용자 최신 요청에 따라 코드·표·그래프를 모두 `experiments/YSH/ysh-001/` 아래에 모았다. 산출물은 하위 `outputs/`이며 실험 폴더의 `.gitignore`로 추적에서 제외한다.
- 반복 제외 기준은 길이 100건 이상의 후행 출현으로 구체화했다. 이것은 강한 민감도 조건이며 최종 학습 데이터로 채택하지 않았다.
- 조건부 확대를 특정 좋은 사례만 골라 하는 대신, 전체 100건 블록 비교에서 공통 20건 반복이 뚜렷하지 않아 해당 연속 구간의 **모든 200·500건 정렬 블록**을 제공했다. 짧은 꼬리는 부분 블록으로 표시한다. 개별 100건마다 사람이 판정해 순차 확대했다는 의미가 아니다. 대상·제외 사유는 `expansion_index.csv`에 있다.
- 모든 블록을 개별 PNG로 대량 저장하는 대신 오프라인 HTML에서 구간·길이·페이지를 선택해 각 그래프를 볼 수 있게 했다. 주요 정적 분석 그림 9개와 브라우저 점검 화면 1개를 추가했다. 전체 그래프의 데이터·범위는 코드로 검산했고 대표 화면을 시각 점검했다. 모든 페이지를 사람이 하나씩 시각 판독한 것은 아니다.
- 기본 제공 Python에는 matplotlib가 없어 Excel 읽기·통계는 제공 Python 3.12, 시각화는 이미 설치된 Python 3.13과 matplotlib/Plotly를 사용했다. 새 패키지는 설치하지 않았다.
- 공식 KAMP 안내 페이지의 직접 열기가 도구에서 실패했고 공식 가이드 원문은 확보하지 못했다. 파일 내부 설명은 확인했지만 제품당 용접점 수·수집주기·실가동시간은 TODO다.

### 2. 날짜와 생산순번

- 날짜+idx 중복키는 1개이고 서로 다른 값을 가진 2행이 해당한다: Excel 1202행과 3552행, 2020-03-25/idx=1.
- Excel 3552행과 5201행은 주변의 3월 27일 구간에 끼어 있지만 날짜는 3월 25일이다. 오기 가능성은 있으나 수정하지 않았다.
- A와 B의 전체 인접 행 쌍은 11,938개 중 6개가 달라졌다(0.0503%). 원본 경계를 B에서도 보존했기 때문에 분석 가능한 내부 구간은 같고, 행 번호로 대응시킨 100건 창 중앙값도 일치했다.
- A/B가 비슷하다는 사실은 실제 작업순서를 증명하지 않는다. 파일상 생산순번을 근거로 제한적인 이벤트 순서 탐색만 허용한다.

### 5. 20·50·100건과 200·500건 그래프

확대에서는 100건 미만 연속 구간 3개를 별도로 건너뛴다. 정렬된 200·500건 블록과 시작점 10건 이동 보기를 제공한다. 경계를 넘어 모자란 길이를 채우지 않았다.

원본의 완전한 100건 블록 117개마다 20건 5구간의 10쌍을 비교했다. 아래는 **변수당 1,170쌍의 중앙값**이다. 서로 종속된 탐색 비교이며 가설검정의 독립 표본으로 취급하지 않는다.

| 변수 | 원시값 RMSE 중앙값 | 평균 제거 RMSE 중앙값 | 상관계수 중앙값 | 시작점 +10건 상관 중앙값 |

**20건짜리 동일 모양이 100건 안에서 공통적으로 5회 반복된다는 근거는 얻지 못했다.** 평균을 제거하고 시작점을 옮겨도 전체적인 판단은 같다. 이것은 모든 국소 구간에 반복이 없다는 증명이 아니다.

200·500건 확대에서는 지속되는 공정 수준과 구간 전환을 볼 수 있었다. 원본 연속 구간별 lag-20 자기상관의 중앙값은 가압력 0.7545, 전류 0.6550으로 높지만 lag-1은 각각 0.9265, 0.9584로 더 높다. 수준이 지속되거나 천천히 변하는 것도 큰 자기상관을 만들므로 이 수치만으로 20건 주기를 주장할 수 없다. 통전시간 lag-20 중앙값은 0.0017이었다. 집계는 구간별 상관의 비가중 중앙값이고 lag에 따라 사용 가능한 구간 수가 달라진다.

### 6. 이동창과 변화 후보

과거 20건은 국소 수준 변화에 더 빨리 적응하고, 100건은 더 긴 과거와의 차이를 보여준다. 어느 창이 불량탐지에 더 좋은지는 개별 정답 없이 선택할 수 없다. 이번에는 세 길이 모두 보존한다.

구간별 직전 값 대비 절대 변화량의 상위 1%를 동률 포함해 표시한 원본 후보는 가압력 138, 전류 139, 전압 126, 통전시간 1,155건이다. 합계 1,558은 변수-행 조합 수이며 고유 용접 행 수가 아니다. 통전시간은 제한된 값과 동률이 많아 후보가 1%보다 크게 늘었다. **이 사후 규칙을 그대로 불량 임계값으로 쓰면 안 된다.**

기재 합계는 39이고 8개 날짜에 기록이 있다. 3/27은 result 전체가 없고 3/31의 유형 3도 없다. 누락은 0으로 채우지 않았다. 유형별 기재 합계는 1번 14, 2번 13, 3번 12이며 합계 39와 일치한다.

scaled는 같은 행 수라도 원본에 바로 붙일 근거가 부족하다. 사전 역변환 가설 `raw ≈ offset + scale × scaled`에서 offset=[1.74,14.52,2.46,70], scale=[118.26,139.78,95.78,2170]을 사용하고 원본 전압을 소수 둘째 자리로 비교하면 **같은 위치의 4열이 모두 맞는 행은 979건**이다. scaled 결측도 71셀 존재한다.

앞선 대화의 “11,690개 정렬 대응”은 별도의 순서 정렬 추정 결과다. 이번 실험에서 그 정렬 알고리즘을 재실행한 것은 아니며, 979와는 비교 기준이 다르다. scaled의 원본 생성 과정·정확한 scaler·행 이동 및 변경 원인은 미확정이다. scaled를 추가 독립 학습 데이터로 합치지 않았다.

## Baseline 대비 변화

학습 모델이 없어 예측 점수 개선은 산출하지 않았다. 통계 기준선 A_all 대비 B_all은 원본 경계를 보존한 내부 창 통계가 동일했다. 반면 반복 제외는 관측 수·날짜 가중치·분포와 후보 수를 크게 바꿨다. 정렬보다 **반복 데이터의 계보와 평가 분할**이 현재 더 중요한 병목이다.

## 해석

Feature가 4개뿐이라는 이유만으로 외부 데이터를 즉시 추가할 필요는 없다. 현재 자료만으로도 수준·변동·상호작용을 분석할 여지가 있지만, 많은 행이 같은 값 궤적을 반복하므로 명목 행 수를 독립 데이터양으로 생각해서는 안 된다.

후속 모델에서는 원본 4개 변수의 Isolation Forest를 먼저 비교 기준으로 삼고, 물리적 단위와 측정 의미를 확인한 뒤 에너지·저항 대리변수나 상호작용을 추가하는 실험이 적절하다. 이는 데이터양 자체를 늘리는 방법이 아니며 성능 개선을 보장하지 않는다. 이번에는 해당 파생변수의 성능을 시험하지 않았다.

자주 나타나는 구간은 관측이 밀집한 범위일 뿐, 품질이 검증된 공정 안정영역이 아니다. 실제 불량 여부·설정값·검사 기록이 있어야 안전한 조건이나 최적 조건을 주장할 수 있다. 추가 데이터가 필요해지면 같은 설비·공정·단위의 새 기간 기록과 검사 결과가 우선이며, 다른 용접 데이터의 단순 행 추가는 아직 근거가 없다. 외부 데이터 사용 규정의 확정 여부도 별도 TODO로 유지한다.

## 가설과 일치 여부

부분 일치. 파일 설명상 생산순번이 있고 모순 경계를 피한 국소 순서 탐색은 가능하다. A/B 차이는 작았고, 반복 처리에 따른 표본 가중치 차이는 컸다. 실제 시간순서와 공장 주기를 확정할 근거는 부족하다. 공통 20건 반복 가설은 이번 비교에서 지지되지 않았다.

## 오류/실패

- 첫 환경 확인에서 기본 Python의 matplotlib 부재를 확인했다. 이미 설치된 별도 Python의 시각화 라이브러리로 해결했다.
- 이전 공백 파일명으로 읽기를 시도해 파일 없음 오류가 났다. 현재 파일명과 해시 확인 후 경로를 수정했다.
- 그래프 첫 렌더에서 Plotly 축 제목 형식 차이를 발견해 객체 형식으로 수정하고 브라우저를 재검증했다. 수정용 단발 PowerShell 명령의 인용 오류는 파일 기반 스크립트로 해결했다.
- 공식 안내 URL은 이번 도구 호출에서 접근 실패, 공식 가이드는 미확보다. 이를 이유로 데이터 단위를 추정해서 확정하지 않았다.
- 완료된 분석/검산 실행은 정상 종료했다. 사용자 기존 `Data_analyze-001.ipynb`는 수정하지 않았다.

## 결론

**순서 후보별 제한적 탐색을 채택한다.** 20건 주기로 생산 단위를 재구성하거나 시간당 생산량을 계산하지 않는다. 현재의 가장 큰 후속 과제는 4개 Feature의 수보다 긴 동일 블록의 출처와 학습·평가 독립성이다.

## 채택 / 보류 / 폐기

- 채택: 원본 행 번호 보존, 모순 경계를 피한 과거 창, 반복 구간 표시, A/B 민감도 비교.
- 보류: 실제 시계열·생산 주기 해석, 자동 반복행 제거, 물리 파생변수의 효과, 검증된 공정 안정영역 판단, 외부 데이터 추가.
- 비채택: 날짜만으로 독립성이 확보됐다고 가정한 성능 주장, scaled의 단순 1:1 결합과 독립 표본 취급, result의 개별 불량 라벨 확장.
