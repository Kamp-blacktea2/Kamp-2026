## 실행자가 먼저 알아야 할 배경

### 관측 단위와 미확정 사항

- 원본 Excel의 한 행을 우선 **한 공정 기록**이라고 부른다. 한 제품, 용접 한 번, 일정한 시간 간격 중 어느 것인지 확정하지 않는다.
- 주요 입력은 `weld force(bar)`, `weld current(kA)`, `weld Voltage(v)`, `weld time(ms)`이다. 열 이름의 단위 표기는 보존하되 측정값/설정값/구간 요약값 여부는 미확정이다.
- 기존 확인에서 Item No는 `65235-25800`, Item Spot은 `01`로 일정했다. 제품 인스턴스 ID로 사용하지 않는다. 일정한 Item No가 품번일 가능성은 가설이며 실제 제품 수를 계산하지 않는다.
- 날짜·idx에 순서 모순이 있다. 정렬이나 보정으로 이를 숨기지 않는다. 원본 순서와 연속 구간 경계를 유지한다.
- `result` 또는 별도 오류 정보가 있더라도 개별 행 품질 정답으로 검증되지 않았다. 임의로 타깃이나 평가 라벨에 연결하지 않는다.
- 기록 간격을 초, 분, 제품 수 또는 실제 용접 횟수로 환산하지 않는다. 순서 분석은 연속 구간 내부의 행 간격만 사용한다.

## 검증 방법

### 1. 공통 전처리와 분석/민감도 구분

- 각 fit의 데이터에서만 스케일러를 학습하고 비교용 anchor에는 transform만 적용한다. 전체 자료를 이용한 탐색 fit은 ‘전체 탐색’으로 명시한다.
- 주 스케일은 평균·표준편차를 이용한다. 민감도는 중앙값·IQR을 이용한다. 분모가 0인 열은 IQR→표준편차 순으로 대체하고 둘 다 0이면 해당 fit에서 제외하며 로그를 남긴다.
- 날짜별 또는 블록별로 따로 표준화해 수준 차이를 지우지 않는다. motif의 평균 제거 표현은 별도로 이름 붙인다.
- 누락값을 발견하면 자동 대치하지 말고 위치와 사유를 확인한다. 네 값이 모두 관측된 행만 사용하는 대안은 제외 수·새 경계를 기록한 뒤 적용한다.
- seed는 주 42, 민감도 7·2026. 난수가 없는 알고리즘은 반복 실행을 생략한다.
- 실험은 ①전체 탐색 ②반복 조건 비교 ③연속 부분 구간 제거 후 재적합으로 나눈다. 어느 것도 독립적인 불량 예측 평가가 아니다.

### 2. PCA — 함께 변하는 관계와 이탈

- X4로 fit. 주 스케일과 세 데이터 조건에서 수행한다.
- 설명분산비·누적분산·loading과 원시값 상관을 보고한다.
- 주 차원 k는 누적분산 90%를 처음 넘는 k를 사용한다. k=4가 필요하면 차원 축소 근거 약함으로 기록하고 재구성 이상치 주장은 보류한다.
- k=1,2,3의 재구성 오차를 민감도로 보존한다. 임의로 가장 극적인 k를 고르지 않는다.
- Q = 표준화 공간에서 원본과 k성분 재구성 간 제곱오차 합. 변수별 기여도도 같은 공간에서 계산한다.
- T² 유사 점수 = 유지한 성분 score² / 해당 eigenvalue의 합. 0 또는 수치적으로 작은 고유값은 제외하고 기록한다. 이론적 관리한계나 확정적 유의확률은 부여하지 않는다.
- 큰 Q는 학습한 선형 관계로 설명하기 어려움, 큰 T²는 그 관계 안에서 멀리 위치함을 뜻한다. 둘을 하나의 이상 라벨로 합치지 않는다.
- 의미 있는 저차원 구조가 없다는 결과를 허용한다.

### 3. GMM — 상태 분포와 소속 불확실성

- X4와 X3를 각각 사용한다. X3는 force/current/time이며 전압을 제외한다.
- K=1..6, covariance_type='full', reg_covar=1e-4, n_init=5, max_iter=500, random_state=42를 주 설정으로 한다.
- 각 조건·입력별 같은 데이터에서 BIC 최솟값 K를 선택한다. BIC 차이 2 이내 후보는 더 작은 K를 대표로 하되 둘 다 표에 남긴다. 다른 데이터 조건의 BIC 절댓값끼리 비교하지 않는다.
- 반복 기록·종속성이 있으므로 BIC는 탐색적 모델 비교 도구다. 실제 상태 수의 통계적 증명으로 쓰지 않는다.
- 수렴 여부, 작은 구성요소, 공분산 조건수, 구성요소 비중을 저장한다. 실패 시 reg_covar=1e-3 재시도 1회만 허용하고 변경을 남긴다. 실패를 높은 K 필요성으로 해석하지 않는다.
- 대표 K에서 seeds 7/2026과 covariance_type='diag'를 민감도로 확인한다. 최적화를 계속 확대하지 않는다.
- 각 행의 구성요소 소속 확률·최대확률·entropy를 저장한다. K=1의 정규화 entropy는 0으로 정의한다.
- 최대 소속 확률 0.8 미만은 ‘소속 불확실’ 표식으로만 사용한다. 정확도나 품질 신뢰도가 아니다.
- 군집별 n, 비중, 네 원시변수 중앙값/IQR, 날짜별 분포, 원본 구간별 점유율을 표로 보고한다.

### 4. Isolation Forest·LOF — 희소성과 주변 이탈

- X4를 사용한다. 지도 품질 타깃을 사용하지 않는다.
- Isolation Forest: n_estimators=300, max_samples=min(256,n), max_features=1.0, bootstrap=False, contamination='auto', random_state=42. 큰 값이 더 특이하도록 `-score_samples`로 방향을 통일한다. 선택 설정에서 seed 7/2026 및 max_samples=min(1024,n)를 비교한다.
- LOF: n_neighbors=20 주 설정, 10/50 민감도, metric='euclidean', novelty=False. 학습 표본의 점수는 `-negative_outlier_factor_`를 사용한다. n_neighbors<n을 보장하고 데이터가 부족하면 미산출로 기록한다.
- LOF는 exact duplicate 이웃, 0거리 비율, 경고·비유한 점수·동점 비율을 기록한다. unique4 진단을 통해 중복 빈도 효과와 값 조합의 기하 구조를 구분한다.
- 재적합 후 미관측 anchor의 LOF 점수가 필요하면 별도의 novelty=True fit으로 계산하고, 그 fit에 사용된 행에 novelty 점수를 적용하지 않는다. 학습 outlier 모드와 수치가 동일하다고 가정하지 않는다. 복잡하면 LOF 안정성은 공통 실제 학습 행의 outlier 순위 비교로 한정하고 범위를 명시한다.
- 상위 1%, 5%를 검토 예산으로 보고한다. 품질 불량률·실제 이상치율로 부르지 않는다.
- 임계점 동점은 모두 포함하고 실제 선택 개수/비율을 병기한다. 임의의 행 번호 tie-break로 군집을 정상/이상으로 갈라놓지 않는다.
- PCA Q, T², 단변량 기준선과 상위 집합의 교집합·차집합을 확인한다. 점수 원시값을 모델 간 평균내지 않는다.

### 5. PELT — 구간의 평균 상태 전환

- 각 원본 연속 구간 안에서만 실행한다. 입력 X4 주 분석, X3는 전압 반복과의 연결에 사용한다.
- 모델 fit 조건의 공통 scaler로 표준화한 값에 L2 비용을 사용한다. 주 설정 min_size=32, jump=1, penalty=3*d*log(n), d=실제 사용 차원.
- penalty 계수 1/3/10, min_size 16/32/64를 민감도로 보되 주 계수3에서 min_size 비교, 주 min_size32에서 penalty 비교만 한다. 완전 교차 탐색은 하지 않는다.
- n<2*min_size이면 경계 분석 미산출. API가 반환하는 마지막 n은 종료점이며 검출 변화점 수에서 제외한다.
- 비용함수와 penalty는 탐색용 설정이다. L2의 평균 변화 탐지가 분산만의 변화를 모두 찾는다고 주장하지 않는다. 분산·기울기 변화는 경계 주변 표로 별도 설명한다.
- 경계의 양쪽 32행에서 변수별 평균·중앙값·IQR·평균 절대차분과 GMM 상태 점유율을 비교한다. 경계를 넘는 데이터가 부족하면 실제 n을 쓰고 단축 사실을 기록한다.
- 다른 설정의 경계가 ±8원본 행 안에 있으면 위치 대응 후보로 본다. 중복 경계는 일대일 최소거리 대응으로 집계한다. tolerance 4/16도 요약한다.
- 경계를 제품 교체/고장으로 확정하지 않는다. 같은 수준이 다시 나타나는 것과 연속 구간의 경계를 구분한다.

### 6. Matrix Profile — 반복 모양과 고립된 구간

- 주 입력 전압, 보조 입력 네 변수 각각. 길이 m=16/32/64, 전압 이웃 길이15/17. 시작점을 한 행씩 이동하되 모든 창은 원본의 연속 구간 안에 있어야 한다.
- self-join은 우선 같은 연속 구간 안에서 수행한다. 서로 다른 날짜·구간을 이어 붙여 단일 시계열로 만들지 않는다.
- 주 모양 거리는 블록 평균만 제거한 유클리드 거리/RMSE로 한다. 진폭은 유지한다. 보조로 z-normalized Matrix Profile을 계산하되 이것이 진폭 차이를 제거한다는 점을 표시한다.
- 구현 라이브러리가 평균 제거만 지원하지 않으면 원시·평균 제거 거리의 정확한 블록 단위 계산을 구현해 같은 최근접 구간 정의를 따른다. 전체 n×n 행렬을 한꺼번에 만들지 않는다. 최소한 50쌍을 직접 계산해 일치 확인한다.
- 두 창이 겹치면 이웃 후보에서 제외한다(시작점 차이>=m). 라이브러리 기본 exclusion zone만으로 비중첩이 보장되는지 확인하고 부족하면 명시적으로 추가한다.
- 각 창에 대해 (a) 모든 유효 비중첩 상대 중 최근접 (b) 해당 변수의 원시 배열이 exact인 상대를 제외한 최근접을 별도로 계산한다. 전체 4변수 exact 여부도 기록한다.
- 최근접이 exact라는 이유로 그 창을 버리면 안 된다. **다음 비동일 후보를 다시 찾아야 한다.** full/top-k distance profile을 순차 확장하거나 정확한 masked 검색을 사용한다. 임의 top-k만 보고 비동일 후보가 없다고 결론내리지 않는다.
- 기존 긴 동일 블록 목록은 제외·감사 보조이며, 실제 비교 창 값으로 exact 여부를 검증한다. controlled100도 추가 비교한다.
- 낮은 거리의 반복 사례와 높은 최근접 거리의 특이 사례를 각 10개 이내로 추린다. 같은 지역의 겹치는 창이 사례 수를 채우지 않도록 greedy 비중첩 대표를 선택하고 전체 창 수와 대표 수를 구분한다.
- 각 쌍에 원본 위치, 간격, 길이, exact 여부, Pearson 상관, 평균 제거 RMSE, 진폭비, 두 구간의 다른 세 변수 통계를 기록한다.
- 모양 검출은 원인·품질 판정이 아니다. 길이가 다른 거리 비교에는 RMSE를 사용하더라도 별도의 길이별 분포를 먼저 본다.
- 상수 창은 원시값 비교에는 남기고 모양 상관은 미산출로 한다. z-normalization의 특수 상수 처리를 높은 모양 유사성으로 오해하지 않는다.
- 다변량 부분집합 motif는 첫 실행의 필수 범위가 아니다. 네 변수별 결과를 대조하고, 공통 위치인지 표로 확인한다. mSTUMP를 추가할 경우 차원 선택 규칙과 정규화 차이를 별도 확장으로 기록한다.

### 7. 모델 결과를 YSH-003과 연결

주 질문은 ‘전압을 제외한 조건이 전압 반복과 관계있는가’이다.

1. X3 GMM으로 원본 행의 상태를 추정한다. X4 상태는 설명용 비교이며 독립적인 전압 설명 근거로 사용하지 않는다.
2. 기존 N=16 인접 쌍을 그대로 재구성하고 Excel 행 대응을 검산한다. 이전 모양 판정: 양쪽 비상수, corr>=0.7, shape_error<=0.75, 진폭비0.5~2.0. shape_error는 `sqrt(sum((Ac-Bc)^2)/(sum(Ac^2)+sum(Bc^2)))`다.
3. 각 16행 창에서 최대 posterior가0.8 이상인 행이 80% 이상 같은 상태를 가질 때 해당 상태 창으로 지정한다. 그 외는 혼합/불확실 창으로 별도 집계한다. 이 문턱은 탐색용이며 품질 기준이 아니다.
4. A/B 창이 같은 상태, 다른 상태, 혼합/불확실인 쌍을 구분하고 전압 통과수/분모·상관·RMSE를 비교한다. 모든 쌍이 한 번씩 집계되도록 분모를 대조한다.
5. all/controlled100, 앞/뒤 절반, 시작점0/8을 구분한다. 표를 합칠 때 구간별 비율 평균인지 합산 비율인지 표시한다.
6. 상태별 전압 반복률은 해당 상태 쌍>=30이고 최소2개의 서로 떨어진 원본 연속 구간에서 관측될 때만 비교 해석한다. 날짜가 달라도 정확 반복 관계면 독립 재현으로 세지 않는다. 부족한 표는 삭제하지 않고 ‘지원 부족’으로 남긴다.
7. N=15/17도 대조한다. 특정 상태에 N=16만 유리한지 또는 넓은 범위의 완만한 유사성인지 구분한다.
8. X3 PELT 경계 ±16행 부근과 그 밖의 전압 통과율·IF/LOF/PCA 점수 분포를 비교한다. 경계 인근 범위가 겹치면 행을 중복 집계하지 않는다. 경계가 많아 대부분을 차지하면 비교 불가로 보고한다.
9. full-data X3 상태가 미래 자료의 분포를 포함한다는 점을 표시한다. 추가로 각 연속 구간 앞 절반만 모아 scaler/GMM을 fit하고 뒤 절반에 적용한 결과를 한 번 확인한다. 기존 EDA·날짜 간 반복 때문에 독립 검증으로 부르지 않는다. 뒤 절반에 새 상태가 강제로 기존 상태에 배정되는 현상은 posterior/밀도로 점검한다.

### 8. 안정성·재현 범위

- primary all과 controlled100, unique4 각각 같은 원본 공통 행/고유조합 anchor에서 결과를 비교한다. 군집 ARI는 label permutation에 불변인 지표로 사용한다. 서로 다른 행 집합의 label을 그대로 비교하지 않는다.
- GMM 안정성은 K를 고정한 설정/seed 비교와 K를 다시 선택한 파이프라인 비교를 구분한다.
- 순서 있는 민감도: all의 각 길이>=200 연속 구간을 원래 순서대로5개에 가깝게 나눈다. 반복 r=1..5에서 각 구간의 r번째 부분을 제외하고 행 모델을 재적합한다. 짧은 구간은 fit에서 유지하되 짧은 구간 영향이라고 표시한다.
- 제거 재적합은 주 K·PCA k를 고정한다. 매번 full grid를 다시 탐색하지 않는다. 제외 경계를 넘어 창·차분·PELT를 계산하지 않는다.
- 이 방법도 다른 날짜의 동일 블록을 남길 수 있어 독립 평가나 신뢰구간이 아니다. 입력 일부가 바뀌었을 때의 설정 민감도 점검으로만 사용한다.
- GMM label은 공통 anchor의 ARI, 이상치 점수는 Spearman 및 상위5% 집합 Jaccard를 사용한다. 동점 포함 실제 집합 크기를 함께 보고한다.
- 원본과 통제 조건을 비교할 때 동일 행의 값 변화가 아니라 fit 분포 변화라는 점을 명시한다. 전체자료를 fit한 scaler를 시간 분리 확인에 재사용하지 않는다.
- 사전 탐색 경고 표식: ARI<0.6 또는 상위5% Jaccard<0.5가 반복되면 ‘설정 의존’으로 표시한다. 이 기준을 통과해도 물리적 실체를 증명한 것은 아니다. 수치 원본을 숨기지 않는다.

## 평가 지표

| 대상 | 지표/표 | 해석 제한 |
|---|---|---|
| 입력 | n, 결측, 고유조합, 구간 수, 반복 비중 | 고유조합 수는 유효 독립 표본 수가 아님 |
| PCA | 분산비/loading, Q, T², 변수별 Q 기여 | 선형 구조·표준화에 의존 |
| GMM | BIC, 수렴, 구성요소 비중, posterior/entropy, 원시값 프로파일 | 상태 수·제품 종류의 정답 아님 |
| IF/LOF | 점수 분위수, 상위1/5% 사례, 기준선과의 겹침 | 불량 확률·검출 정확도 아님 |
| 변화점 | 경계 수·위치, 양쪽 효과 크기, 설정 간 위치 대응 | 장비 이벤트/제품 경계 미확정 |
| motif | 길이별 최근접 거리, 상관·진폭, exact 제외 전후 | 가까운 모양이 물리적 cycle 증명은 아님 |
| 모델 안정성 | ARI, Spearman, Jaccard, 실제 비교 n | 독립 일반화 점수 아님 |
| 조건 연결 | 상태별 전압 통과 분자/분모, 구간별 결과 | 군집 선택·반복 종속성·시간 추세의 영향 |

실루엣 점수는 선택적으로 보조 보고하되 GMM/HDBSCAN 등 서로 다른 가정의 모델을 이 점수 하나로 순위 매기지 않는다. 정확도/F1/AUC는 유효한 품질 정답이 없으므로 산출하지 않는다. 공식적인 유의확률·신뢰구간은 이번 범위 밖이며 관측 차이를 인과 효과로 해석하지 않는다.

## 성공/판단 기준

실험 성공은 원하는 군집이나 이상치를 반드시 찾는 것이 아니라, 아래 질문에 근거와 한계를 붙여 답하는 것이다.

1. 단일 상태, 여러 상태, 연속 변화 중 어떤 설명이 관측 자료에 적합한가? GMM K=1 선택도 성공적인 결과다.
2. 관계 이탈·전체 희소성·주변 이탈이 같은 행을 가리키는가? 다른 행을 가리키면 각 사례의 실제 값으로 설명한다.
3. 전압 반복은 다른 세 변수의 상태와 연결되는가? 표본·구간 지원이 부족하면 보류한다.
4. 그 결과가 정확 반복·스케일·seed·연속 일부 제거에 얼마나 의존하는가?
5. 이후 어떤 Feature/검증 단위를 검토할 근거가 생겼는가? 발견하지 못했다면 추가 모델을 무제한 늘리지 않고 결과를 기록한다.

최종 판단은 항목별 ‘후속 검토할 관측 구조 / 설정 의존 / 표본 부족 / 지지되지 않음’으로 적는다. ‘정상/불량’, ‘제품A/B’, ‘고장 원인’으로 승격하지 않는다.

## 보류하는 모델과 범위 확장 조건

- HDBSCAN: GMM의 분포 가정으로 상태가 설명되지 않고 불규칙한 밀도 구조가 관찰될 때 별도 확장. 첫 실행 필수 여섯 방법에는 포함하지 않는다.
- HMM: 상태의 해석과 기록 순서가 충분히 확보된 뒤 상태 전이 가설을 검토할 때 사용. 현재 제품 경계를 대신 생성하지 않는다.
- Autoencoder/VAE/Transformer: 네 변수와 반복 종속 자료에서 먼저 추가할 근거 부족. 단순 방법의 특정 표현 한계가 확인된 후 별도 계획.
- One-Class SVM: 신뢰할 정상 참조 집합이 없고 튜닝 민감도도 추가되므로 첫 실행에서 제외한다. 이론적으로 실행 불가능하다는 뜻은 아니다.
- 외부 파이프 전체 분석, 품질 예측, 모델 앙상블, 최적 공정조건 제안은 별도 과제다.

2. all / controlled100 / unique4 각각에서 StandardScaler와 RobustScaler를 비교한다. 스케일러는 각 fit의 행에서만 학습한다. X3·X4 GMM, X4 PCA·IF·LOF를 포함한다. 모델 seed42·주 설정을 고정하고 GMM은 고정 K=6과 스케일별 K=1..6 재선택을 구분한다. ARI, 순위 상관, 상위5% Jaccard와 실제 동점 포함 수를 보고한다.
3. all/controlled100 각 연속 구간의 앞 절반만 모아 X3 scaler/GMM을 학습한다. Standard/Robust 모두 뒤 절반에 적용하며 고정K6과 앞 절반 BIC 선택 모델을 구분한다. 뒤 절반의 상태를 기존 15/16/17행 전압 비교에 연결하여 분자·분모를 다시 계산한다. posterior/밀도는 정상 판정이 아니다.
4. 창의 '여러 상태 혼합'과 '낮은 소속 확률'을 분리한다. 기존 same/different/mixed_or_uncertain 집계도 보존하여 이전 보고서와 대조한다. 모든 행의 posterior>=0.8 여부와 창의 80% 단일상태 조건을 별도 기록한다.
5. PCA의 누적분산·loading·Q/T², 고정 k=1/2/3 Q 순위와 변수별 Q 기여를 비교한다. 각 연속 긴 구간의 1/5 제거 반복에서 PCA 고정k 결과도 보완한다. 주 k=4 Q는 의미없는 수치 오차이므로 순위 해석에서 제외한다.
6. 재실행 경로를 단일 sequence 구현으로 연결한다. 완전 동일 여부는 원시 배열 비교로만 계산한다. 대표 motif는 A/B 역방향과 양쪽 창의 재사용·겹침을 함께 제한한다. 기존 모든 창 요약은 바뀌지 않아야 하며 대표 사례만 바뀔 수 있다.
7. 독립 검산에서 원본 불변, 앞/뒤 비중첩, 스케일 통계, GMM posterior 합, 점수 방향, 상태별 분모, 전압 판정, PCA Q 기여 합, motif exact 판정·대표 비중첩을 확인한다. sklearn GMM의 full covariance에서 단순 좌표 스케일 변화에 따른 적합 차이는 수치 정규화·초기화·지역해의 영향도 있으므로 실제 공정 상태 변화라고 부르지 않는다.
8. 결과는 `outputs/validation/`와 `추가검증결과.md`에 저장하고 기존 `실험결과.md` 상단 및 report.py에 연결한다. 코드·설정·원본·실행 환경·검산 해시를 별도 manifest에 보존한다. 개인 실험기록도 갱신한다.

이 검증도 전체 EDA를 본 자료와 반복된 날짜를 포함하므로 독립 품질 검증이 아니다. 보고서의 결론은 계산 재현성·설정 안정성·상태별 관측 차이에 한정한다. 새로운 모델 계열이나 전처리를 무제한 탐색하지 않는다.
