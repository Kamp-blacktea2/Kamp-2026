## 실제 수행 내용

1. Excel 시작행 1879, 4693, 7803, 10879의 각 298행을 원본에서 다시 매핑하고 Raw4 값과 순서의 완전 동일성을 검산했다.
2. YSH-001 `exact_repeated_blocks.csv`에서 repeat298 전체를 포함하는 parent 후보 6개를 찾고, 모든 후보 구간의 합집합으로 `parent-repeat-other`와 `outside-parent`를 만들었다.
3. YSH-007의 `lodo_row_scores.csv`, `in_sample_scores.csv`, `physical_row_followup.csv`를 원본 Excel 행에 1:1 연결했다.
4. A/B-repeat298-core/B-nonrepeat를 주 분해하고, parent-repeat-other/outside-parent를 민감도로 추가했다.
5. 298 상대위치별 후보 support를 세어 주 binary positive를 `support≥3/4`, 민감도를 `≥1/4`와 `4/4`로 계산했다.
6. 기존 physical screening을 motif 위치에 재표현하고, motif 내부 q90은 별도 sensitivity로만 계산했다.
7. YSH-005의 실제 코드·설정·전처리·문턱을 감사하고, 저장된 seed42 reconstruction으로 기존 행 점수와 후보를 bit-level 정의에 맞춰 재현했다. Raw4만 사용하고 MinMaxScaler는 03-24~03-31 train 8,470행에만 fit된 기존 값을 그대로 썼다.
8. 행별 total/feature error와 후보를 저장하고 repeat298 네 occurrence의 동일 Raw4가 완전히 같은 AE error·candidate를 내는지 확인했다.
9. AE와 각 GMM 표지를 support≥3/4 주 기준 및 ≥1/4·4/4 민감도로 비교하고, dominant-variable 및 AE/GMM/consensus episode를 분리했다. union은 contextual envelope로만 저장했다.
10. 모든 후보·episode를 확정한 뒤 Result를 마지막에 연결했다. 독립 검산 코드로 AE 점수·문턱·feature error·agreement·episode·Result와 기존 GMM 파일 불변성을 재계산했다.

## 계획에서 변경된 점

- 최초 계획의 동료 AE export는 여전히 저장소에서 확인되지 않았다. 후속 사용자 지시에 따라 그 보고를 대체 재현한 것으로 간주하지 않고, 별도 **YSH-005 AE reference** 분석으로 008C/008D를 수행했다.
- 새 AE를 학습하거나 GMM 결과에 맞춰 튜닝하지 않았다. YSH-005의 저장된 `ae_42` reconstruction, train-only MinMaxScaler, `train mean + 8×population SD` 문턱을 그대로 사용했다. 저장 reconstruction에서 feature별 scaled squared error를 계산해 요구 열을 만들었으며 그 정의를 metadata에 기록했다.
- 계획에 있던 그림은 만들지 않았다. 모든 주 판단에 필요한 분자·분모·상대위치는 CSV로 남겼다.
- parent sensitivity는 실행했지만 `outside-parent`가 16행뿐이어서 안정적인 비교집단으로 사용하지 않았다.

[상대위치 profile](outputs/repeat298_relative_profile.csv), [방법별 episode](outputs/repeat298_episodes.csv).

동일 Raw4인데 occurrence별 LODO NLL·d²·조건부 z가 다른 것은 보류 날짜마다 reference model과 scaler가 다르기 때문이다. 이 차이를 occurrence별 공정값 변화 또는 품질 차이로 해석하지 않았다.

### 4. 기존 physical screening과 motif-relative sensitivity

기존 전역/LODO 기준 `row_review_candidate`는 support≥3/4에서 16개 상대위치를 표시했다. motif 내부 d² 중앙값 q90=7.6303, max |z| 중앙값 q90=2.1775와 기존 physical signature support≥3/4를 결합한 선택적 sensitivity는 34개 위치를 표시했다. 기존 16개는 모두 sensitivity에 포함됐고 18개가 추가되어 Jaccard는 0.471이었다. [physical 비교](outputs/physical_screening_motif_sensitivity.csv).

이는 기존 후보가 motif 내부에서도 상대적으로 강한 위치라는 일관성을 보이지만, motif q90은 정의상 꼬리를 생성한다. 새 18개를 추가 불량 후보나 개선된 threshold로 해석하지 않는다. 기존 physical threshold 자체도 block-conditioned 기준이 아니다.

### 5. AE–GMM agreement와 episode 상태

#### 5.1 고정 AE 재현과 동일 입력 sanity check

후속 분석은 동료 AE가 아니라 **YSH-005 seed42 reference AE**다. 구조는 4→3→2→3→4 RReLU, Adam(lr=0.01), batch 64, 50 epoch이며 입력은 Raw4뿐이다. 03-24~03-31의 8,470행에만 fit한 MinMaxScaler와 저장 reconstruction을 사용했다. 행 점수는 scaled feature squared error의 평균이고 문턱은 train 평균 + 8×population SD = **0.0732639557**이다. 기존 YSH-005의 11,939개 점수와 후보(train 42, test 14)를 그대로 재현했다. [AE 정의](outputs/ae_model_metadata.json), [행별 필수 열](outputs/ae_row_scores.csv).

전체 56개 AE 후보 중 repeat298에는 occurrence당 12행, 총 48행이 있었다. 네 occurrence의 각 상대위치에서 total error와 F/I/V/t feature error의 최대–최소 범위는 모두 정확히 0이고 candidate도 같았다. 따라서 1,192행을 독립 사건으로 세지 않으면 AE 후보는 **상대위치 1–12의 12/298개(4.03%)**이며 모두 support=4/4다. AE는 repeat298 전체가 아니라 시작부 일부만 표시했다. [동일성 감사](outputs/ae_repeat298_sanity.csv), [상대위치 profile](outputs/ae_gmm_relative_profile.csv).

사용자가 전달한 별도 동료 AE의 “254/298, Voltage와 Current 기여” 보고는 원 산출물·모델 정의가 없어 재현 여부가 여전히 미확인이다. 이번 고정 YSH-005 AE에서는 12/298이고 그 12개 모두 dominant variable이 V이므로, 두 결과를 같은 AE의 반복 실행으로 간주하지 않는다.

#### 5.2 위치별 AE×GMM agreement

주 support≥3/4 결과는 다음과 같다. AE positive는 모든 비교에서 12개다.

| GMM/physical 표지 | GMM positive | 교집합 | Jaccard | Cohen κ |
| --- | ---: | ---: | ---: | ---: |
| NLL q90 | 253 | 12 | 0.0474 | 0.0148 |
| d² q90 | 17 | 0 | 0 | -0.0496 |
| conditional-z≥2.5 | 10 | 0 | 0 | -0.0380 |
| 기존 physical global candidate | 16 | 0 | 0 | -0.0482 |

NLL은 AE 위치 1–12를 모두 포함하지만 motif 대부분인 253개를 표시해 Jaccard와 κ가 매우 낮다. 따라서 공통 12개만으로 두 모델이 같은 국소 이상을 탐지했다고 보지 않는다. 더 local한 d²·conditional-z·physical 주 후보와는 교집합이 0이다.

민감도에서도 결론은 유지됐다. support≥1/4에서 교집합/Jaccard는 NLL 12/0.0433, d² 3/0.0500, conditional-z 0/0, physical 3/0.0612였다. support=4/4에서는 NLL만 12/0.0816이고 나머지는 모두 교집합 0이었다. 연속 점수의 298위치 Spearman은 AE total error 대 NLL 중앙값 0.632, d² 중앙값 0.411, max |conditional-z| 중앙값 0.317이다. 이는 효과크기 기술치이며 유의성 검정이나 품질 성능이 아니다. [agreement 표](outputs/ae_gmm_agreement_summary.csv), [점수 상관](outputs/ae_gmm_score_correlations.csv).

#### 5.3 dominant variable과 episode

주 기준에서 공통 후보가 존재한 것은 NLL뿐이다. AE dominant는 12개 모두 V였고, GMM conditional-z dominant는 V 7, F 2, I 2, t 1로 **7/12(58.3%)**가 일치했다. 그러나 이 교집합에서 AE 최빈변수를 항상 예측하는 baseline도 V 12/12=100%이므로 58.3%를 dominant-variable agreement 근거로 해석할 수 없다. permissive 기준의 d²·physical 공통 3개는 모두 V/V였지만 표본이 3개이고 주 기준에서는 0개다. [dominant 혼동표](outputs/dominant_variable_confusion.csv), [요약](outputs/dominant_variable_agreement_summary.csv).

AE motif episode는 위치 1–12 한 구간이다. NLL consensus episode도 1–12 한 구간이지만, d²·conditional-z·physical의 주 consensus episode는 없다. [통합 episode 표](outputs/ae_gmm_episodes.csv)는 AE episode, 각 GMM episode, AE∩각 GMM consensus를 구분한다. [union 파일](outputs/ae_gmm_contextual_envelopes.csv)은 주변 문맥용 envelope일 뿐 episode나 독립 오류 건수가 아니다.

## Baseline 대비 변화

YSH-007은 B의 높은 NLL, component 조성, d²·조건부 z와 physical 후보를 전체 행/날짜 수준에서 확인했다. YSH-008은 모델을 변경하지 않고 사전 고정한 repeat298과 더 긴 parent 구조로 이를 분해했다.

- global NLL: repeat298 자체의 영향이 큼. core 제거 후 B–A 평균차 42.24% 감소.
- local d²: repeat298 제거로 B–A 평균차가 줄지 않음. 전체 motif보다 소수 위치의 이탈로 남음.
- 물리 후보: core에서 행 기준 7.30%, 위치 기준 support≥3/4는 16/298.
- 대조군: B-nonrepeat 99.64%가 parent-repeat-other여서 기존 B-nonrepeat 해석에 추가 교란이 확인됨.
- YSH-005 AE: repeat298 전체가 아니라 위치 1–12의 12/298만 표시. 이 위치는 NLL q90에는 모두 포함되지만 주 d²·conditional-z·physical 후보와는 겹치지 않음.

## 해석

현재 GMM 결과는 “repeat298 전체가 전역 희소 상태이면서, 그 내부의 d²·조건부 z는 별도 국소 위치에 집중”하는 구조를 지지한다. NLL만 보면 공정상태 전체 반응에 가깝고, d²/physical 표지만 보면 local deviation 후보가 남는다.

YSH-005 AE는 motif 전체가 아니라 시작 12개 위치만 표시했고, GMM NLL은 그 12개를 포함하면서 motif의 253개 위치를 표시했다. 반면 주 local d²·conditional-z·physical 표지와 AE의 교집합은 0이다. 따라서 제안의 A(두 모델이 motif 전체를 함께 이상으로 봄)나 B(동일한 국소 위치를 함께 강하게 탐지)를 지지하지 않는다. 이번 결과는 C에 더 가깝지만, 동료 AE 원 산출물이 아닌 YSH-005 reference라는 범위를 넘겨 일반화하지 않는다.

dominant variable도 공통 NLL 위치에서 7/12 일치했으나 AE가 전부 V인 불균형 baseline보다 낮다. 방법별 anomaly 정의가 다른 것으로 해석하며 점수 결합이나 공통 불량 선언을 하지 않는다.

parent 감사 결과도 강한 제한이다. B의 99.71%가 parent 합집합에 들어가고 outside-parent는 16행뿐이다. repeat298 하나만의 효과와 B 날짜/상위 motif 효과를 안정적으로 분리할 수 없다.

## 오류/실패

- 첫 AE 후속 실행에서 feature error를 float64로 먼저 승격해 YSH-005의 PyTorch float32 연산 순서와 문턱이 미세하게 달라졌다. float32 subtraction→square→mean 순서를 보존하도록 수정한 뒤 기존 11,939개 점수·후보와 정확히 일치시켰다.
- 동료 AE 원 export는 여전히 미확인이다. 이번 008C/008D는 명시적으로 YSH-005 reference이며, 선행 보고 254/298을 재현했다고 기록하지 않았다.
- outside-parent가 16행뿐이어서 parent 통제 비교의 안정성을 평가할 수 없다.
- Result의 행/블록 대응 키가 없어 품질 검출 성능, 원인 또는 불량 유형을 평가하지 않았다.

## 결론

repeat298은 B의 높은 **global NLL을 상당 부분 구성하는 특수 반복 공정상태**다. 그러나 component 내부 d²는 core 제거 전후 거의 변하지 않으며, motif 안에서는 139–143 등을 포함한 소수 local deviation 위치만 남는다. 기존 physical 후보 16개 주 위치는 motif-relative sensitivity에서도 유지됐다.

동시에 repeat298보다 긴 parent exact block이 B 5,600행 중 5,584행을 덮어, `B-nonrepeat`조차 사실상 parent 반복구조다. 따라서 repeat298 하나만의 효과와 B 날짜/상위 motif 효과를 분리했다고 볼 수 없다. 동일 Raw4 motif만으로 날짜 Result 변동을 설명할 수도 없다.

YSH-005 AE는 motif 전체가 아니라 위치 1–12만 표시한다. 이 구간은 전역 NLL episode와 겹치지만 local d²·conditional-z·physical의 주 episode와는 겹치지 않는다. 따라서 두 모델의 공통 local anomaly 근거는 없고, dominant variable의 7/12 일치도 불균형 baseline을 넘지 못한다. 별도 동료 AE의 254/298 보고는 여전히 원 산출물 미확인이다.

## 채택 / 보류 / 폐기

**부분 채택.** repeat298을 전역 희소 상태와 내부 local deviation을 구분하는 구조 변수, 그리고 동일 입력 AE sanity check 단위로 사용하는 것은 채택한다. AE–GMM 공통 이상, 불량 유형, 품질 설명으로의 승격은 보류한다.
