## 4. 이번 실험의 목적 — 질문

**기존 AE·IF가 표시한 이상 후보를 반복 공정조건의 군집으로 설명할 수 있는가?**

K-Means를 비교용으로 추가해 군집과 기존 이상 점수의 관계를 해석한다. 단순히 새 알고리즘을 실행한 사실보다 '반복 조건의 차이'와 '그 조건 안의 드문 관측'을 구분할 근거를 얻는 것이 목적이다. 상태는 통계적 공정조건 후보이며 정상 상태·실제 설비 운전모드로 확정하지 않는다.

## 5. 가설

- H1: 학습 구간에서 정한 군집 중 반복되는 일부 군집에 AE 후보가 집중한다. 조건이 유지되면 개별 무작위 이상점만으로 보는 해석보다 반복 조건과 관련된 해석을 지지한다.
- H2: AE와 다른 원리의 IF에서도 AE 후보의 상당 부분이 선택된다. 공통 후보는 '서로 다른 알고리즘에서 반복 탐지된 강한 공정 이상 후보'이며 실제 불량 정답이 아니다.
- H3: H1의 해석은 동일 조합 빈도를 줄여도 유지된다. 유지되지 않으면 빈도·스케일 의존 설명을 우선하며 조건부 IF 확장을 보류한다.

## 6. K-Means를 수행하는 이유

K-Means는 스케일된4변수의 중심과 거리를 통해 단순한 조건 분할을 제공한다. 기존 GMM의 유연한 분포 가정에서 나타난 상태가 거리 기반 방법에서도 유지되는지 비교하고, AE 경보의 군집 집중을 설명하는 기준이 된다. 중심 분할은 항상 생성될 수 있으므로 군집 존재 자체가 실제 regime의 증거는 아니다. 비구형·크기가 다른 집단, 이산값, 이상점 및 반복 빈도에 영향을 받는 한계를 함께 평가한다.

## 7. K-Means 실험 설계 — 변경할 요소·고정할 요소·사용 데이터

### 7.1 입력과 분할

- 단위: 원본 한 행. 4행 제품 묶음이나 날짜 평균을 clustering 단위로 바꾸지 않는다.
- 입력 순서: Force / Current / Voltage / Weld Time. idx·날짜·불량·품번 제외. 파생 feature와 rolling은 첫 모델 입력에서 제외해 기존4변수 AE·IF와 비교를 유지한다.
- 기준 학습 구간:3/24~3/31의8,470행. 후속 관찰 구간:4/2·3·7의3,469행. 미래 일반화 테스트라고 부르지 않는다.
- 주 전처리: 학습 구간만으로 StandardScaler fit, 변환 후 K-Means fit. 후속 구간은 transform/predict만 한다. 결측·무한대 발생 시 원본 해시·파싱 오류를 먼저 조사하며 자동 대치·절삭하지 않는다.
- 원본 high Force, 반복값, 소수 Time을 보존한다. 품질 불량 여부를 모르는 학습 자료를 '정상 학습셋'이라 부르지 않는다.
- 민감도: (a) 같은 학습 행의 RobustScaler(중앙값·IQR), (b) 학습4변수 완전일치 조합의 첫 출현만 fit하는 unique4. 두 설정 모두 주 분석에서 정한 K를 고정하고 전체 원본에 predict하여 ARI·중심·AE 집중 변화를 비교한다. unique4 scaler도 unique 학습자료에만 fit한다. 이는 독립성 확보나 원본 삭제가 아니다.

### 7.2 고정 설정과 K 선택

- `K=2,3,4,5,6`; K=1은 inertia 기준선만 계산한다. 범위를 보고서의 좋은 결과에 맞춰 늘리지 않는다.
- `init='k-means++', n_init=20, max_iter=300, tol=1e-4, algorithm='lloyd'`.
- 기준 seed42, 안정성 seed7·2026. 각 K에서 seed42 모델을 대표로 고정하고 가장 좋은 seed를 고르지 않는다.
- 학습 inertia와 상대 감소율로 Elbow를 표·곡선에 표시한다. Silhouette는 학습에서 seed42로 비복원 추출한 최대5,000행의 동일 인덱스를 모든 K에 사용한다. 표본에 군집이 빠지거나 계산 조건이 성립하지 않으면 NA와 사유를 남긴다.
- 잠정 후보 요건: 각 학습 군집 크기≥`max(50, ceil(.01×학습행수))`, 두 보조 seed 각각 주 seed 대비 ARI≥.80, Silhouette≥.25. 공정 해석 요건으로 모든 군집이 다른 군집과 적어도 한 변수의 원시 중앙값에서 학습 표준편차의0.5배 이상 차이나야 한다. 이는 공학적 허용오차가 아닌 이번 탐색의 내부 선택 기준이다.
- 요건 통과 K 가운데 최고 Silhouette에서0.02 이내인 **가장 작은 K**를 잠정 선택한다. Elbow는 선택 K 이후의 상대 inertia 감소가 직전 감소의 절반 이하인지 확인한다. 뚜렷한 굴곡이 없거나 상충하면 'K 불확실·잠정 분할'로 표시한다. 거리 점수만으로 실제 regime을 확정하지 않는다.
- K=6은 탐색 범위의 끝이므로 다음 K의 감소율을 확인할 수 없다. 범위를 확장하지 않고 Elbow 확인 불가·잠정 분할로 남긴다.
- 하나도 통과하지 않으면 대표 regime 채택을 보류한다. 실패한 K도 모두 보고하고 사후 범위 확장·feature 추가로 성공을 만들지 않는다.
- K 선택에는 AE/IF flag, 날짜별 불량, 후속기간 경보 일치율을 사용하지 않는다. 날짜 재등장·AE 집중은 K를 고정한 뒤 해석한다.
- 설정의 API 의미는 저장소 버전에 맞춘 [scikit-learn 1.6.1 KMeans 문서](https://scikit-learn.org/1.6/modules/generated/sklearn.cluster.KMeans.html)를 확인했다. 위 수치 기준은 KAMP 공식 기준이 아니라 본 계획의 사전 결정이다.

### 7.3 군집별 확인 항목

군집별 전체/학습/후속 n·비율, 각4변수 min/Q1/중앙값/Q3/max, 중심의 원단위 환산, 날짜별 비율을 기록한다. Force 2.0~2.6 밖과 >3bar의 포함 비율을 별도로 붙인다. 군집별 AE/IF 점수 분포·flag 비율 및 AE 전체 중 해당 군집의 비중을 비교한다.

표·그래프 계획: K별 inertia/Silhouette/seed ARI/최소크기 표와 곡선,4변수 군집별 boxplot, 날짜×군집 비율 heatmap, 원본행 순서 군집·경보 strip, 군집×AE/IF 교차표. 실제 날짜·원단위와 작은 군집의 표본 수를 함께 표시한다. 군집 번호 자체에 순서·품질 의미를 주지 않는다.

설정 간 ARI는 군집 번호에 무관하게 계산한다. H1의 같은 군집을 비교할 때는 학습 원본행의 교집합 수를 최대화하는 일대일 대응으로 라벨을 정렬하고 원단위 중심도 확인한다. AE 포함비율이 높아지도록 라벨 대응을 선택하지 않는다.

## 8. Isolation Forest를 사용하는 이유

AE는 학습한 재구성에서 벗어나는 정도를 보고, IF는 무작위 분할에서 관측이 얼마나 쉽게 고립되는지로 희소성을 평가한다. 서로 다른 원리의 일치·불일치를 통해 AE 구조에만 의존하는 해석인지 살핀다. 이미 YSH-005에 행 IF가 있으므로 **새 글로벌 IF 탐색을 반복하기보다 동일 조건의 저장 점수를 우선 재사용**한다. [scikit-learn 1.6.1 IsolationForest 문서](https://scikit-learn.org/1.6/modules/generated/sklearn.ensemble.IsolationForest.html).

## 9. Isolation Forest 실험 설계

- X4 입력·학습기간·원본행 키를 AE와 맞춘다. 기준은 YSH-005 `if_standard_42`이다.
- 고정 사양: `n_estimators=300`, `max_samples=min(256,n_train)`, `max_features=1.0`, `bootstrap=False`, `contamination='auto'`, `random_state=42`, CPU4스레드. seed7·2026은 기존 저장 결과의 안정성 비교에만 쓴다.
- IF는 거리 기반 표준화가 필수인 모델이 아니다. 기존 결과 재사용과 비교 일관성을 위해 기존 train-only StandardScaler를 유지한다. YSH-005에서 Standard/Robust 점수·flag가 같았다는 결과도 보존한다.
- 연속 점수 `s=-score_samples(X)`를 사용해 클수록 이상 후보가 되게 한다. score 자체는 불량 확률이 아니다.
- 주 이진 기준: **학습 점수95% 분위수(linear) 이상**. `contamination='auto'`의 기본 predict와 이 사용자 문턱을 혼동하지 않는다. 동점 전부를 포함하며 실제 flag 비율이 정확히5%일 필요는 없다.
- 99% 학습 분위수는 문턱 민감도 한 개로 미리 고정한다. 좋은 겹침·불량 건수에 맞춰 둘 중 하나를 주 결과로 승격하지 않는다. 날짜마다 문턱을 다시 계산하지 않는다.
- 오염률·나무 수·feature·seed의 추가 탐색은 하지 않는다. 기존 모델 또는 점수의 메타데이터가 다르면 같은 baseline으로 간주하지 않고 비교를 보류한다.

## 10. 기존 AutoEncoder와 비교 방법

### 10.1 재사용 전제 및 부족한 파일

현재 작업 사본에는 YSH-005 `outputs/tables/row_scores.csv`, `row_models.csv`, `outputs/models/` 및 기존 구간·반복 마스크 CSV가 없다. 코드가 기록하는 경로와 실제 존재를 구분한다. 보고서의 합계만으로11,939개 행의 flag를 생성하지 않는다.

우선 기존 `row_scores.csv`와 모델/문턱 metadata를 확보한다. SHA-256, Excel 행번호2~11940, 중복 키0, 날짜, 학습 마스크, score/flag 완전성을 대조한다. 점수표가 없고 기존 모델만 확보되면 추후 실행 단계에서 그 모델의 추론으로만 복원하는 별도 절차를 정한다. **둘 다 없으면 AE 교차분석은 보류하고 새 AE 학습으로 대체하지 않는다.** K-Means 단독 구조 확인은 진행할 수 있다.

기준 AE는 YSH-005 `ae_42`; MinMax 학습범위·MSE·평가모드·문턱 정의를 확인한다. 0.0732640은 보고서의 반올림 예시이므로 실제 flag 재생성에는 저장된 정밀 문턱을 사용한다. 사용자가 언급한 별도 AE의 결과가 나중에 제공되면 전처리·분할·키를 먼저 확인하고 별도의 보조 비교로만 추가한다.

### 10.2 네 그룹과 지표

1. AE flag + IF flag
2. AE flag + IF 비flag
3. AE 비flag + IF flag
4. AE 비flag + IF 비flag

여기서 비flag는 정상 품질의 증명이 아니다. 각 그룹의 n·4변수 분포·날짜·Force 두 기준 포함비율·K-Means 분포를 학습/후속으로 나누어 비교한다. 행 키가 검증된 과거 rolling 값은 부가 설명으로 연결한다. 네 그룹 합계가 비교 대상 수와 같은지 확인한다.

- 연속 점수 Spearman, `공통/합집합` Jaccard, `공통/AE flag`, `공통/IF flag`를 함께 기록한다. 분모0은 NA다.
- 큰 군집이 AE를 많이 포함하는 착시를 막기 위해 `P(cluster|AE flag)`와 `P(AE flag|cluster)/P(AE flag)`를 함께 본다.
- 주 문턱의 경보량 차이를 유지해 보고하며, 추가로 두 점수 각각의 **학습99% 분위수**를 적용한 고정 예산 민감도를 병기한다. AE의 원래 flag를 대체하거나 IF를 AE 개수에 맞추지 않는다. 동점 비율도 보고한다.
- 날짜별 AE/IF/공통 비율의 분모는 해당 날짜 원본 기록 수다. 같은 조합 재등장이 성능 재현으로 과장되지 않도록 조합별로 한 번 센 보조 교차표도 제시한다.

## 11. Force / Current / Rolling 분석과의 연결

Force 두 정의를 사전 고정하고 군집·경보를 설명하는 속성으로만 쓴다. Force2.0~2.6 밖과>3bar를 동의어로 쓰지 않는다. Current 평균·표준편차·인접 절대변화는 설명용이며 이번 모델 입력으로 추가하지 않는다.

Rolling 연결은 YSH-001의 **현재값을 제외한 과거50행**을 대표 창으로 고정한다. 기존 저장값이 있으면 정의·행 키를 검증해 재사용한다. 추후 계산이 필요하면 원본 순서를 유지하고 날짜 변경, idx 비연속, 날짜+idx 중복 관련 경계에서 창을 끊는다. 과거50개가 부족하면 NA이며 과거20/100행은 민감도 두 개로만 병기한다. Current 표본표준편차(ddof=1), 구간 내 |인접차분| 평균을 네 그룹에서 비교한다. 초·분 단위 조기경고 시간으로 환산하지 않는다.

단순 날짜별 Current/Power/Resistance 상관 후보를 다시 대량 탐색하지 않는다. 새 질문은 **같은 군집에서 AE·IF가 일치하는 후보의 과거 변동성이 다른가**이다. 입력 기록은 해당 용접 완료 후 수집될 수 있으므로 '현재 용접 전 경고' 가능성도 별도 검증이 필요하다.

## 12. 실제 날짜별 불량기록과 연결하는 방법

- 모델·K·문턱을 고정한 뒤 날짜·설비·품번 범위를 확인하여 집계표끼리 연결한다. Raw 행에 result를 복제하거나 `result.idx`로 조인하지 않는다.
- 일별 군집비중·AE/IF/공통비율·연속점수 중앙값/95분위수와 유형별 기재 건수를 비교한다. 유형1·2는8일, 유형3은7일이다. 완전3유형 합계 비교는7일만 주 결과로 쓰고,3/31의5는 부분합으로 별도 표기한다.
- 실제 생산량·검사 대상 제품 수를 모른다. `1,000×기재 건수/Raw 행 수`는 **1,000기록당 기재 불량 수**로만 부른다. 분모를 임의로 행수/4로 바꾸지 않는다. 검증된 제품 불량률 비교는 TODO다.
- 사전 정한 지표 전부에 Spearman과 유효 날짜 수를 표시하고 한 날짜씩 제외한 계수 범위·부호 유지 여부를 기록한다. 5일 미만·상수열은 NA. 상관 유의성을 내세운 후보 선정이나 인과·예측력 해석은 하지 않는다.
- 날짜 라벨을 적은 산점도와 집계표를 만든다. 현재 날짜들로 K·threshold를 고르거나 contamination을 보정하지 않는다.

## 13. 중복 여부 및 차별점

행 단위 군집·글로벌 IF,4행 묶음 GMM·IF, AE/IF 점수 비교, Force 날짜별 분포, rolling, 물리 proxy와 유형별 상관은 기존 작업과 중복된다. 이를 신규 성과로 포장하지 않는다.

새 부분은 **기존 AE·IF 후보의 K-Means 군집 집중/불일치 그룹 해석**, 그리고 중복 빈도 통제 후 그 설명이 유지되는지의 사전 기준이다. YSH-004 GMM 전체기간 fit과 이번 기준기간 K-Means fit은 학습범위가 달라 직접 우열 비교하지 않는다. 행별 저장 GMM 라벨을 확보한 경우 동일 원본행의 교차표만 보조적으로 표시한다.

YSH-005 코드의 IF는 S8 전체 또는 X4 전체 학습자료에 fit하며, GMM의 `state`별 IF를 fit하지 않는다. 따라서 cluster 내부 IF는 구현상 같은 작업은 아니지만, 군집 안정성과 새 정보가 없다면 수행할 이유가 없다. 현재 주 실행 범위에는 넣지 않는다.

## 14. 데이터 누수 점검 / selection bias / 해석의 한계

- 학습/후속 기간 간 모든4변수 조합이 중복된다. 후속 비중·점수 결과는 관측된 조건의 재등장 진단이다. 무작위 행 분할·일반 교차검증 F1을 사용하지 않는다.
- 긴 정확 반복과 날짜를 동시에 보존한 독립 분할이 어려웠다는 YSH 결과를 반영한다. 중복 제거 후 독립 테스트셋이 생겼다고 주장하지 않는다. 새로운 날짜·새 조건·검사 매핑이 필요하다.
- 군집 수·스케일·threshold·seed·feature는 위 설정으로 고정한다. 모든 실패·NA·민감도를 함께 보고한다. 수정을 원하면 결과를 본 뒤 변경했다는 이유와 버전을 별도 기록한다.
- 이 계획은 기존 EDA·보고서를 읽은 후 작성되었다. 완전한 사전등록이나 미공개 검증이 아니다. Result를 fit에서 제외해도 기존 탐색의 선택 편향이 사라지지 않는다.
- 원본4값의 부동소수점 표현과 소수 Time을 유지한다. 반올림으로 중복을 늘리거나 순서를 복원하지 않는다.
- cluster≠정상/불량, anomaly≠defect, correlation≠causation. 날짜별 집계를 행의 정답으로 쓰지 않는다. Accuracy/Precision/Recall/F1/AUROC 등 제품 분류 성능을 보고하지 않는다.

## 16. 실행 계획 — 추천 순서

1. 원본 해시·행수·헤더·날짜·Result 결측을 이 문서와 대조한다. 기존 점수·구간·반복 마스크의 확보 여부와 출처를 확인한다.
2. 프로젝트 루트 공용 `.venv`를 확인한다. 현재 `C:/Kamp-2026/.venv/Scripts/python.exe`는 없다. 추후 실행 준비 때만 `setup-environment.ps1`과 루트 requirements를 사용한다. 개인 Python·별도 환경으로 우회하지 않는다. 이번에는 환경 설치·의존성 변경을 하지 않았다.
3. 기존 AE/IF 점수를 원본행에 검증 조인한다. 파일이 없으면 그 비교를 보류하고 단독 K-Means 준비까지만 진행한다.
4. 기준기간 K1~6 및 seed 안정성 평가 → 사전 규칙으로 K 고정 → 설정·입력 해시 저장 → 후속기간 predict 순서로 수행한다.
5. 군집별 원단위·날짜·Force 설명, AE/IF 네 그룹·연속점수 분석을 수행한다. 고정 K의 Robust/unique4 민감도를 모두 보고한다.
6. 유효한 과거 rolling만 연결하고, 모델 결과를 고정한 뒤 Result를 날짜별로 대조한다.
7. 가설별 지지/보류, 기존 작업 대비 추가 정보, 후속 필요 자료를 기록한다. 조건부 cluster 내부 IF는 아래 문턱을 통과한 뒤 별도 계획으로 결정한다.

구현 파일은 아직 없으므로 존재하지 않는 Python 실행 명령을 재현 명령으로 적지 않는다. 추후 구현 시 실행 경로·CLI·버전·seed·분할·행 키·데이터 해시·저장 위치를 이 계획에 추가한다. 현재 작성물은 이 Markdown 한 개이며, 개인 실험기록 갱신도 실행 단계로 남긴다.

## 17. 후속 실험 조건 — K-Means 군집 내부 IF

다음 조건을 **모두** 충족할 때만 별도 후속 계획의 후보로 남긴다.

- H1·H3가 지지되고 K/스케일/반복 통제에서 설명 가능한 군집이 유지된다.

- 글로벌 AE/IF 네 그룹에서 같은 군집 내부의 희소성을 구분해야 할 구체적인 미해결 사례가 남는다.
- 기존 YSH 산출물 검토에서도 동일 질문의 cluster 내부 IF 결과가 없음을 재확인한다. 같은 결론의 재실행에 그치면 제외한다.

조건 미달이면 수행하지 않는다. 조건을 통과하더라도 드문 군집을 '정상 regime'으로 인정하는 절차가 아니다. 후속에서는 군집·scaler를 기준기간에 고정하고 군집별 학습 점수 문턱을 적용하되, 서로 다른 숲의 점수 절댓값을 직접 비교하지 않는다. 글로벌 IF와 비교할 추가 가치·경보 예산·고유조합 민감도를 별도 계획에 먼저 고정한다.

## 18. 최종 사전경고 모델에 갖는 의미

추가 가능한 정보는 군집 ID와 중심거리(현재 조건), AE/IF 점수·공통 flag(다중 모델 이상 후보), 과거 Current 변동성(최근 문맥), 기존에 본 조합인지 여부다. 이들은 검토 우선순위와 공정 상태 설명에 쓰일 수 있다.

| 질문·가설 | 다른 원리에서도 같은 조건의 후보를 탐지하는가(H2)? |

| 입력 feature·전처리 | 모델은 기존 X4와 학습 scaler 유지. 과거50행 Current 변동성은 설명에만 사용 |
| 모델 설정 | 기존 ae_42, if_standard_42 재사용. IF95% 주 기준/99% 민감도, 기존 AE 문턱 고정 |
| 비교 방법 | 네 그룹4변수·날짜·Force·군집·rolling, Spearman/Jaccard/양방향 포함률 |
| 표·그래프 | 네 그룹 요약·군집 교차표, 점수 산점도, 날짜별 AE/IF/공통 비율, 과거변동성 분포 |
| 해석 | 공통 후보는 강한 공정 이상 검토 대상. 비flag는 정상 판정이 아님 |
| 다음 단계 | 공통/AE≥50% 및 seed 방향 유지, 설명 가능한 미해결 사례가 남으면3번 안정성 확인 |
| 보류/기각 | 공통 기준 미달이면 합의 가설 지지 부족을 보고. 점수 없으면 중단·보류하며 재학습하지 않음 |

### 우선순위 3 — 반복 빈도·스케일 통제 후 결론 유지와 집계 연결

| 항목 | 고정 계획 |
|---|---|
| 질문·가설 | 군집·AE 집중이 빈도/스케일 변경에도 유지되는가(H3)? |
| 필요 데이터 | Raw,1·2번 결과, result 날짜·유형 기록. AE 미확보 시 ARI·중심 비교만 |
| 입력 feature·전처리 | X4, unique4 첫 출현 학습 및 Robust 학습을 각각 주 설정과 비교 |
| 모델 설정 |1번에서 고른 K·seed 고정. feature·threshold 추가 탐색 없음 |
| 비교 방법 | 전체 원본행 ARI, 중심·H1 집중 변화, 고정 일별지표와 Result의 유형별 Spearman·날짜제외 범위 |
| 표·그래프 | 설정별 안정성표, 군집 프로파일 비교, 누락을 표시한 품질집계표·날짜 라벨 산점도 |
| 해석 | 유지되면 상대적으로 안정적인 조건 설명. 연관은 품질 원인·예측 성능이 아님 |
| 다음 단계 | H1/H3 및17절 표본·새 정보 조건 모두 통과할 때만 cluster 내부 IF 별도 계획 검토 |
| 보류/기각 | ARI<.70 또는 H1 결론 소실이면 빈도/스케일 의존으로 기록, 조건부 IF 제외. 낮은 품질 상관을 이유로 재조정하지 않음 |
