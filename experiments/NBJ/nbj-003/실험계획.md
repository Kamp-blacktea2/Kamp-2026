## 질문과 가설

최근 용접 N개에서 계산 가능한 센서 변동성이 **날짜별 기록 불량률**과 함께 움직이는가? NBJ-002에서 관찰한 하루 전체 power·resistance proxy IQR의 관계가 최근 창에서도 유지되는지, Current 평균과 변동성 지표의 차이가 있는지 살핀다. 개별 제품의 불량 여부나 실제 조기 경고 성능은 이 데이터로 확인할 수 없다.

## 입력과 분석 단위

원본 Excel `Raw data` 11,939행·9일과 `result` 23행을 사용했다. 날짜별 불량 기록이 있는 8일을 주 비교 대상으로 삼고, 유형 기록이 부분적인 3/31을 뺀 7일을 민감도 비교에 썼다. 3/27의 미기록은 0건으로 대체하지 않았다. 기록 불량률의 분모는 해당 날짜의 Raw 행 수로, 고유 생산품 수로 확인된 값은 아니다.

원본 Excel 행 순서를 유지하고 날짜 경계마다 창을 초기화했다. 날짜 오류가 의심되는 Excel 3552·5201행은 원본 유지와 제외를 병행했다. 제외 시 해당 날짜의 Raw 행 수를 다시 계산했으며, 원본 날짜를 임의 정정하지 않았다.

## 실제 Notebook에 기록된 계산 방법

- 센서 원단위 Force(bar), Current(kA), Voltage(V), Weld Time(ms)를 읽고 Current·Force·Voltage의 수준 및 변동성, Voltage×Current(power proxy), Voltage/Current(resistance proxy), 인접 기록의 절대 Current 변화 등을 계산했다. Proxy를 직접 측정한 물리량으로 해석하지 않는다.
- 주 분석 **B**는 현재 행까지, 보조 **A**는 한 행 shift한 직전까지의 값만 사용했다. 창 크기 `N=20, 50, 100`과 참고 `N=200`; `min_periods=N`으로 창이 모자라면 계산하지 않았다.
- 각 평가 날짜를 제외한 다른 날짜의 유효 rolling 값으로 95·99백분위 경계를 정하고 **초과**한 행을 경고 후보로 셌다. 경고율의 분모는 해당 날짜의 유효 rolling 행 수다. 참조 날짜에 미래 날짜가 포함될 수 있으므로 이는 회고적 날짜 제외 분석이다.
- 날짜별 rolling 지표 평균·p90·p95 및 경고율을 날짜별 기록 불량률과 Spearman 순위상관으로 비교했다. 8일 전체, 날짜 하나 제외 범위, 3/31 제외 7일, A/B·창 크기·의심행 제외 민감도를 함께 확인했다.
- 후보 안정성 필터는 `N=20/50/100`의 A/B·두 행 처리 경우 전체 12조건에서 날짜 평균 지표의 `ρ≥0.5`, 날짜 하나 제외 최소 `ρ≥0.15`, 7일 `ρ≥0.4`, 유효한 날짜 하나 제외 계산 8회였다. 하루 평균 지표 등은 별도 제외하고, 후보 간 중복은 **B·N=50·8일** 날짜 평균의 `|ρ|≥0.9`로 축소했다. 최대 3개를 남기는 코드 순서를 따랐다.
- 기존 AE 비교를 위해 Notebook은 날짜 제외 9일×3 seed(`42`, `7`, `2026`)를 다시 학습했다. 구조 `4→3→2→3→4`, 50 epoch, batch 64, Adam 학습률 0.01, 각 fold Train의 Min-Max scaling, Train 평가 MSE 평균+8×모집단 표준편차 경계였다. 이 기록은 NBJ-001이나 NBJ-002와 동일한 모델 파일을 재사용했다는 뜻이 아니다.
- 안정 후보가 2개 이상일 때만 참조 날짜 중앙값·IQR로 표준화한 동일 가중치 결합 점수를 생성했다. 후보 선정에 같은 8일의 결과가 쓰였으므로 독립 성능 검증은 아니다.

## 판단 기준과 한계

창별 관계의 크기 하나만으로 최적 배포 설정을 정하지 않는다. 날짜 7~8개의 탐색적 상관, 후보 선택 편향, 반복 센서 조합, 제품별 정답·검사시점 부재를 함께 고려한다. AE 또는 rolling 경고 후보를 실제 불량품이라고 표현하지 않으며, 높은 날짜별 상관을 예측 성능이나 인과관계로 해석하지 않는다. [실험결과.md](실험결과.md)의 수치는 저장된 Notebook과 원본 요약문에서 가져온 것이다.
