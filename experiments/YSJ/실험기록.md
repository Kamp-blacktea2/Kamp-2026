# YSJ 실험기록

# 용접 공정 데이터 분석 및 AutoEncoder 이상탐지 실험

## 1. 실험 목적

용접 공정의 주요 변수인 Force, Current, Voltage, Time의 패턴을 분석하고,
일반적인 공정 패턴과 다른 상태를 탐지하기 위해 비지도학습 기반 분석을 수행하였다.

원본 데이터에는 각 행에 대한 정상/불량 라벨이 존재하지 않는다.
따라서 본 분석에서 탐지하는 이상치는 실제 불량품이 아니라
일반적인 공정 조건과 다른 패턴을 의미한다.


## 2. 데이터 구성

전체 데이터: 11,939 rows

사용 변수:

- weld force(bar)
- weld current(kA)
- weld Voltage(v)
- weld time(ms)

4개 변수 모두 결측치는 존재하지 않았다.

전체 평균:

| 변수 | 평균 |
|---|---:|
| Force | 2.788 bar |
| Current | 14.711 kA |
| Voltage | 2.704 V |
| Time | 71.724 ms |


# 3. EDA

## 3.1 Force

### 분석 과정

생산 순서를 나타내는 idx를 기준으로 날짜별 Force 변화를 확인하였다.

대부분의 데이터는 약 2.3 bar 부근에 집중되어 있었지만,
일부 날짜에서는 생산 중간에 Force가 약 7~8 bar 수준까지 크게 증가하는
별도의 구간이 발견되었다.

주요 발생 날짜:

- 2020-03-25
- 2020-03-27
- 2020-03-31
- 2020-04-03

### 결과

7~8 bar 데이터는 무작위로 발생하는 몇 개의 점이 아니라
특정 생산 구간에서 연속적으로 나타났다.

따라서 단순 이상치로 제거하지 않고
별도의 공정 조건 또는 생산 상태일 가능성이 있는 데이터로 유지하였다.


## 3.2 Current

### 분석 과정

날짜별 Current 분포와 생산 순서에 따른 변화를 분석하였다.

Current의 단순 평균뿐만 아니라 변동 및 상태 변화를 확인하기 위해
다음 특징을 추가로 분석하였다.

- Current MAD
- Low Current Ratio
- Transition Rate
- Mean Low Run
- Max Low Run

### 결과

Low Current Ratio와 Transition Rate 사이에서
Spearman 상관계수 약 0.97의 매우 강한 양의 관계가 나타났다.

즉 저전류 상태가 많이 발생하는 경우
Current 상태의 전환 역시 자주 발생하는 경향이 확인되었다.

반면 Current MAD는 다른 Current 파생변수들과 상대적으로
강한 관계를 보이지 않았다.

따라서 Current는 단순 평균이나 분산만 보는 것보다
저전류 상태의 비율과 상태 전환 패턴까지 함께 보는 것이 필요하다고 판단하였다.


## 3.3 Voltage

### 분석 과정

날짜별 Voltage 중앙값과 Voltage MAD를 계산하였다.

또한 Current와 Voltage를 생산 순서에 따라 동시에 시각화하고,
날짜별 Pearson 및 Spearman 상관계수를 계산하였다.

### 결과

Voltage 중앙값은 대부분 약 2.70 V 부근으로 큰 차이가 없었다.

반면 Voltage MAD는 날짜별 차이가 존재하였다.

Current와 Voltage의 상관관계 역시 날짜마다 방향과 크기가 달랐다.

따라서 전체 데이터에서

Current 증가 → Voltage 증가

또는

Current 증가 → Voltage 감소

와 같은 하나의 단순한 관계로 설명하기 어려웠다.


# 4. Force + Current + Voltage 통합 분석

### 분석 과정

Force가 7~8 bar로 크게 변하는 구간에서
Current와 Voltage도 함께 변화하는지 생산 순서 기준으로 비교하였다.

### 결과

Force가 높은 특수 구간에서는
Current와 Voltage 역시 일반적인 2.3 bar 구간과 다른 패턴을 보이는 경우가 확인되었다.

따라서 Force의 7~8 bar 구간은 단순한 Force 센서 이상이라기보다
여러 공정 변수가 동시에 달라지는 별도의 공정 상태일 가능성이 있다고 판단하였다.


# 5. K-Means 공정 상태 탐색

### 분석 과정

Force + Current + Voltage를 이용하여 K-Means clustering을 수행하였다.

K=2~6에 대해 Silhouette Score를 비교하였다.

### 결과

K=3에서 Silhouette Score가 약 0.73으로 가장 높게 나타났다.

K=3의 Cluster 평균:

| Cluster | Force | Current | Voltage |
|---|---:|---:|---:|
| 0 | 7.196 | 14.835 | 2.610 |
| 1 | 2.338 | 14.697 | 2.702 |
| 2 | 6.717 | 14.845 | 2.757 |

Cluster 1은 Force 약 2.3 bar의 일반적인 공정 조건에 해당하였다.

나머지 Cluster에서는 Force가 약 6~8 bar로 높아지면서
Current와 Voltage의 조합 역시 달라졌다.

이를 통해 기존 EDA에서 발견한 Force 고압 구간이
다변량 공간에서도 일반적인 공정 데이터와 구분되는 것을 확인하였다.

단, Cluster 번호는 정상/불량을 의미하지 않는다.


# 6. AutoEncoder 이상탐지

## 6.1 모델 구성

최종 AutoEncoder에는 파생변수를 넣지 않고
원본 공정 변수 4개만 사용하였다.

입력:

- Force
- Current
- Voltage
- Time

모델 구조:

4
→ Dense(8)
→ Dense(4)
→ Dense(2)
→ Dense(4)
→ Dense(8)
→ Dense(4)

Optimizer: Adam  
Loss: MSE

데이터를 Scaling한 후 입력값을 다시 복원하도록 AutoEncoder를 학습하였다.


## 6.2 학습 결과

Train Loss와 Validation Loss가 학습 초기에 빠르게 감소하였으며
이후 점차 안정적으로 수렴하였다.

Train Loss와 Validation Loss가 크게 벌어지는 현상도 나타나지 않았다.

따라서 현재 학습 그래프에서는 뚜렷한 과적합 현상은 관찰되지 않았다.


## 6.3 Reconstruction Error

각 데이터에 대해

원본값 ↔ AutoEncoder 복원값

차이를 Reconstruction Error로 계산하였다.

대부분의 데이터는 낮은 Reconstruction Error에 집중되었지만,
일부 데이터에서 매우 높은 Reconstruction Error가 발생하였다.

즉 AutoEncoder가 일반적인 공정 패턴은 잘 복원하지만
일부 특수한 공정 조건은 제대로 복원하지 못하는 것을 확인하였다.


# 7. AutoEncoder 이상 데이터 분석

이상 데이터와 비이상 데이터를 나누어
각 변수의 평균, 중앙값, 표준편차를 비교하였다.

### 중앙값 비교

| 변수 | 비이상 | 이상 |
|---|---:|---:|
| Force | 2.34 | 7.42 |
| Current | 14.73 | 14.93 |
| Voltage | 2.702 | 2.749 |
| Time | 72 | 72 |

가장 큰 차이는 Force에서 나타났다.

Force 중앙값이

2.34 bar → 7.42 bar

로 크게 증가하였다.

Current 역시

14.73 → 14.93 kA

Voltage는

2.702 → 2.749 V

로 이상 그룹에서 상대적으로 높게 나타났다.

반면 Time의 중앙값은 두 그룹 모두 72 ms로 동일하였다.


# 8. 현재까지의 핵심 결과

EDA에서 Force가 약 2.3 bar인 일반적인 공정 조건과
7~8 bar 수준의 별도 공정 조건이 존재하는 것을 확인하였다.

이 Force 변화는 단독으로 발생하는 것이 아니라
일부 구간에서 Current와 Voltage 패턴 변화와 함께 나타났다.

K-Means에서도 이러한 데이터가 일반적인 2.3 bar 공정과
별도의 Cluster로 구분되었다.

AutoEncoder에서도 이상 그룹의 중앙값이

- Force: 7.42 bar
- Current: 14.93 kA
- Voltage: 2.749 V

로 나타나 동일한 특수 공정 조건을 강하게 탐지하고 있었다.

따라서 EDA → K-Means → AutoEncoder 분석에서
공통적으로 일반적인 공정 조건과 다른 다변량 공정 상태가 확인되었다.

다만 이것을 실제 불량이라고 판단할 수는 없다.

현재 AutoEncoder의 의미는 다음과 같다.

**AutoEncoder Anomaly
= 실제 불량품 X
= 일반적인 공정 패턴과 다른 공정 상태 O**


# 9. 다음 검증 방향

현재 AutoEncoder가 Force 7~8 bar의 특수 공정 조건을
주요 이상으로 탐지하고 있을 가능성이 높다.

따라서 다음 단계에서는

1. AutoEncoder 이상치가 날짜별로 얼마나 발생하는지 확인
2. 이상치가 실제로 Force 7~8 bar 구간에 집중되는지 확인
3. Force가 일반적인 2.x bar인 데이터만 따로 분석
4. 그 상태에서도 Current/Voltage 기반 이상 패턴이 탐지되는지 확인

하는 과정이 필요하다.

이를 통해 모델이 단순히 '높은 Force 공정'을 찾고 있는 것인지,
아니면 일반적인 Force 조건에서도 Current와 Voltage의 비정상적인 조합을
탐지할 수 있는지를 구분할 수 있다.
