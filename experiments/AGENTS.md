# 개인 실험 작업 규칙

목적: 질문과 가설을 중심으로 개인 실험과 실패 이력을 보존합니다. 루트 AGENTS.md도 함께 따릅니다.

- 모든 실험은 담당자의 `NBJ/`, `YSJ/`, `YSH/` 아래에서 수행합니다.
- 새 실험은 `EXP번호_짧은이름` 형식으로 만듭니다. 개인별 `EXP001`, `EXP002` 순으로 관리하고 번호를 재사용하지 않습니다. 팀 공유 참조에는 이니셜을 포함합니다.
- 시작 전에 `templates/실험계획_template.md`를 복사해 실험 폴더에 `실험계획.md`를 작성합니다.
- 가능하면 한 실험에서 하나의 질문/가설을 검증합니다.
- 종료 후 `templates/실험결과_template.md`를 복사해 `실험결과.md`를 작성합니다.
- 개인 `실험기록.md`의 상단 정보와 표를 갱신하고 각 실험의 질문, 변경, 결과, 다음 행동을 3~4줄로 요약합니다.
- 실패하거나 중단한 실험도 삭제하지 않습니다. 상태, 오류, 원인 및 다음 행동을 남깁니다.
- EDA / PREPROCESSING / FEATURE / ML / DL / VALIDATION / ERROR_ANALYSIS 등은 `실험계획.md`와 `실험기록.md`의 metadata로 관리하며 유형별 상위 폴더를 만들지 않습니다.
- 다른 팀원의 실험과 기존 변경을 존중합니다. 검증된 재사용 코드는 영향 범위 확인 및 리뷰 후 `src/`로 승격합니다.
- 원본 데이터·비밀값·대용량 산출물은 기록에 포함하지 않고 재현 가능한 경로와 설정만 남깁니다.
