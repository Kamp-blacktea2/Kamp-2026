# 로컬 산출물 안내

목적: 실험의 그림, 표 및 산출물을 로컬에서 관리합니다.

- `figures/`: 그림 보관용 자리.
- `tables/`: 표 보관용 자리.
- 모델 파일 및 체크포인트: 필요 시 로컬에 보관하고 Git에서 제외합니다.

안내 문서와 `.gitkeep`을 제외한 산출물은 기본적으로 Git에서 제외됩니다. 실험결과에는 파일 자체 대신 재현 명령과 로컬 경로를 기록합니다. 작은 공유용 그림·표는 권한, 비밀값, 크기를 확인한 뒤 팀 리뷰를 거쳐 정확한 경로만 추적할 수 있습니다.
