필요할 때 `raw/`(원본), `interim/`(중간 결과), `processed/`(처리 결과)를 로컬에 만듭니다. 이는 보관 위치 안내이며 실제 데이터 구조나 처리 과정을 확정하지 않습니다. 해당 경로는 Git에서 제외됩니다.

원본 데이터는 변경하거나 commit하지 않습니다. 접근 경로에 인증 정보가 있다면 문서에 적지 않습니다. 작은 공개 데이터의 추적이 필요할 때만 권한·내용·크기를 확인하고 팀 리뷰 후 `.gitignore`에 정확한 예외 경로를 추가합니다.
