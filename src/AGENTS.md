# 공용 코드 작업 규칙

목적: 팀 전체가 재사용할 검증된 코드를 관리합니다. 루트 AGENTS.md도 함께 따릅니다.

- `src/`에는 검증된 공용 코드만 둡니다.
- 개인 실험용 일회성 코드를 바로 넣지 않습니다. 가능하면 개인 실험에서 먼저 검증하고 재사용 가치가 확인되면 승격합니다.
- 기존 공용 함수를 변경하기 전에 호출부, 입력/출력 계약, 관련 실험 등 영향 범위를 먼저 확인합니다.
- 승격 시 근거가 되는 실험계획·실험결과를 PR에 연결하고, 사용법 및 변경에 맞는 확인 결과를 남깁니다.
- 개인 경로, 비밀값, 원본 데이터를 코드에 넣지 않습니다.
- 데이터 구조, 모델 또는 라이브러리가 미정인 상태에서 구현을 추측해 만들지 않습니다.

하위 폴더는 향후 공용화할 코드의 자리입니다: `data/`, `preprocessing/`, `features/`, `models/`, `evaluation/`, `utils/`. 이 구분은 개인 실험의 분류 체계가 아닙니다.
